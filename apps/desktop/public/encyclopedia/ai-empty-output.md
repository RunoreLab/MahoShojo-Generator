# AI 返回空对象/空内容（{} / [] / 空白）

> 作者：[Colanns](https://github.com/colasama) / [末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-05-08

有时你不会看到明显的 “HTTP 5xx/52x” 报错，也没有触发逮捕页，但生成结果会变成：

- **空对象**：`{}`
- **空数组**：`[]`
- **空字符串/空白**：什么都没有，或提示“服务端响应为空/未收到有效内容”
- **只有思考过程，没有正文**：思考面板里有内容，但战报正文为空，或提示“AI 只返回了思考过程，但未返回可展示的战报正文”

这类情况通常属于 **AI 输出质量/链路波动导致的“有效内容缺失”**：模型没按预期产出结构化结果，或产出过程被中断，最终你拿到的是“空壳”。

## 常见原因

- **输出被截断/中断**：高峰期、超时、网络波动导致只返回了半截，解析后变成空
- **模型侧降级**：在不稳定时，模型可能返回极短/无效内容（甚至只有 `{}`）
- **结构化输出失败**：模型没有按要求给出完整 JSON；解析器无法提取有效字段
- **上游安全策略/拒答的变体**：有些模型不会输出明显拒答语，而是给一个“空回应”
- **思考耗尽输出预算**：部分推理模型会先输出很长 reasoning；如果“请长时间思考”之类要求过强，模型可能把可用输出 token 用在思考通道，最后没有发送正文 `text-delta`
- **供应商/兼容层通道异常**：少数 OpenAI 兼容接口会把应当作为最终答案的内容放进 reasoning 通道，或者只返回 reasoning，不返回最终正文

## 有思考摘要，但仍提示空内容，是什么意思？

思考摘要来自 **reasoning 通道**，战报正文来自 **markdown/text 通道**。两者不是同一条数据流。

如果你看到“AI 思考摘要”里已经有几千字，但战报正文为空，通常说明：

1. 浏览器确实收到了模型的 reasoning 事件
2. 服务端没有收到可展示的正文 `text-delta`
3. 这更接近上游模型/供应商输出异常，不能直接证明站内把正文流弄丢了

这种情况下不要把思考摘要当作正式战报保存。思考内容可能包含未整理、未校验、未脱敏的中间推演，不一定符合战报格式和角色更新协议。

## 你能做什么（按优先顺序）

1. **直接重试 1～2 次**：空对象/空白常是偶发
2. **减少“超长思考/长时间推理”的要求**：把“多想一会儿”改成“先简要规划，再输出完整战报”，避免 reasoning 吃完整个输出预算
3. **把输入缩短、把任务拆小**：降低一次生成的负载（尤其是长战报/长设定）
4. **对战报优先改用流式模式**：至少能看到生成过程，便于判断是“被截断”还是“拒答”
5. **更换模型/供应商（若使用自备通道）**：不同模型对结构化输出的稳定性差异很大；遇到 reasoning-only 时尤其建议换非强推理模型试一次
6. **频繁出现**：优先排查网络/Cloudflare 波动（见相关条目）

## 流式模式自查（SSE）与信息收集

如果你遇到的是“非流式正常、流式为空/立即结束”，建议按下面步骤自查并收集信息（用于自救或反馈）：

1. **开启调试开关**：在战报页 URL 加 `?debugSse=1`，然后重新生成一次。
2. **看控制台**：应出现 `SSE 调试：响应信息`，其中：
   - `status` 应为 `200`
   - `contentType` 应包含 `text/event-stream`
3. **确认是否真正开始 pump**：通常会看到至少一条 `SSE 调试事件`，例如：
   - `phase: "open"`（服务端已建立 SSE，并给出 generationId）
   - `phase: "pump_start"`（开始从上游读取并下发事件）
4. **看读取结束摘要**：控制台会打印 `SSE 调试：读取结束`，重点关注：
   - `bytes` 是否为 `0`（为 0 多半是链路提前断开或中间层吞掉了流）
   - `parsedEvents` 是否为 `0`（有字节但事件数为 0，通常是 SSE 分隔符/格式不符合）
   - `sawDoneEvent` 是否为 `true`（若为 `false` 且很快结束，可能是上游/中间层提前关闭）
   - 是否只有 `event: reasoning` / `event: reasoning_done`，没有 `event: markdown`（这是“只有思考、没有正文”的典型证据）
   - debug 错误里若出现 `errorCode: "ai_reasoning_only_without_markdown"`，说明服务端已确认收到 reasoning，但没有收到可展示正文
5. **出现 `DOMException: The operation was aborted.` 怎么办？**
   - 这通常表示**浏览器侧中止了读取**（例如：你切换页面、重复点击生成导致旧请求被 AbortController 取消、浏览器/扩展拦截了长连接）。
   - 建议：等待页面稳定后重试；避免短时间内连续触发多次生成；必要时用无痕模式/禁用扩展再试。
6. **看 Network 面板（可选但很有用）**：找到 `/api/arena/generate-stream?format=sse`，检查 Response 是否包含多段 `event: markdown` / `event: done`；若只有很短的握手包，通常说明流被提前关闭。

## 如何区分“空内容”和“拒答/安全策略”？

- **空内容/空对象**：输出几乎没有信息（`{}`/空白），或只剩极短的无效片段（本页）
- **拒答**：输出出现「身为语言模型…」「安全策略…」等模板语（见：`/encyclopedia/ai-refusal`）
- **逮捕页**：跳转到逮捕页通常是站内敏感词/安全机制（见：`/encyclopedia/sensitive-words`）
