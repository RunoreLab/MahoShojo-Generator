# 竞技场多人模式：一起围观、提案与生成

> 作者：MahoShojo Generator 管理组  
> 更新时间：2026-09-03  
> 适用版本：v0.9.0+

多人模式不是“第二套竞技场”，而是叠加在现有 `/arena` 上的一层实时协作：**你和朋友们进入同一个房间，共享同一份配置，实时围观同一份战报**。

## 多人模式能干什么？

- 和朋友进入同一个竞技场房间，一起配置这一局，并实时观看同一份战报
- 成员可以修改竞技场配置，并把修改作为**提案**发送给房主，房主接受后才进入本局配置
- 什么都不操作、只进房围观战报直播，也完全可以

一个比较有趣的玩法是“多人跑团”：大家各自提案自己的角色，给角色写好行动引导，最后由房主汇总生成——相当于让 AI 当裁判的跑团。

## 快速开始

1. 房主进入 `/arena`，点击 **打开多人房间**
2. 填写房间标题，选择可发现性（**公开发现**或**仅凭房间码**），点击 **创建多人房间**
3. 把房间码发给朋友；朋友在同一个页面凭房间码加入（公开房间也可以在“公开房间”列表里直接加入）
4. 大家配置角色、提交提案、房主审阅
5. 房主确认配置后点击生成，**所有成员实时看到同一份战报**

需要登录才能使用多人房间；房间最多 16 人。

## 两种最简单的玩法

### 👀 纯围观房

加入房间后不提交任何提案，等房主开始生成即可。适合“我朋友想给我直播战报”的场景——你能看到和房主完全相同的战报内容与结果。

### 🎲 多人跑团（推荐试试）

1. 每位成员在同步房间配置后，像平时一样编辑竞技场：**提案自己的角色**加入阵容
2. 在角色的「行动」中写下本轮的行动引导（例如“潜入图书馆寻找禁书”）
3. 把修改作为提案发送给房主
4. 房主逐项审阅，接受大家的提案
5. 房主统一开始生成，一起看 AI 如何演绎这一轮

## 房主与成员

| 能力 | 房主 | 成员 |
| --- | --- | --- |
| 编辑竞技场配置 | ✅ 直接编辑（点“更新房间配置”后生效） | ✅ 编辑自己的工作副本 |
| 修改进入本局配置 | ✅ 发布后立即生效 | ⬜ 仅以提案形式发送，房主接受后生效 |
| 发起 / 停止生成 | ✅ | ⬜ |
| 审阅提案 | ✅ 接受所选 / 拒绝全部 | —（只能撤回自己的提案） |
| 管理成员 | ✅ 移除成员、关闭房间 | —（可以离开房间） |
| 围观战报 | ✅ | ✅ 同一份实时战报 |
| 查看房间历史战报 | ✅ | ✅ |

成员的修改不会直接覆盖房间配置；房主也始终拥有最终控制权（可以拒绝提案）。

## 提案怎么玩

你可以先像平时一样编辑竞技场（加角色、改引导、调情景、换模式等），编辑发生在你自己的工作副本里，不会立刻影响房间。

- 打开 **提案** 面板，按界面提示把修改作为提案发送给房主
- 房主会看到每一条修改的“变更明细”，并可以逐项选择接受或拒绝
- 提案被接受后，才会进入房间的当前配置（房间配置版本会更新）
- 如果房主修改了房间配置导致你的提案过时，界面会提示冲突或过期，重新同步后再提交即可
- 成员可以随时撤回自己尚未处理的提案

## 断线了怎么办？

不用慌，更**不要急着重新点生成**：

- 网络短暂中断后，房间与生成任务会尝试自动重新连接，恢复到服务器记录的进度
- 看到提示“正在恢复缺口”时，说明客户端正在从服务器补齐错过的战报内容
- 看到“启动结果尚未确认”时，先等待客户端读取服务器状态确认结果，不要重复提交
- 长时间无法恢复时，再使用界面上的“重新连接”按钮

生成是服务器权威的任务：即使你的浏览器短暂掉线，服务器上的生成也不会因为你的断线而丢失。

## 多人和排位是什么关系？

多人生成走的是与单人竞技场**相同的战报生成与排位结算链路**：能否计入 strict/free 排位，仍然按现有口径判断（例如是否 1v1、是否使用引导、是否读写历战/状态等）。

- 只围观、没有提案被接受的对局，本质上就是房主的一次普通生成
- 房间历史战报会标注这一局是否“包含协作变更”（成员提案被接受后产生的影响）
- 想保持对局可比性时，请像单人排位一样避免引导类输入；最终以战报卡片里的「严格排位」面板显示的资格与结算状态为准

详见：`/encyclopedia/ranking`。

## 隐私与数据边界

- 成员提案不是把你的所有本地数据直接传给房间：提案只包含经过服务器校验的配置变更（如角色引用、引导文本、模式设置）
- 成员不能通过房间上传/粘贴本地 JSON、读取房主本地完整配置，也不能借房间查看他人的私有数据卡
- API Key 等凭据永远不会进入房间配置、战报或日志
- 公开房间会出现在房间目录中；不想被陌生人看到就选“仅凭房间码”

## 常见问题（FAQ）

### 为什么必须登录？

多人房间需要稳定标识“谁是谁”（房主、成员、提案作者），匿名身份无法保证房间安全，因此需要登录使用。

### 公开房间和仅凭房间码有什么区别？

- **公开发现**：房间会出现在“公开房间”目录里，任何人都能浏览并加入
- **仅凭房间码**：不出现在目录里，只有拿到房间码的人能加入

### 房主掉线了怎么办？

生成由服务器权威执行，房主浏览器短暂掉线不影响生成继续；房主重新连接后会恢复房间状态。若房主长时间未返回，成员可以离开房间另开一局。

### 房主能一直拒绝我的提案吗？

能。提案只是“建议”，接受与否由房主决定——这是房间最终控制权的一部分。建议开局前先商量好分工。

### 提示“正在恢复缺口”是什么意思？

客户端检测到本地错过的战报内容，正在从服务器权威记录补齐。等它完成即可，不需要重新生成。

### 生成过程中加入房间能看到战报吗？

能看到后续实时发布的内容；已生成的部分可以通过房间历史战报回看最近一场。

### 房间会被保存吗？

房间是实时协作空间：房主可以主动关闭房间（所有成员断开），被关闭或被替换后房间即结束。房间存续期间生成的战报会进入本房间历史战报，供房间成员回看；战报本身的持久化与单人竞技场一致。
