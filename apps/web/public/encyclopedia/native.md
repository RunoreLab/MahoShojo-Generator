# 原生性（签名）

> 作者：[末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-05-13

“原生性”用于区分两类卡：

- **原生卡**：通过站内流程生成并保留签名（通常更接近“问卷生成”的风格）
- **非原生卡**：编辑卡 / 外部修改 / 结构重塑后导入等（通常更自由、更可控）

## 为什么有时会显示“未知”？

原生性依赖服务端签名校验。若当前部署未配置签名密钥，系统无法验证签名真伪，因此会显示“未知”。  
这不是你的问题，也不影响卡的使用，只是少了一个“风格提示”。

## 原生 ≠ 更强 / 更弱

原生性是“来源与可追溯性”提示，不是强度标签。  
在对战里，“强度”更容易被以下因素影响：

- 技术值（规则/提示词密度）
- 是否有引导/判定事件
- 是否读写长线状态（历战/状态栏）

## 跨生态导入与素材注入

万途 Card 导入、酒馆 PNG 导入、自由编辑、手动创建通用卡等流程，都属于跨生态或自定义创作流程。它们可以正常用于创作、管理和战报生成，但不会自动获得本站原生签名。

`v0.8.2` 起，竞技场支持素材注入。素材注入会改变本次战报的上下文，因此默认不计严格排位；这和“卡片是否原生”是两个不同判断：原生性说明卡的来源，素材注入说明本次生成额外参考了哪些资料。
