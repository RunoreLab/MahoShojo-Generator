# 数据卡问题：导入/解析/格式校验/签名

> 作者：[Colanns](https://github.com/colasama) / [末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-01-05

数据卡（角色卡/情景卡/叙事历史等）本质是 JSON 文件。报错大多来自：**文件不是有效 JSON**、**字段不符合格式**、或**来源/签名信息变化**。

如果你不是在“导入文件”，而是在“生成时”看到类似 `格式验证失败`，也可能是 **AI 输出没按结构来**（见：`/encyclopedia/ai-output-format`）。

## 常见报错长什么样？

- `JSON 解析失败` / `读取文件失败`
- `格式验证失败` / `缺少必需字段`
- `这不是可识别的…数据卡（templateId/version 不匹配）`
- `数据卡不存在或已被删除`

## 自救建议（按优先顺序）

1. **确认文件类型**：必须是 `.json`，不要把图片/文本改后缀冒充
2. **确认编码**：尽量使用 UTF-8，避免从聊天软件“复制粘贴后存盘”导致乱码
3. **回到来源重新导出**：如果是从站内下载的卡，重新下载一份再导入
4. **别手改大结构**：外部编辑建议只改你明确理解的字段；大改后更容易触发格式校验失败
5. **遇到“原生性未知/非原生”**：这不影响使用，只是来源提示变化（见相关条目）
