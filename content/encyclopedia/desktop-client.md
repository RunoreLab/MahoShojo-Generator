# 桌面客户端：安装、更新与本地数据

桌面客户端是《魔法少女生成器》的 Windows 应用，与网页端共用产品内容和部分在线服务，但本地数据的保存位置不同。

**版本与下载状态请以 [桌面端下载页](https://mahoshojo.colanns.me/download) 为准。** 在正式版安装包发布前，不要从非官方渠道寻找所谓“正式版”。

## 一、适合谁使用？

- 希望在 Windows 上以独立窗口使用创作、竞技场及本地作品库等功能。
- 希望管理本机的数据卡、Web 包及 AI 连接配置。
- 希望在线使用账户与公开内容，同时在可用的功能范围内处理本地资料。

桌面端并不等于“所有操作都离线”：在线账户、公开库、托管 AI 等功能需要网络。使用自备 AI 连接时，是否能离线还取决于你所配置的模型和服务是否运行在本机。

## 二、下载安装

1. 访问 [桌面端下载页](https://mahoshojo.colanns.me/download)，确认当前显示“已开放下载”。
2. 通过页面上的链接获取官方 Windows x64 安装包及 SHA256 校验文件。
3. 安装前先确认来源。Windows PowerShell 可以运行 `Get-FileHash "安装包完整路径" -Algorithm SHA256`，将输出的 SHA256 与官方清单比较。
4. 按安装向导完成安装；若缺少 Microsoft Edge WebView2 运行时，安装程序需要联网下载它，因此不是完全离线安装包。
5. 如需使用在线账户功能，在客户端的登录入口完成系统浏览器授权。

正式版首发面向 **Windows 11 x64**；Windows 10 22H2 的兼容情况以发布说明和实机反馈为准。macOS、Linux 或 ARM 原生安装包不在本轮承诺范围内；网页版依然可以继续使用。

### 为什么 Windows 提示“未知发布者”？

首发版暂不使用 Windows Authenticode 发行者代码签名，因此安装时可能出现“未知发布者”、SmartScreen 信誉提示或其他安全提醒。这**不能单凭提示就证明安装包恶意或安全**。

请先通过官网进入官方 GitHub Release，核实文件名、来源和 SHA256。不要为了安装而关闭系统整体安全防护；如果不能确认文件来源，应停止安装并反馈。

**注意：** Windows 安装程序的发行者代码签名，和 Tauri 应用内更新包所用的完整性签名，是两套不同机制。

## 三、网页版与桌面版的数据关系

| 数据类型 | 跨端规则 |
| --- | --- |
| 登录账户、线上公开数据卡与受账户管理的云端内容 | 登录并联网后，按各功能现有的云端规则访问 |
| 网页端本地库（浏览器 IndexedDB） | **不会**因登录同一账户自动转入桌面端 |
| 桌面端本地作品库及本机设置 | 保存在当前 Windows 用户的本机应用数据区域，不能假定与网页端或其他电脑自动同步 |
| 浏览器本地会话、Web 包与其他个人草稿 | 先核对相应功能是否提供导出/导入；不要把浏览器本地数据当作云端备份 |
| 自备 AI 连接与 API Key | 按客户端独立配置；不要期望浏览器的本地设置自动迁移 |

跨端迁移时，建议先导出能够导出的数据，再从目标端导入；具体功能是否支持批量恢复，以当时页面提供的操作为准。

**从 Beta 升级：** 在正式安装包通过升级验收、发布明确的迁移说明之前，请先保留原版本并备份重要的本地卡片与作品。不要通过卸载旧版、删除应用数据、清除浏览器网站数据等方式“修复升级”。

## 四、更新与故障排查

- **检查新版本**：从 0.1.0 起，在“设置 → 高级”中选择“检查更新”，查看版本和说明，再确认下载与安装。下载期间可以取消；安装开始后应用会关闭，请先保存作品并结束生成、备份或恢复。Beta 用户首次进入正式版仍需手动下载安装包。
- **更新检查或下载失败**：当前安装保持不变，可稍后重试，或访问 [下载页](https://mahoshojo.colanns.me/download) 手动下载。客户端不会在后台强制安装更新。
- **查看开源许可**：在“设置 → 高级 → 第三方开源许可”离线阅读随安装包提供的组件及字体归属说明。
- **启动白屏、页面打不开**：确认操作系统与 WebView2 运行时正常；重新启动应用后记录版本号和操作步骤。
- **登录没有返回客户端**：先检查默认浏览器、网络及协议跳转提示，不要反复启动多个登录窗口。
- **AI 连接失败**：检查所选供应商、模型、端点、密钥和网络；自备服务不可用不一定是客户端故障。
- **本地作品不见了**：先核实 Windows 用户、客户端版本和本地库入口，保留现场并检查备份，避免先清理数据。

如需反馈，请提供：客户端版本、Windows 版本、故障发生步骤、可公开的错误提示/截图。**请勿在反馈中提交 API Key、登录令牌或完整的私人作品库。**
