# 524 Timeout（Cloudflare 超时）

> 作者：[Colanns](https://github.com/colasama) / [末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-01-05

**524** 是 Cloudflare 的经典报错之一：Cloudflare 已经连上了“源站”（也就是本站后端），但后端在限定时间内**没有返回响应**，于是 Cloudflare 判定“等待太久”并中断请求。

## 你会看到什么？

- 页面/弹窗提示 `HTTP 524` / `524 Timeout` / `A timeout occurred`
- 或者表现为：**长时间无响应** → 最后失败

## 常见原因

- 生成任务太重：输入过长、要求过多、一次生成太大
- 高峰期拥堵：服务端排队，处理时间被拉长
- 上游模型响应慢：AI 提供方临时波动

## 你能做什么（按优先顺序）

1. **直接重试**：偶发 524 很常见
2. **把任务拆小**：减少一次性生成长度/复杂度（尤其是长战报、长设定）
3. **减少并发**：不要同时开多个标签页一起生成
4. **对战报改用流式模式**：至少能边生成边看到内容，不容易“等到超时才全无”

## 这会导致数据丢失吗？

通常不会。**524 更像“等太久被中断”**，不是“你的数据坏了”。但对于非流式生成，确实可能出现“本次没有拿到内容，需要重试”。
