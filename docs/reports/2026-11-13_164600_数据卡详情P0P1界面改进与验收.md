# 数据卡详情 P0～P1 界面改进与验收

日期：2026-11-13
状态：已实现并完成下列本地验证；非发布或真实 Desktop 窗口验收记录。

## 评估与处理

对照当前代码，底栏的紫、蓝、绿按钮竞争、嵌套横向按钮组在手机上挤压、底部重复关闭、空提示占位和正文前元信息过多均成立。公告横幅原层级 `1000` 也确实高于详情使用的 `50`。

| 优先级 | 意见 | 本轮处理 |
| --- | --- | --- |
| P0 | 重构底栏响应式 | 共源操作栏允许完整按钮换行，文本保持单行；常见手机宽度保持双按钮并排，空间不足时整颗按钮换到下一行。无消息时不创建提示占位。 |
| P0 | 精简操作、统一主次 | 底栏保留下载 JSON 与按宿主能力提供的存到本地库；有保存能力时保存为主操作，否则下载为主操作。复用现有生成操作按钮和主题 token。 |
| P1 | 去掉重复关闭 | 保留头部关闭、初始焦点、Tab 圈留、Escape 和关闭后的焦点还原；头部关闭与操作按钮至少 44 CSS px。 |
| P1 | 公告与模态层级 | 横幅降低到当前页面浮层 `z-40`，低于基础模态框 `z-50`；公告详情使用现有 `--app-z-modal`。没有提高全局模态层级。 |
| P1 | 正文与元信息顺序 | 概览之后先展示正文，技术、标签、排位和日期在正文之后；日期默认折叠。作者和完整来源说明仍在正文前，缓存、预设、本机未验签等限制保持可见。 |
| P2 | 移动端全屏 | 暂缓，保持现有居中详情容器，不加入返回导航或新的全屏状态。 |

卡牌工坊移入 Web 详情的“更多”，与公开云端卡的举报入口共用披露面板。“更多”使用普通按钮与原生 Tab 顺序，接入现有 Escape 栈；Escape 先收起面板并还原触发按钮焦点，点击或移焦到外部时收起。举报加载和禁用解释保留。

没有采纳“默认折叠来源”这一部分：来源关系到用户对缓存、权限与本机签名状态的理解，不能只为压缩高度而藏掉。待处理提示和处理／申诉摘要仍在正文之前。

## 实现与依据

- [BasicCardDetailsModal](../../packages/ui-web/src/card-details/BasicCardDetailsModal.tsx)：共源布局、正文顺序、日期披露和头部关闭。

- [Web 装配](../../apps/web/components/DataCardDetailsModal.tsx) 与 [Desktop 装配](../../apps/desktop/src/features/card-details/card-details-modal.tsx)：保留原下载、权限、保存回执及异步生命周期，仅回用共享展示层。
- [AnnouncementCenter](../../packages/ui-web/src/announcement/AnnouncementCenter.tsx)：公告横幅层级修复，独立提交 `66cb16ea`。
- [CardDetailsSample](../../packages/ui-web/src/showroom/CardDetailsSample.tsx)：样板间直接渲染生产详情、按钮和披露面板，提供公开／所有者／缓存／本地／预设、保存中和下载校验中状态。

依据：[双端视觉治理决策](../decisions/2026-10-19_215000_双端视觉治理体系决策.md)、[视觉基线规格](../specs/2026-10-19_215200_双端视觉基线与工程契约规格.md) 的 VIS-CSS-001/002、VIS-SHOW-001、VIS-A11Y-001、VIS-GOV-001，以及[本地库规格](../specs/2026-09-29_200500_本地库Web落地与BattleDataModal一等数据源规格.md) 的复制行为边界。未修改 accepted 语义、数据格式或权限规则。

## 未验证与影响

根字号放大是文字重排检查，不等同浏览器原生缩放。真实 WebView2、浏览器原生 200% 缩放、系统 DPI、读屏及原生高对比主题未验收；forced-colors 巡检仅为浏览器模拟。既有共享按钮与主题的对比度缺口不在本轮全局改色。

没有新增生产依赖、环境变量、持久化迁移或发布操作；下载 JSON 内容和保存副本的来源、权限及回执仍归原宿主处理。
