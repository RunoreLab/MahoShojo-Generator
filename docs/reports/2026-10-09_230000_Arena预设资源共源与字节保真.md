# Arena 预设资源共源与字节保真

状态：D5.1b b1-B2 资源前置；本地实现与定向自动验证。页面、执行器、生产部署与 Windows 真机验收不属于本片。

## 单一权威与现有消费

- 49 份角色 JSON（400,954 B）与 15 份情景 JSON（254,045 B）从 Web 静态目录原字节迁到 `content/presets/`、`content/scenario-presets/`。角色 picker 保持原有 41 项与顺序；另 8 份旧资源由 `content/sync-manifest.json` 的 `arenaPresets.*.legacyFiles` 显式保留，继续供应原 URL，不自动加入 picker。
- `domain/presets`、`domain/scenario-presets` 承载原纯目录、类型与文件名校验，Web 原 lib 路径直接 re-export。所有既有 Web 消费者继续使用这些路径；未改选择、来源身份或加载行为。
- 复用 `scripts/generate-encyclopedia-content.mjs`、两宿主既有 dev/build 脚本及资源门禁。两端 `public/presets/`、`public/scenario-presets/` 只在构建期生成，Git 只跟踪根 `content/` 权威。脚本核对目录、类型、legacy、完整文件集，并以原字节同步；只剪除自己拥有的目录，保留无关静态资产。
- `arena-black.svg`（52,104 B）移入 `content/brand/`；它与既有 `arena-white.svg`（20,746 B）均列入 shared，保留 Web `/arena-black.svg`、`/arena-white.svg`。Desktop 的新增静态字节合计 727,849 B；Git 无双份资源正文，无新生成框架或生产依赖。相关页面/CSS 留给后续 UI 切片。

## 身份、签名与 Hosted 边界

`generate-arena-room-preset-registry.mjs` 改从根 content 读取。API registry 仅改变 64 个 `sourcePath`；整份 Web catalog、Hosted authority 逐字节不变。迁移前后 64 份正文 SHA-256 全相等；ID、kind、canonical versionToken、签名字段及所有其他 payload 字段均不变。资源复制不执行签名验证、重签名、来源升级或 JSON 重序列化。

Hosted 两份测试与 Web 两份原 public 导入测试改读 content 权威，避免开发机残留生成物掩盖干净检出的缺失。MONO-006 的导入、文件读取、Git ignore/跟踪及生成物屏蔽门禁纳入两目录；没有放宽门禁。纯 domain catalog 的显式 exports 与真实 Web re-export 模块图加入 server-safe 检查；品牌输出精确区分 shared 与 Web-only。
