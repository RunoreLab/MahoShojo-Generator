## 资源与行为修订

恋爱包的分发文件共 **104,464 B，约 102 KiB**（不含生成的 manifest）。移除 1,248,191 B 的本地页眉图和备份文件；默认页眉为 CSS 与文字，作者原插图保留为点击后加载的 HTTPS 外链。请求由用户浏览器直接送到图片站，无项目服务器代理或图片托管。外站失败保留报告与本地页眉；图片使用 `no-referrer`。默认不发起外部请求。

修复六个维度可重复 ID 的校验缺口：schema 要求每个维度恰好一次，运行时同步检查；卡片与汇总不再分别用 50/0 填补缺失项。策略至少包含一条避雷建议。演示数据与 AI 示例共源，仅目标文件 404 时加载演示；损坏 JSON 或结构错误显示明确错误，不静默替换成演示。

保留原评分玩法，将能力处理限定为“战力不直接替代恋爱评分，但考虑与相处相关的能力事实”。后日谈和 CG 明确为尊重角色意愿与既有关系的假设分支；示例建议改为自愿公开活动，尊重拒绝与不回复。

收容包的分发文件共 **285,617 B，约 279 KiB**，均为 HTML/CSS/JavaScript/JSON/Markdown 与小型 SVG。保留原档案、模块与等待生成的占位数据。补充内容边界、设定忠实性及事实记录规则，明确认知检查、权限与档案科记录属于虚构演出，并修正一处元数据示例的伤势表述矛盾。

## 真实模型验收

使用 OpenRouter `baidu/ernie-5.5-flash-preview:free`，按仓库实际提示词组装、尾注解析、JSON/schema、Overlay 与通用物化流程验收。调用前核对[官方模型列表](https://openrouter.ai/api/v1/models)中输入/输出价格为零；9 次完成的响应回执均为 `cost: 0`。此前尝试的 `google/gemma-4-31b-it:free` 返回一次 429，未产生生成结果。

| 包 | 首轮案例 | 首轮格式与渲染 | 单独复测 |
| --- | --- | --- | --- |
| 恋爱测评 | 普通图书馆员、日常辨谎能力、已有稳定恋人且拒绝追求 | 2/3 通过；辨谎案例 JSON 损坏，被拒绝物化 | 同一辨谎案例另行调用一次，通过 |
| 收容档案 | 无人格导向灯、自愿观察的绝对防护角色、仅有传闻的街道 | 3/3 通过 | 无 |

六个案例最终都有可运行目标。原始失败输出仍保留，没有修改模型原文来伪造通过，也没有给产品增加自动二次调用。收容包来源说明精简后，提示词语义不变；三份既有生成目标重新通过最终 revision 的 schema/Overlay 与浏览器检查。

另在提示词中开启历战/当前状态写入选项，追加普通角色与明确拒绝恋爱角色各一次：普通角色通过，元数据明确不改变真实关系且保留无既定恋人；拒绝恋爱案例缺少尾注，记录为格式失败。两次仅检查生成协议，没有执行实际角色写入。全部 7 份通过结果的尾注另经宿主 `hasArenaWebPackageMeta` 校验通过。

对六份通过的目标，另用真实 Edge 在受限 iframe 中加载最终包资源：1280px 与 390px 无横向溢出、无未捕获脚本错误、无默认外部网络请求；收容模块均装配，运行时诊断无警告。额外模拟运行时损坏 JSON 和重复维度，均显示错误并隐藏报告主体。

人工复核未见露骨成人、猎奇折磨等违规内容；辨谎没有扩展为读心，绝对防护没有被削弱或增加代价，明确拒绝恋爱的角色保留普通朋友边界，街道传闻没有被写成已证实能力。自由生成仍有质量局限：导向灯案例个别操作条款前后不够一致，普通恋爱案例扩写了素材未明确给出的心理动机。这是小样本证据，不能据此承诺所有模型均能稳定一次生成成功。

合成输入、提示词、模型原文、测试脚本、逐例结果与截图保留在忽略目录 `.tmp/community-web-package-eval/`，不包含在预设分发文件中；密钥未写入报告或仓库。
