## 已确认改善与未通过项

- 已移除代码中强制破解、忽略无消耗、按能力类别禁用、强行平衡等明确冲突。合成绝对防御、羁绊触发、温暖日常、情景 IF、越权输出等案例出现符合目标的结果。
- 时停案例曾被写成三分钟、七分钟冷却；补充数值与单位忠实性后，两模型定向重测均使用十秒窗口，未再出现该次错误。
- 热门评估情景可以完成评估任务而非强行写成战斗。多轮茶会能澄清“魔力耗尽”的角色猜测，并在演习结束后将临时禁用与永久设定分开；更新 JSON 使用正确 roleId。
- **人物弱点仍有失败**：公开经典案例仍将伊利亚的颓废、自我怀疑或酒精写成实战削弱，即使原卡明确其战斗本能不受影响。最终补强规则并恢复交战任务后，该模型仍出现此错误。
- **元叙事与胜负仍有失败**：一例把练习剑轻击夸大为致命重击，并把免疫一次伤害直接当成获胜依据。能力次数遵守和不执行越权文本，并不足以证明结果推演正确。
- **复杂评估规则仍未全验**：输出可完成十二维评估，但曾援引不存在的限制或混淆角色自述与客观事实；后续样本有所收敛，未逐项正式验证长情景所有评分条款。
- **茶会标识与身份仍有失败**：模型会把中文姓名或拼音写入 speakerId，而非原始 ID；摘要出现将玩家“旅人”与 NPC 纸羽混同。没有将这些输出自动写入生产状态。
- **格式仍有失败**：候选一次尾注未闭合；既有保留原文与失败路径不变，本轮未通过放宽解析或自动再生成掩盖失败。

这些结果支持完成共源和规则冲突修复，但不支持“任意长卡、任意模型已稳定忠实”的结论。若后续需要更稳定的自动更新，应以代表性长卡继续比较模型，或另行评估有成本预算的独立核对方案。本轮不引入额外生产调用。

真实调用主要覆盖 Arena Markdown 内容、茶会 JSONL/摘要/更新 JSON；真实外部 SSE、HTML/Web Package、完整结构化 Arena 和多 Provider 矩阵未逐项执行。相应消息与格式接线有自动测试，外部模型可靠性仍未验证。

node scripts/evaluate-narrative-prompts.mjs --source-ref 4f68a5da24567ca696ca0065db8211d70d101f62 --out .tmp/narrative-eval/baseline.json
node scripts/evaluate-narrative-prompts.mjs --out .tmp/narrative-eval/candidate.json --run true --models agnes-3.0-flash,agnes-2.5-flash --key-file .tmp/api-keys/Agnes.key --baseline .tmp/narrative-eval/baseline.json --results .tmp/narrative-eval/results.jsonl
