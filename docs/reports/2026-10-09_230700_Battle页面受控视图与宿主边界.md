# Battle 页面受控视图与宿主边界

状态：B2 共享前置，Web 真实消费；Desktop 页面交付与完整 CI 单独验收。

## 本片范围

- `@mahoshojo/ui-web/arena` 承载原 `/battle` 页框、hero、区块组合、本地导入表单、roster/material/scenario Section 与 presentation，以及预设、模式、故事控件。
- Web 的旧入口路径保留为实际消费包装，`BattleLitePage` 继续拥有 store/auth/network、模态和结果扩展；single/Proposal adapters 与 session/context 保留原宿主。
- Lite 主情景消费同一 `ArenaScenarioSection`、`ScenarioPickerPanel` 和预设 picker；其辅助情景能力关闭。仅布局和原有 Lite 文案通过 presentation 参数区分，未创建第二套情景表单。继承高级数据保持原样。
- `BattleLitePageView` 的 null slot 不显示相应区块；缺少在线入口和下载 port 时不显示这些操作。Web 明确提供原链接与完整能力，Web 没有因此删功能。
- `ArenaRosterImportPanel` 仅拥有临时表单状态与成功清除/失败保留/输入复位；Web 解析、本地库偏好、自动保存和状态提示继续由 `RosterUploader` adapter 提供。
- `@mahoshojo/ui-web/arena.css` 原样承接 Web battle-lite token、暗色和组件样式；Web 明确导入。旧 class、层级与样式值保留，没有新全局模态、字体或焦点机制。
- 纯 story-length 格式函数移到 `@mahoshojo/domain/story-length`，Web 服务端和控件均用同份实现。原默认值、归一化和格式文本不变；未改 Prompt。
- 资源依赖为独立预设资源原子（`domain/presets` 与 `domain/scenario-presets`），未重复复制 JSON/图片。

## 结果展示原子

`@mahoshojo/ui-web/arena-report` 真实拥有原 `BattleReportCard` 与 `StreamingBattleReportCard` 的正文、元数据、Markdown 组件、模式/宽度、推理展示、随机判定、插图、停止/超时和截图 DOM 准备/复位。

Web 两个旧入口保留原调用签名，以显式 host ports 提供：

- 原 `GeneratedByUserBadge`（保留登录态与徽章读取）；
- 原 Web 外链媒体准入、URL 转换与 heuristic reasoning；
- 原截图配置、桌面下载、移动端分享/长按预览回退；
- Markdown 文件保存与错误反馈。

共享视图不导入 Web store/auth/network。缺省拒绝外链 Markdown 媒体，不显示缺少 port 的导出；`illustrationAsset` 是宿主显式提供的资产。停止操作可独立于截图能力，Web wrapper 显式保留旧 onSaveImage 所决定的按钮可见性。

战报表格插件与判定文本辅助函数真迁到 `arena-report-text` 纯叶子；Web 旧 lib 路径 re-export。通用 Markdown adapter 仍按原顺序注入领域插件，没有把它强绑到百科。ui-web 只声明 Web 已使用的同锁版本依赖，无新增版本或 resolution；frozen/offline lockfile 与供应链策略验证通过。

结果原子定向验收：Web 七文件四十测试（含新增真实 wrapper DOM 五条）、共享无宿主能力 DOM 一条、根 server-safe/真实 Web CSS 编译二十四测试、ui-web TypeScript、双方定向 ESLint、workspace boundary 与 diff 检查通过；独立源码审查通过。完整生产构建/整合 CI 仍由最终冻结整合树执行，不以本报告替代。
