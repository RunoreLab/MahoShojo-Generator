## 1. 本片交付

规范依据为 [Desktop 共源 ADR](../decisions/2026-10-02_184000_Desktop产品架构与Web共源决策.md)、
[共享边界](../architecture/2026-10-02_184000_Desktop产品架构与共享边界.md)及
[Arena 双生成契约](../specs/2026-08-31_063734_Arena双生成契约回归修正规格.md)。

- `ai-core/arena-generation` 显式出口持有原 Hosted 纯 Prompt/schema/JSON 解析；原兼容路径仍被
  Hosted `prompt`、`node-executor`、D1 finalization 和 companion 实际调用，不是无消费者的副本
- 同一出口提供单人业务输入投影、报告文本投影、结果 roster 映射及 Markdown 转换。
  Web `/battle`、`/arena` 仍经原 `BattleActions`/`BattleResult` 调用 `useBattleEngine`，此真实 hook
  改为回用共享纯核；报告类型从 React 组件迁出，原 `NewsReport` 类型入口保留兼容
- `domain/narrative-history-operations` 接收 entry 构造、稳定 generation 去重、标题 fallback 与
  原请求历史读取投影。Web store 和 Room 原兼容路径回用，未增加第二套历史规则

两页面布局、原 advanced 字段、分队、Lore、素材、情景/辅助情景、语言、自定义长度及历史读写设置保持。
纯输入投影不收 Provider/凭据、request identity 或权威上下文；它保留完整角色/素材扩展，只映射原传输字段。
客户端 `isNative` 仍只是待服务器重验的声明，不产生新资格。

## 2. 保留在宿主的权威与生命周期

- Web 持有随机占位符解析、敏感词检查、屏蔽词回调、Provider 快照、dispatch、恢复、取消、完成判定和实际写入
- 输入中的分队/叙事历史仍在 Web Package 异步解析之前采集；读取关闭不发送历史，写入开关独立
- Hosted 保留 `serverContext`/output contract 选择、记者随机元信息、随机判定执行、资格校验、签名、Provider 路由和 finalization
- 历史旧 key `arena-narrative-history-v1`、persist version 2、migration、hydration 和存储实现继续由 Web 持有；共享 entry 函数只接收宿主提供的时间与 ID
- 失败/取消/缺少终态不追加；同 generation 重放返回已有 entry；Prompt 顺序保持旧的尾部追加/读取逻辑

本片无 native route/DTO、Desktop `/battle` 页面、历史 writer/DB、Strict/多人功能、连续会话、立绘或资源大迁移。
没有新造无消费者的 Direct 执行层。canonical 四模式最少人数仍为 2/2/1/1；服务端 32 上限未变，没有新增缩限。

## 4. 后继依赖

本片完成不表示 Desktop/Hosted Arena 已可用。Next generation runtime 当前无条件使用 unavailable replay store，
其 reserve 不能创建 generation；non-stream companion 复用同 service，因此也不能以 companion 绕过该限制。
官方 Hono primary 虽在配置中存在，不能据此推导 Native 已获任意 origin 或凭据注入许可。

后续普通 Desktop 旅程应复用已有 Direct execution，并另行冻结输入/UI/存储与取消边界。
Hosted 接入须独立设计固定 origin、actor/auth、恢复与取消，或另行审定 Next active runtime；不得用 mock 宣称线上创建通道可用。
CSS/预设资源、完整 `/arena`、Strict 与多人仍按[唯一计划](../plans/2026-09-30_160100_Desktop客户端阶段实施计划.md)分片。
