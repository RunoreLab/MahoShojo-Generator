## 当前问题与共享边界

维护者提供的真实 Scenario 截图中，结果标题、JSON、保存和下载区域没有统一卡片背景；本地保存是弱化的透明边框按钮，而重复下载入口之一使用大号渐变按钮。源码确认 `ScenarioPageLayout.results` 是多个结果语义区块的装配位置，不是一个可以无条件套 `.card` 的单一结果。

共享层负责相同语义区块的背景、边框、圆角、阴影与内边距；宿主继续负责本地/云端保存及文件处理。保留 Web 通用情景编辑器和结构化输出的不同交互，不为样式迁移修改生成、签名、草稿或保存状态。

字体声明差异已证实：Web 全局为 `Arial, sans-serif`，Desktop 全局为 `Segoe UI, PingFang SC, Microsoft YaHei, system-ui, sans-serif`。这不等于已经验证 Windows 实际字形回退。原始 JSON 的 `font-mono` 又具有单独的代码字体语义；不能根据截图把所有等宽字体一律删除。

## 可见行为变化（不伪装为无影响迁移）

- 五页同义的 JSON 下载/复制使用次操作，保存使用主操作；共享 `SaveJsonButton` 的文本模式复制也沿用共享按钮触达尺寸。Web 实际消费者同步调整尺寸/配色，并非只改变 Desktop。主生成仍回用已有 Web `generate-button`，不另建一套 Desktop 生成尺寸
- Web 云端“替换已有”是现有独立能力，保留其确认/权限/内部样式，本轮不改造通用云端保存组件
- Free / Scenario 的保存模式由 UA 推荐，两页没有切换控件。下载模式只保留共享下载入口；文本模式保留完整文本/复制，并仅在此模式显示一个次级下载入口，避免去重误删旧能力
- Desktop 的本地卡库保存是主要结果操作，复制/导出是次操作；显式不可撤销的确认清除有危险操作样式，普通“清除草稿”入口不额外强调
- 结果标题与签名辅助信息分层，官方/未验证/未签名的会话判定及数据均不修改

## 字体与视觉补验：最小只读采样

在相同 Windows 设备、相同视口尺寸/缩放、相同明暗主题下，分别打开 Web 和本轮 Desktop 的五个页面。使用受控假数据得到结果，不调用付费模型、不更改真实凭据。记录实际提交与 Web 构建身份；不要把线上旧版本与本轮 Desktop 的差异误算为本轮回归。

在各自 DevTools Console 执行以下脚本。它只读取样式与可见布局，不读取正文、JSON 内容、输入值、localStorage、Cookie 或凭据，也不发送网络请求。

```javascript
(() => {
  const scope = document.querySelector('[data-testid="page-scenario"], [data-testid="page-free"]')
    ?? document.querySelector('main') ?? document.body;
  const groups = {
    body: [document.body],
    headings: [...scope.querySelectorAll('h1, h2, h3')],
    actions: [...scope.querySelectorAll('button')].filter((element) =>
      /保存|下载|复制/.test(element.textContent ?? ''),
    ),
    code: [...scope.querySelectorAll('pre, code')],
  };
  const rows = Object.entries(groups).flatMap(([group, elements]) =>
    elements.filter((element) => element.getClientRects().length > 0).map((element, index) => {
      const style = getComputedStyle(element);
      const box = element.getBoundingClientRect();
      return {
        group, index, tag: element.tagName.toLowerCase(),
        fontFamily: style.fontFamily, fontSize: style.fontSize,
        fontWeight: style.fontWeight, lineHeight: style.lineHeight,
        letterSpacing: style.letterSpacing, color: style.color,
        backgroundColor: style.backgroundColor, backgroundImage: style.backgroundImage,
        border: style.border, borderRadius: style.borderRadius,
        boxShadow: style.boxShadow, padding: style.padding,
        margin: style.margin, width: Math.round(box.width), height: Math.round(box.height),
      };
    }),
  );
  console.table(rows);
  return {
    viewport: { width: innerWidth, height: innerHeight, dpr: devicePixelRatio },
    colorMode: document.documentElement.dataset.colorMode ?? 'unset',
    rows,
  };
})();
```

先确认 `headings` / `actions` / `code` 各组实际非空；若本页结果不在默认 scope 中，应在 Elements 确认实际容器后调整，不能拿仅 body 的数据称为结果区采样完成。

`fontFamily` 是解析后的字体列表，不是逐字形实际使用字体的证明。在 Elements → Computed → Rendered Fonts 对结果标题、正文与 JSON 中的中文/西文分别核对实际字体；记录字体名称和字形数量即可，不上传用户生成正文。确认目标共同字体栈后再修改共享 typography 定义，避免引入大体积 Web Font 或只把宿主差异藏进变量。

### 实机验收要点

1. Scenario 结构化结果从标题到保存/导出位于同一个清晰 Surface；Web 通用编辑器没有双层卡片或重复 padding
2. 五页保存主操作、复制/下载次操作、取消/清除可区分；Tab 焦点可见，禁用按钮不可触发，亮/暗主题与减少动态效果可读
3. 每个结果只有一个 JSON 文件导出入口；Desktop 下载在 WebView2 中完成，内容/文件名完整，复制与文本模式保留；Web 浏览器导出不回归
4. 已恢复数据或仅含签名字段的数据不冒充已验证可信；标题调整不改签名计算、存储或生成请求
5. 每页保存失败保留结果、生成中取消/准备取消、确认重新生成仍走现有保护；自动定位设置继续有效，恢复历史结果不自动跳动
6. 截图覆盖五页同状态的 Web/Desktop、亮/暗、100%/125% 缩放，记录实际窗口宽度，不将 DOM 单元测试称为像素验收

## 自身环境限制

本轮独立自有云浏览器无法连接当前执行器的本地预览端口（`ERR_CONNECTION_REFUSED`）；受控内联夹具导航也被浏览器 URL 策略拒绝，已停止且关闭该标签及测试服务。没有改网络/浏览器安全配置、使用其他托管绕过策略，或把 jsdom 样式解析冒充真实浏览器字体证据。此前 AIP 的真实 Windows 验收不自动覆盖本轮视觉变化。
