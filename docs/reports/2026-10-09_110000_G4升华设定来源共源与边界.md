# G4 升华设定来源共源与边界

状态：实现与自动验证；Windows 本轮交互待验。基于 `09995348` 的后续有限切片，不代表完整 Arena/Strict/多人或所有云功能已交付。

## 本片

- Web 的 Lore 选择面板提为 `ui-web/sublimation` 的 `SublimationLoreSelection`，Web 与 Desktop 实际消费。共用预设列表、上传、粘贴、选择/移除/启停、原生许可提示和 Token 展示；宿主保留来源读取端口。
- Desktop 使用既有本地/公共卡库、公开缓存和内置预设资源，不增加 Native 命令或任意 Endpoint。没有账号仍可读取本地库；在线失败、缓存失效的行为由既有卡库端口负责，不伪装成空数据。
- 草稿新增可选 `selectedQuestionnaires`；旧草稿缺字段视为空集合，旧 `loreText` 保持补充输入兼容。Desktop 上传/粘贴/卡库导入保留原始来源快照及未知扩展（内置预设继续采用领域归一化定义，Web 未新增此快照机制）；损坏来源不默认为预设、不静默丢条目。恢复不触发模型。
- 客户端 Direct 使用共享 Lore 合成，勾选关闭不进入提示词，生成结果不取得原生签名。Hosted JSON/SSE 都传共享 wire，保留 `presetId`/`dataCardId`，上传及本地/缓存副本走 `upload`，不携带服务器身份。
- 结构化 Hosted 只有签名候选分支才按服务器预设或经授权数据卡回读，采用服务器正文与许可。线上数据卡需 owner 或 public+approved；失效/撤回/无权限会放弃原生资格，不让本地快照升级可信。流式生成路由沿现有契约使用传入正文而不做该原生来源回读，该路由自身与 Desktop 最终结果不签名；Web 对符合既有资格的非上传流式结果仍可能走独立重新签名接口，其最终可信性由该接口裁决。不能把“传 ID”说成“已验证来源”。
- Desktop 选取期间阻止重复派发；来源加载中不能清草稿或生成，卸载中止/丢弃迟到结果，账号切换使旧卡库回调失效。不同本地记录即使 canonical 问卷 ID 相同仍独立保留。

## 本片发现的旧 Web 问题

上传/粘贴 JSON 可声明 `nativeAllowed:true`，旧页面警告和流式重新签名条件只检查声明值。本片把上传来源显式视作非原生，修正展示与重新签名分支；服务端权威校验从未因此放宽。文件、粘贴和旧偏好恢复三条真实页面回归检查不调用重新签名接口。
