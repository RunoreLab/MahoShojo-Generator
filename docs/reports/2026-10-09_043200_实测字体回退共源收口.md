## 实现

- `packages/ui-web/src/styles.css` 唯一定义 `--app-font-sans` 与 `--app-font-mono`
- sans 保留 Web 的 Arial 西文优先，明确 Microsoft YaHei / PingFang SC / Noto Sans CJK SC / Noto Sans SC 本机回退
- mono 保留已有 ui-monospace、SFMono、Menlo、Monaco、Consolas、Liberation Mono、Courier New 顺序，在末尾 generic monospace 前加入相同中文无衬线回退。拉丁代码等宽语义保留，中文不承诺等宽
- Tailwind `--font-sans` / `--font-mono`、preflight、正文、code/kbd/samp/pre、表单继承和显式工具类消费同源规则；移除两个宿主及 Web blue-theme 的全局硬编码覆盖
- 不下载字体、不新增依赖、不改字体大小/行高、不改结果数据或导出、签名、生成、草稿机制

这是有限的可见排版变化：Desktop 西文正文回到 Web Arial，中文代码回退显式化；Web 非默认字体设置下的中文也可能改变。字体是否存在及 `ui-monospace` 在其他系统的实际映射仍影响字形选择，不能宣称跨系统像素完全固定。Emoji 保留平台字形回退；未强制将 emoji 变成文本字形。

有意保留的独立字体语义：CSS 加载前的 Desktop 启动屏、Web 装饰性 `.gc-card`、KaTeX、导出图案/模板及独立管理/OAuth HTML。这些不属于本次正文与 JSON 的共享运行时排版，不额外复制产品字体 token 到启动内联脚本。
