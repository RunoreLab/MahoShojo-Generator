# 分页直接跳转实施与验收

日期：2026-10-29

状态：已实现；验证范围见下文

## 范围与行为

新增共享 `PageJump`（`@mahoshojo/ui-web/pagination`），沿用现有页码、offset 和数据加载入口。输入页码仅修改草稿，点击“跳转”或按 Enter 后直接定位目标页，不遍历中间页。

| 入口 | 跳页方式 |
| --- | --- |
| 角色/情景等数据卡选择器：公开、我的、收藏、本地及已缓存视图 | 使用当前来源的已知总页数；线上直达目标 offset，本地/缓存切换已有数据 |
| 我的数据卡管理弹窗 | 复用已有受控分页回调 |
| 云端回收站 | 按 `filteredCount` 计算当前类型的总页数，直接查目标 offset |
| 服务器战报历史 | 使用服务端总数，并保持 `BATTLE_REPORT_MAX_PAGE` 上限 |
| 赛季排行榜归档 | 对筛选后的快照切页，不额外读取归档或实时榜 |
| 角色预设、情景预设、Web 包卡片网格 | 对本地已加载列表直接定位 |
| 魔法茶会会话列表 | 对当前列表直接定位，保留选择视图变更通知 |
| 牌组编辑器中的“我的角色卡” | 使用摘要 API 的 total 和 offset |

控件对空值、非整数、越界页码和当前页禁止提交；加载中禁用；外部翻页或总页数变化会清除旧输入。Enter 避免提交外层表单，并尊重输入法组合状态。页码错误时显示合法范围说明。只有一页时隐藏控件，分页栏允许窄屏换行。

实时排行榜和竞技排行榜弹窗目前只有 Top 300 范围、没有准确末页；游标型目录、房间发现、继续查找本地来源等需要前一页游标的入口，继续使用现有加载方式。公开卡片选择器总数未知时也不展示跳页控件。未为跳页增加扫描全表、预取中间页或新 API。

## 依据与复用

遵循 [双端视觉基线与工程契约规格](../specs/2026-10-19_215200_双端视觉基线与工程契约规格.md) 的 VIS-CSS-001/002、VIS-SHOW-001、VIS-A11Y-001 和 VIS-GOV-001。控件使用已有主题 token 和图标，Web/Desktop 共用，并在样板间操作控件分区展示交互态与禁用态。

未改变 wire contract、存储格式、权限、环境变量或部署配置。

## 实际验证

- 共享 UI 定向测试：8 个文件、159 项通过，覆盖页码校验、输入法组合事件、外层表单、外部页码变化、四来源直接跳至第十页、回收站筛选计数、战报页码上限以及既有预设/会话/样板间行为。
- Web 定向测试：6 个文件、28 项通过；牌组编辑器的请求 offset 严格为 `[0, 36]`，未请求中间页。
- Desktop 归档跳页回归：130 行快照直达第三页，归档请求仍一次，实时榜仅保留初始 offset 0 请求；实时榜无跳页输入。
- Desktop 战斗页及公开排行较大回归组：2 个文件、238 项通过、2 项可选平台验收跳过；新增归档跳页用例另行定向通过。
- `@mahoshojo/ui-web` build、lint，Web 与 Desktop `typecheck:build`、workspace boundary 检查通过。共享包 lint 保留既有可访问性 warnings，无 errors。
- `design-tokens`、`design-contrast`、`visual-showroom`：3 个文件、54 项通过。
- 真实 headless Chromium：375px 亮/暗下，输入草稿不翻页、Enter 跳至 88 页、拒绝 101 页、Tab 到按钮并 Enter 跳至第 2 页，均通过且无横向溢出。截图与结果保存在 `.tmp/page-jump-*-375.png` 和 `.tmp/page-jump-browser.json`。
- `review-visual` 样板间 6 档检查：亮/暗 × 1280/375、forced-colors、200% 根字号，fail=0。两档暗色各报告既有“浅色/深色”主题切换按钮的对比度 3.44:1 警告，未指向新增跳页控件；报告在 `.tmp/visual-review/report-2026-10-29T08-18-25-647Z.json`。

浏览器与模拟 IPC 结果不代表真实 Tauri/WebView2、物理输入法、读屏或生产服务验收；这些环境本次未测。
