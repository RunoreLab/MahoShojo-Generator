## 交付与实际共源

Desktop `/arena` 已接通普通四模式、结构化与 Markdown 流式 Direct 的高级单次旅程，使用与 `/battle` 相同的宿主/session/执行核。从简洁页的“高级单次配置”进入；两页分别持有活动 session 与固定版本化草稿 key，不自动搬移、覆盖或清除对方草稿。首页保持既有 Web 产品目录结构。

- 高级页框、完整 Header、双栏折叠工作区、Lore 与判定外壳、叙事历史编辑器来自 `@mahoshojo/ui-web/arena` 和 `narrative-history`。Web 真实页面和 Modal 同批回用这些控件；Desktop 没有复制近似表单或另写历史 UI。
- 角色/分队、主辅情景、素材、故事与历史读写设置、结果与推理展示沿已共享控件。新增辅助情景使用既有 scenario capabilities；预设、本地库、公开/缓存与文件端口留在宿主。
- Lore 使用现问卷 domain/content、CardLibrary host 与 G4 的 Desktop 来源保真/授权清理 seam。预设、本地/公开副本、上传和粘贴可作为参考设定，并支持启用、排序、详情与移除。关闭 Lore 的来源保留在请求快照中并标记 `useLore:false`，实际提示词不注入其正文。
- 历史导入归一化、V1 卡封装、不可变更新、问卷请求投影与判定 source 规则成为共享 domain 出口；Web store 和实际 hooks 回用。旧 key/version/migration/hydration、Web quickCheck 与云保存仍由原宿主负责，不移入共享视图或 Desktop。
- `/arena` 仅开放上述单次能力。服务器选择明确不可用且不回退 Direct；系统服务器目标仍不能冒充客户端执行。Web 格式、连续故事、插图、Strict、排位、多人、线上随机匹配及占位角色均未开放。

## 来源、历史与保存边界

手动事件与角色、主情景、辅助情景的继承事件在活动草稿中形成可编辑列表；素材和 Lore 内的事件不提升为执行输入。生成时直接冻结该列表，不重新继承已被用户删改的事件。一次请求只调用一次现役共享 resolver，重绘、保存、重复点击不重掷；结果明确为本地判定，不能构成服务器权威。

来源沿 card ID、文件名、标签的既有优先级；非空有效事件按全局同 key 替换，空事件和 legacy 格式保持 early-return，移除/切换来源仍按全局 key 清理，不引入引用计数。高级文本导入按“导入前 roster 文件名集合”跳过重复角色并提示，仍处理其来源事件；原角色正文不被替换，同一新批次内部的旧重复规则不变。库/预设和 `/battle` 不套用新增文本过滤。Web 纯抽取保留既有调用参数，包括旧文本回调可能用 label key、角色自身用 file key 的历史差异；本片没有顺手改写该 Web 行为，Desktop 显式绑定已确定的来源 key。

活动历史使用原始 entry ID，显示排序只排序视图，显式 AI 顺序操作才改变提示词顺序。新增、编辑、删除、清空、追加与覆盖导入均使用共享规则；放弃未提交正文、覆盖和删除需要明确确认。

导入原文与规范投影分开：原文包含未知字段、空白和多卡数组，留在 `historyOriginals` 并通过“导出当前会话”完整导出；编辑及另存 history 卡使用规范活动 entries，不宣称归一化保留了所有原字段。G4 聚合 picker 仍只读引用，不把临时显示 ID 写回源卡。

历史默认关闭生成后追加；开启后只有合格 completed/stop 结果追加活动草稿。保存 history 卡与 unsigned 角色副本分别显式触发，源卡不覆盖。混合手工/导入/多次生成的高级 history 卡不填单一 `unsigned.execution`，战后角色副本保留其确定执行模式。完成时间和候选固定，内容 ID 与 `putIfAbsent` 保障保存重试，existing-wins 不复活墓碑。

所有新增暂存和在途状态纳入页面唯一关闭守卫；普通 AI/账号 scope 变化不直接清空历史编辑器的未提交正文。迟到导入返回 cancelled 并保留原粘贴，不能据卸载或关闭模态假称写入已撤销。高级模式切换若会关闭带未提交文本的情景编辑，需要确认。

## 预算与失败恢复

没有新增数据库、聊天库、Native 能力或生产依赖。保留原业务 12 MiB、decoded text+reasoning 4 MiB、32 角色、256 总参考项和模式最少 2/2/1/1；辅助情景、素材、问卷与实际读取的历史共同计数。草稿 4 MiB 字符、本地卡完整封套 4 MiB 字节不变。

损坏/未来草稿保护、显式恢复、未配置时可编辑、guard 初始化失败时封锁未保护输入，以及取消/EOF/失败无历史副作用沿同一 session。原文归档导致草稿超限时，旧存储不被覆盖，内存内容仍可完整导出；历史规范投影可另存并不表示原文归档已经落库。磁盘或封套超限仍明确显示保存失败，不截断数据或要求重新生成。

## 待验与后继

Windows/WebView2、真实 Tauri IPC/OS 凭据、真实模型内容质量、文件对话框/下载、主题/布局/缩放与完整视觉交互继续待集中实机验收。本片未调用真实模型、输入真实 Key、使用用户设备、发起付费任务或云写入，未生产部署。
