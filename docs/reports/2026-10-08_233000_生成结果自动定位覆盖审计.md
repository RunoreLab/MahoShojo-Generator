## 统一契约

`@mahoshojo/ui-web/details-controls` 的 `useGeneratedResultAutoScroll(ref)` 返回 `begin(request, signal?)`；在既有生成意图获准后调用，得到该请求的预览通知。仅真实正文/有效卡片首次可预览时通知，不把占位、reasoning、原始 HTML 或服务器晚到的 generationId 当新结果。新请求替换滚动闩锁，旧请求通知与 abort 后通知无效；生成、取消、恢复仍由既有 owner 管理。`notify.cancel()`仅撤销该请求尚未执行的定位，供失败时实时预览被移除的宿主使用，不触发业务取消。

结果容器的 ref 应在首次预览所在的 DOM commit 已挂载，不能指向 display:contents 或不可见的占位。共享决策在 commit 后测量：仅结果整体在视口下方时定位，已经可见或滚过不拉回；流式后续与完成不重复；读既有设备偏好，减少动效使用 auto。关闭时消费通知，重新打开只影响下一次结果。不会主动聚焦、滚动到流式底部或修改浏览器历史。

Desktop 已有卡片生命周期沿用 `useResultAutoScroll`，使用通用 session 的 `resultRestored` 排除恢复卡；该 session 已在 controller signal 层拒绝取消后完成卡。两种入口共用同一几何/偏好/动效决策。

## 验证与边界

- 共享 hook 行为覆盖：首次预览/重复分片、新请求替代、取消/已排队取消、开关不追溯、已可见/已滚过、减少动效、恢复卡
- 实际长篇生成 hook + 真实 SSE reader 覆盖：占位/reasoning 不滚、首正文一次、终态不重复、新请求再次定位、恢复/选旧章不滚、取消不滚；同批正文+失败 done 在有/无旧章时先红后绿，撤销导航但不 abort 请求或写入失败章节
- Sublimation 真实页面覆盖：导入/恢复不滚、重复生成、首正文/终态、停止后迟到正文、失败、可见位置、减少动效、关闭偏好
