## 范围与共同来源

本片遵循 Desktop 产品共源 ADR、D5.1-T 逐工具旅程计划及双端共源切片指南。现有 Web 工坊可编辑的是主题色、插图比例及裁剪，不存在完整名称/数值/效果字段表单；本片保持这个边界。

- `packages/domain/src/card-forge-document.ts`：既有 forge v1 / 旧版 metadata / 直接 face JSON 解析、创建、序列化；Web 原路径真实 re-export
- `packages/domain/src/game-card-image-crop.ts`、`game-card-presentation.ts`：既有裁剪算法、比例与呈现常量；Web 真实回用
- `packages/ui-web/src/card-forge/`：原 `GameCardFace`、`ImageCropEditor`、主题色区段及整段工坊样式；Web 页面使用共同实现，Desktop 使用相同控件/卡面
- Web wrapper 继续注入 `WEB_SNAPDOM_MEDIA`；Desktop 注入 `DENY_SNAPDOM_MEDIA`、本地下载、受限画布 capture 与打包的 `/logo-white.svg`（既有 content 同步清单已包含）
- Desktop `/card-forge`：本地 JSON 导入 → 卡面预览 → 主题色/本地插图裁剪 → PNG、内嵌插图 forge JSON、原始 JSON 三个独立出口

未迁移 AI 转换、ModelScope/立绘、云卡库、媒体 SQLite 或新草稿仓储。无新 provider、secret、native command/权限及生产部署变更。

## Desktop 媒体边界与合理差异

旧版 `metadata.imageUrl` 接受任意字符串；Web 仍保留原能力。本地片必须在任何预览 `img` 建立前检查，不以截图时的 DENY 策略代替预览限制：

1. 远程 URL、相对路径、`file:`、文档携带的 `blob:`、SVG 或其他不支持类型不加载、不 fetch、不走媒体代理；仅将原件保留并提示选择本地图片
2. 支持静态 PNG、常见 JPEG（SOF0/1/2）与 WebP；文件声明不能代替真实 raster 签名，内嵌 Data URL 的 MIME 必须与签名一致。拒绝识别出的 APNG/动画 WebP；不承诺全部历史 JPEG 变体兼容
3. 图片头部验证后才进入浏览器解码；解码完成再次检查实际宽高。解码失败/超时不替换当前卡面
4. 10 MiB 图片硬上限参考既有 Web 10 MiB 软提醒，但仅适用于 Desktop 本地宿主；16 MP 限制单张 RGBA 解码约 64 MiB，单边 8192 限制异常长边。不是全进程内存保证，也不收紧共享卡面字段契约
5. 原始 JSON 和最终格式化 UTF-8 JSON 均最多 32 MiB，可容纳 10 MiB 内嵌图片 Base64 与卡面。复用 `SafeJsonValueSchema` 的 64 层/10,000 节点及危险键拒绝；超限显式失败，不截断
6. PNG 前以导出展开后的 DOM bounds/scroll geometry × 实际 scale × DPR 检查 16 MP / 8192 画布预算；过大不悄悄降画质，继续允许 JSON 出口

## 原件与规范文档不混称

原始文件以 `Uint8Array` 保留并单独下载，不经过 schema、安全投影或 JSON 重序列化；BOM、空白及所有未知字段逐字节保留。失败导入不会覆盖已有来源。

规范 forge JSON 沿用共同 schema：face 顶层 catchall 扩展保留，但效果条目中 `type` / `description` 以外扩展字段会被既有 schema 剥离；legacy 外层 `sourceCardData` / `sourceCardType` 等不属于 forge 文档。未加载图片不进入新存档。界面明确提示这些损耗及原件出口，不宣称所有 unknown 字段无损。未来若要规范文档也保留嵌套 effect 扩展，须以共同文档投影独立修订并让 Web 回用，不在 Desktop 建另一套 overlay。

## 生命周期

- 导入/解码/导出单飞；新来源覆盖未导出编辑前确认，错误保当前卡面/原件
- 主题色/裁剪/换图/移除图均标记未保存；共用既有 route、beforeunload、native close 守卫。在途操作不能通过确认绕过
- 下载 API 只能知道下载发起，不能知道系统保存/取消。因此 JSON 下载后仍保留 dirty 提醒；PNG、原件出口亦不清除编辑状态
- 共享卡面捕获有同步重入锁与宿主交叉操作 veto，RAF/捕获/分享失败后的晚到结果不能在卸载后下载、弹窗或回写旧 busy 状态
- Desktop Blob 下载沿用 60 秒延迟撤销；未新增文件系统权限

当前环境已有 Chromium 本机 socket EPERM / 升级拒绝记录，本片不绕过。jsdom 控件与 capture adapter 测试不是实际浏览器截图，更不是 Windows WebView2 验收。真实图片解码/PNG 像素输出、触控/鼠标裁剪、窄屏/深浅色/高 DPI、文件对话框与保存取消、原生窗口关闭仍集中待验，不阻断后续独立开发。没有新增 SQLite 写入，故本片不宣称媒体数据库验收。
