# 自动审核完整输入与免费模型评估

核验日期：2026-11-22。本文记录一次技术调研及合成样本评估，不是规范性文件；模型价格、可用性和服务端行为可能变化。

## 问题与实现

原自动审核复用了管理端摘要提取，限制单个字符串、数组项数和总长度；正常数据卡也可能在送入模型前丢失正文。输入覆盖不完整会使结果难以自动处理，并非都由模型上下文不足造成。

本次实现从 `data` 的完整 JSON 构造审核正文，附上名称、简介和类型；不再按原摘要阈值截取字段或数组。正文大小仍遵守数据卡既有上传上限；无法解析、完整序列化或找到可接收完整输入的渠道时留待人工。上游报告输入过长或截断时尝试后续后端，未能取得完整结果时也留待人工。

模型路由仍有一项有意保守的过渡限制：针对目前无法确认是否静默截断的后端，只在旧版总长度范围内发送完整内容，超过时尝试经过长输入验证的渠道，均不可用则留待人工。这个 12,000 UTF-16 单元阈值是应用侧保护值，不是模型的已知上下文上限；配置合适的长上下文后端才能让更长内容自动审核。

Cloudflare 对 [Clef Flash](https://developers.cloudflare.com/workers-ai/models/clef-flash/) 的文档说明其文本 `state` 会被截断以适应上下文；[OpenRouter 模型索引](https://openrouter.ai/for-ai)另有较小的路由限制说明。二者表述不一致，代码对该渠道采用更保守的 UTF-8 字节检查；这不是精确 token 计数，也不是对服务商上限的承诺。

## 模型核验

经 OpenRouter 的模型列表和免费路由核验：`perplexity/pplx-decider-v1.3:free` 与 `perplexity/pplx-decider-flash-v1.3:free` 当时显示免费、262,144-token 上下文；`respan/span-01-lite` 可用；`inception/mercury-decide:free` 在该列表中缺失，实际 decisions 请求返回 HTTP 404。该 404 只能证明所测接口和时点不可用，不代表所有服务商均已停用。参考 [Perplexity Decider V1.3 模型页](https://openrouter.ai/perplexity/pplx-decider-v1.3:free)及[模型作者说明](https://huggingface.co/perplexity-ai/pplx-decider-v1.3/blob/main/README.md)。

仅使用人工合成数据，向每个候选发出 13 次 decisions 请求，题目使用仓库 `AUTO_REVIEW_JEV_QUESTIONS_V2`。其中六例为正常内容、六例为违规内容，另有一例约六万中文字符并把违规标记放在末尾。三种模型均返回了九道有效答案，且发现长样本末尾标记；39 次成功响应均报告成本为零。

下表为统一比较口径：七个违规类别分数取最大值，至少 0.5 为拒绝，小于 0.2 为通过，其余待审。该脚本没有调用仓库裁决函数，也没有记录 Span 的 `should_pass`；Span 的生产专用阈值和 veto 与此不同。故该表既不是线上错误率，也不是现有 Span 策略的实际分流结果。

| 模型 | 通过 / 拒绝 / 待审 | 六个正常样本的误拒 | 六个违规样本的漏放 | 单次耗时 |
| --- | --- | --- | --- | --- |
| Perplexity Decider V1.3 免费版 | 6 / 7 / 0 | 0 | 0 | 463–2677 ms |
| Perplexity Decider Flash V1.3 免费版 | 3 / 8 / 2 | 1 | 0 | 374–1133 ms |
| Respan Span-01-lite 免费版 | 7 / 6 / 0 | 0 | 1 | 915–2267 ms |

对 Perplexity V1.3 免费路由另做一次 520,000 个合成汉字的超上下文请求，服务返回 HTTP 400 并报告超过 262,144 tokens，没有返回 usage。该探针表明当次请求被明确拒绝，不能保证未来所有路由或模型版本均如此。合成样本仅用于筛选候选，不足以校准生产阈值或证明真实数据误判率。

另使用仓库实际自动审核引擎和 V2 问题集作端到端合成验证：正常卡获得 `approve`；约 20,000 字符、违规标记位于尾部的卡获得 `reject`；两次覆盖信息均为完整，响应 HTTP 200 且各自报告零费用。

综合当前评估，优先建议使用 Perplexity Decider V1.3 免费路由作为长输入候选，并保留经实际验证的免费后备渠道；Flash 对非露骨成人恋爱存在一次误拒，应谨慎评估；停用经实际确认失效的 Mercury 免费路由。正式调整须核对实际生效配置、凭据、模型专属阈值、路由次序及回滚方式，不能仅凭历史审核记录推断完整配置。

## 验证与剩余事项

本地测试覆盖完整字段、长数组、深层结构、字节上限、上游长度错误、静默截断风险渠道回退，以及新卡和更新卡在覆盖不完整时保持待审。实际线上部署状态和模型配置应以发布记录与 Worker 配置核查为准；本报告不包含凭据、真实卡片或用户身份。

历史待审内容不会因本次代码变更自动回填或重审。自动审核依然可能出现分类错误、免费额度变化、模型下架或上游不可用，调整模型和阈值后应持续检查实际待审量、误判及回退情况。
