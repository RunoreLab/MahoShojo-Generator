## 交付范围

新增 `@mahoshojo/hosted-api/arena-generation/client` 显式 client-safe 出口，将既有 create-once、未知首次结果 lookup、GET resume、完整 SSE cursor 去重、连接状态和有界恢复编排迁出 Web 文件。实际 Web `openArenaGenerationStream` 仍由原 `useBattleEngine` 等消费者调用，认证、actor 头、storage key/version/body-scoped identity、请求路径与路由选择保留在 Web adapter。

共享核只导入既有 `sse.ts` 纯解析。transport 只有 create/lookup/resume/cancel 四种操作及公开 request/generation/cursor/pin 信息；不接受 Cookie、Provider Key、actor token、任意 URL/header/body，不默认发网络请求或读取浏览器存储。Web 标准 Response/ReadableStream 是中性载体。合成 Native-shaped consumer 验证接口可实现性，未增加产品 Native/IPC/目标/权限。

取消保留现 primary-only 独立 generation intent。没有宣称修复“第二次 probe 改路由”：现生产策略本就不对该操作 probe。202 仍表示停止请求已受理；普通 reader.cancel 仅断订阅。未知创建只查找，不再 POST，不换目标。
