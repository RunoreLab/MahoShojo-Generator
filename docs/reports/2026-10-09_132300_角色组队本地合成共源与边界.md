# 角色组队本地合成共源与边界

日期：2026-10-09
施工归属：[唯一 Desktop 计划 D5.1-T](../plans/2026-09-30_160100_Desktop客户端阶段实施计划.md)
规范依据：[产品共源 ADR](../decisions/2026-10-02_184000_Desktop产品架构与Web共源决策.md)、[双端产品规格 DESK-PARITY-006](../specs/2026-10-06_084200_双端产品对齐与设置共源规格.md)

## 交付范围

Desktop `/character-party` 接通本地卡库/JSON 文件/粘贴 → 队员排序与标识 → 输出模板 → 实时合成预览 → 未签名本地另存/JSON 下载。原角色不会改写，无 AI 请求、云保存、随机匹配、签名能力或多人功能。

- `domain/team-merge` 从 Web 原 `lib/team/merge-team-cards.ts` 提取，Web 原入口真实重导出；转换至通用卡仍经过原有 `parseDataCardByTemplate` 门禁
- `ui-web/team` 从 Web 原页面提取队员表格、命名、移动/移除/清空、模板选项、结果标题和 JSON 区，Web 原 controller 实际消费；原在线库、验签、重签名、云存、立绘继续由 Web 持有
- Desktop `party-page.tsx` 注入已有 `IpcLocalCardRepository`、`saveImportedUnsignedCharacter` 和文本下载端口；不增加 native command、权限或存储表。真实共享角色卡组件承担可预览结果；不满足完整卡面字段时保留 JSON 预览
- 本地库沿用已有只读分页/最新单卡读取和失效选择令牌；较晚返回的选卡不能覆盖更新的文件/粘贴/编排操作

## 兼容与损耗

合成是有损拼接，不是结构无损迁移。沿用 Web 既有语义：同模板字段递归合并，标量数字/布尔变为带队员标签的字符串；数组按队员顺序展开，对象数组前缀第一个 title/name/label；不同模板转通用卡。纯核原有对 signature/isPreset 的字段处理继续保留，不在本片重设计。

输入原始对象与合成投影分开。Desktop 仅从合成输入的顶层移除 signature、isPreset、_native、_isNative、isNative，不把整个下划线扩展类别删除；任意嵌套同名字段不自动成为来源权威。保存记录 provenance 固定 unsigned/imported，输入签名不授予官方/原生/排名资格。

“另存队员源 JSON”下载按当前顺序排列的原始对象数组，保留源签名及未知扩展；这是数据归档，不是验签。它保留 JSON 数据而非原文件字节/空白。总源数据可达到 3 MiB，但单次重新导入上限是 1 MiB，因此大源数组不保证作为单个文件直接往返；可按角色拆分后导入。本片不新增归档协议。

## 有界输入、预算与生命周期

- 单文件/单次粘贴最多 1 MiB，文件读取前后都检查；使用既有 SafeJsonValueSchema 拒绝危险键、过深或过多节点
- 队伍最多 32 个角色，源 JSON 总量最多 3 MiB；文件批次逐个读取且全批校验后才添加，任一失败原队伍/粘贴内容不丢
- 名称不截断。合成前按源字节、节点数及实际队员标识（含空标识时的原名回退）计算保守预算，先拒绝前缀反复展开的资源放大，再进行合成；最终结果再次检查 3 MiB 与安全 JSON 结构。预算是保守上界，不承诺所有实际小于上限的组合都能通过
- 超预算保留源队伍，允许缩短标识、移除队员或另存完整源 JSON；不先生成巨串再仅依赖输出门禁
- 保存/下载/文件导入单飞，忙碌时编排禁用，离开/窗口关闭复用现有守卫。保存失败保留结果可重试；相同内容使用 putIfAbsent，不覆盖旧卡或复活回收站条目
- 页面状态仅在本次挂载内，尚无队伍草稿自动持久化；用户离开前应另存结果或源 JSON。实时本地拼接不产生 AI 任务，也不在每次编辑后滚动页面

## 验证

自动测试覆盖原 Web 三个合并例、标量/数组顺序和非变异、未知扩展/顶层来源标记、非法与超限输入、14 KB 输入导致约 10 MB 输出的前缀放大（含清空标识回退）、实际控件编排/模板、原子文件批次、迟到本地库选择、库错误、失败后重试和保存单飞。

Web 页面测试通过真实共享控件编排后继续调用原 verify-origin/resign-data；Desktop 页面测试实际走合成、已有 IPC insert-if-absent document/provenance 和 Blob 下载，并断言无网络请求。

最终全量/构建门禁结果在收口时补记。Windows Tauri/WebView2 文件/下载对话框、SQLite 真机写入与重启、IME/焦点/键盘、关闭保护、高 DPI/窄屏视觉仍待集中实机验收；自动 DOM 与 mock IPC 不替代这些证据。

## 回滚与延期

撤回 Desktop 路由与能力声明即可停止入口，不删除本地卡库数据；Web 可独立保留共享纯核/控件。编辑器/工坊继续按唯一计划拆片，茶会会话、在线 Arena、Strict、多人与本片无关。此次不部署、不发布安装包，也不以源码完成关闭实机待验项。
