# 模型选择器页面抖动修复

日期：2026-10-28

适用：Web 与 Desktop 共用的 `AiProviderCustomSelect`

## 问题与根因

用户报告生成期间页面反复上下回跳，并确认打开模型菜单后滑动即可触发。检查当前共享组件并以修复前源码构建真实浏览器夹具后，Edge 156.0.4314.50 复现：用户将页面滚到 `scrollY=932`，连续宿主更新后又被拉回 `721`，回跳 211px。

直接原因是菜单对活动项调用 `scrollIntoView({ block: 'nearest' })`，定位会影响菜单外的滚动祖先。该 effect 依赖 `navItems`，默认 `actions=[]` 每次创建新引用，宿主更新时重建 `options/actions` 也会重新触发。鼠标悬停改变活动项则进一步触发定位。旧版菜单底部继续滚轮还会带动背景页面（本地观测 `232→657`）。

Arena 的结果导航另有每请求发布一次及共享 hook 单次通知保护，本次不修改生成生命周期、结果首次定位、取消或恢复协议。它们不能解释打开菜单后的持续回拉。

## 修复范围与依据

- 共享选择器只调整菜单自身的 `scrollTop`，以菜单 client 区域与选项实际矩形计算最小位移，兼顾边框和单项高于菜单的情况。
- 打开菜单与键盘导航显式携带定位请求；悬停只高亮，普通重渲染不重新定位。重复 Home/End 仍可把活动项带回菜单可见区。
- 默认空动作列表使用稳定常量；目录/动作换引用及等总长但选项/动作分界变化有回归覆盖。
- 菜单使用 `overscroll-y-contain`；菜单内滚动到边缘不继续滚动背景，菜单外仍允许页面滚动。焦点还给触发器时使用 `preventScroll`。
- 更新共源样板间的表单分区，用生产组件展示长列表、分组、动作区及持续模拟状态更新。

依据：[模型选择器规格 DESK-AIP-002/009](../specs/2026-10-08_173400_DesktopAIProvider共源选择器、快速配置与多模型连接.md)、[视觉基线 VIS-CSS-002 / VIS-SHOW-001 / VIS-A11Y-001](../specs/2026-10-19_215200_双端视觉基线与工程契约规格.md)。复用现有共享选择器、主题类和 Escape 层级栈；无需新增依赖、环境变量、持久化迁移或部署配置。
