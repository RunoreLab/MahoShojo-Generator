## 交付范围与实际共源

Desktop 只登记真实 `/battle` 路由；`/arena` 完整版仍未开放。四种普通模式使用相同 Web 领域核，接入预设与自定义 Direct 目标、结构化与 Markdown 流式输出，选卡、故事配置、执行、取消、结果、显式本地另存和完整 JSON 导出。未配置 AI 时输入仍可编辑；服务器选择明确不可用，不回落到 Direct，也不把系统服务器目标当作本机模型。

- `apps/desktop/src/app/battle-page.tsx` 仅负责宿主 ports、选择/导入与 session 绑定，实际页框、hero、角色/分队、情景、素材、故事、历史设置、预设及结果卡来自 `@mahoshojo/ui-web/arena`、`arena-report`。Web 同批实际回用原控件与结果内容，没有另一套近似表单或战报 UI。共享视图边界见[受控视图报告](./2026-10-09_230700_Battle页面受控视图与宿主边界.md)，资源与字节保真见[预设资源报告](./2026-10-09_230000_Arena预设资源共源与字节保真.md)。
- 预设清单与原件来自共享 domain/content；本地库、在线公开卡和离线缓存复用既有 CardLibraryModal/host。共享纯角色解析保留旧结构兼容和万途转换；警告仅在当前 scope 成功导入后展示。本地/缓存原卡不因加载获得服务器签名资格。
- `domain/arena-adjudication` 提取当前 Hosted 正在执行的 resolver，Hosted 保持原随机源；Desktop 在请求冻结时只掷一次本地随机并冻结结果。继承角色与主情景事件，材料内事件不执行。结果与 UI 明示本地判定不构成服务器权威。
- Hosted、Web 格式、连续故事、插图、Strict、多人及完整版的操作不在本页冒充已交付，Web 既有能力继续保留。

## 会话、保存与预算

`features/arena/session.ts` 是独立 Arena owner，不伪装 generic card family 或 Hosted route。每次冻结输入、执行模式、模型/目标、requestId、generationId、时间与判定；同步锁阻止重复派发，账号/配置世代与 AbortSignal 围栏阻断取消或旧响应的副作用。只有匹配原 scope、明确 `completed/stop` 且有效的结果进入共享战后候选纯核。EOF、失败、取消与晚包保留已收到正文/推理，不追加历史或修改工作角色。

历史读写沿实际 Web 默认与工作副本语义：

1. `writeNarrativeHistory=false` 默认关闭；开启后合格完成只追加当前活动草稿历史。保存为本地 history 卡仍由用户显式触发，不自动写卡库。
2. 角色历史与当前状态默认开启；合格完成更新当前 roster 的 unsigned 工作副本，源卡库记录保持不变。角色另存与完整 history 卡另存分离。
3. G4 历史 picker 的聚合临时 ID 只用作提示词引用，不回写原 history 卡，也不混入活动历史去重。
4. 首次完成的时间与 generationId 固定；保存通过内容派生 ID 与 `putIfAbsent` 重试，existing-wins 不复活墓碑。磁盘失败或单条超限显示失败，原文留在内存，可再次显式保存或完整导出。
5. 草稿沿现 localStorage/唯一离页及原生关闭 guard。版本、损坏、未来版本和过大旧草稿受保护，必须显式恢复/清除。恢复原文不会重放旧生成或角色候选；已知 remote 来源保持 remote，旧草稿缺失来源则不捏造 local 执行。

没有新数据库或聊天存储。保留原业务 12 MiB 请求、4 MiB decoded text+reasoning、32 角色、256 参考项与模式最少 2/2/1/1；本地卡完整封套为 4 MiB 字节、草稿为 4 MiB 字符，不扩大全局预算，不裁截完整生成数据。生成成功与保存成功是两个状态。

共享暂存粘贴、未提交分队名和 AI 连接编辑均接入页面唯一关闭守卫；在途导入/保存不能伪装成已撤销。报告媒体默认拒绝外链，模型生成的链接只经过既有内容链接策略（默认确认）和 Native URL 边界，不直接导航 WebView。
