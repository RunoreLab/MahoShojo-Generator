## 6. 网络边界单列观测

现 HTML CSP 只有 `sandbox allow-scripts`，**不能预设“所有网络被拒”**。在包窗由明确按钮仅探测自己持有的 loopback HTTP 服务：fetch、图片、CSS/脚本、WebSocket；记录服务端收包与 WebView Network/CSP/CORS/错误。主窗固定项目 API 到 loopback 的流量与包窗子资源分开归因。

- 测试请求只含固定合成 marker，不含包之外的内容、cookie、凭据或用户信息；服务端只记方法/路径/时间，不记敏感头
- 不向第三方、公网或局域网他人地址发包；不为测试改 hosts、DNS、证书信任、VPN、防火墙或浏览器安全参数。不能通过自签名警告时停止该项
- HTTP/loopback 当前可达与否是事实结果，不是批准长期放行。HTTPS、private-network、DNS/WebSocket策略没有完成真实覆盖时逐项列缺口；顶层 on_navigation 被拒不能推出子资源已封
- 若发现包可触达宿主凭据、任意文件/库、其它 instance 或 Native command，立即停止执行分支并回报；一般子资源网络可达按未冻结策略记录，不擅自改Native权限或把测试结果当策略决策
