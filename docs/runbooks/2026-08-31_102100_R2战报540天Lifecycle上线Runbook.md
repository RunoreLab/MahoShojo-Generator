## retention 决策

官方现行 Standard 免费 storage 为 10 GB-month。默认账户安全余量 1 GB-month，因此规划 ceiling 为 9 GB-month。

当前 runtime 权限无法查询其他 bucket，故：

```text
chosen_retention_days = 540（软件与运维候选）
production_write      = BLOCKED，直到 O_other 与现有 Lifecycle 被管理权限读回
```

540 天按已观测日峰值和一天删除延迟推演：

```text
14,340,672 × 541 = 7,758,903,552 bytes ≈ 7.76 GB
```

该值低于 9 GB ceiling，并在 battle-report 预算内保留约 1.24 GB 波动空间。730 天按同一峰值约 10.47 GB，超过 ceiling；365 天约 5.25 GB，明显少用可用容量。因此在账户其他 R2 使用可容纳于剩余空间的前提下，540 天是当前最大合理档位。

## 管理权限盘点

需要 `Workers R2 Storage Read` 读取账户/bucket，写规则另需 `Workers R2 Storage Write`。凭据只通过 operator environment 注入，不写入仓库或命令历史。

```bash
pnpm --filter @mahoshojo/web exec wrangler r2 bucket list
pnpm --filter @mahoshojo/web exec wrangler r2 bucket lifecycle list mhsj-r2
```

还需在 Dashboard/GraphQL 记录最近 31 天的 `payloadSize`、`metadataSize`、`objectCount`、`uploadCount`、Class A/B，并计算账户其他 Standard storage `O_other`。

若 `O_other + 7.76 GB > 9 GB`，必须下调 retention；不得无观测地写入 540 天规则。

## 写入与 read-back

规则 ID：`arena-battle-reports-expire-v2`

prefix：`v1/battle-report-generations/`

不配置 IA transition。

```bash
pnpm --filter @mahoshojo/web exec wrangler r2 bucket lifecycle add \
  mhsj-r2 \
  arena-battle-reports-expire-v2 \
  v1/battle-report-generations/ \
  --expire-days 540

pnpm --filter @mahoshojo/web exec wrangler r2 bucket lifecycle list mhsj-r2
```

read-back 必须精确证明：rule ID、prefix、540 days、enabled 且没有 IA transition。若同 ID 或 overlapping prefix 已存在，不得叠加；先人工核对并使用完整配置更新流程。

## 上线后观察与回滚

至少观察 R2 storage/object count、Class A/B、GET 404/5xx、personal regenerate 409/502、D1 新 preview、Redis memory/eviction 和 Hono terminal unavailable。

Lifecycle 生效后，既有对象也会进入规则；通常在 expiration 后约 24 小时删除。对象删除后不可恢复。发现错误时可移除规则阻止未来删除：

```bash
pnpm --filter @mahoshojo/web exec wrangler r2 bucket lifecycle remove \
  mhsj-r2 \
  --name arena-battle-reports-expire-v2
```

撤销前后均需 `lifecycle list` read-back，并保留规则与时间证据。
