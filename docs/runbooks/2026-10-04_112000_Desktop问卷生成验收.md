## 当前交付

默认 16 题问卷离线打包，问卷控件和角色正文由 Web/Desktop 共源。配置 OpenAI-compatible Provider 后明确发送 Direct 请求，完成后可保存 unsigned 角色卡。其他问卷类型、在线问卷、云存档及数据卡签名未接入。

草稿由页面会话持有，在 WebView localStorage 中保存回答、语言、结果和部分正文；恢复需明确点击，不恢复上游请求。流式正文即时显示，草稿按 1 秒窗口合并写入；终态、手动取消、确认离开/关闭或卸载时刷新待写内容。异常退出仍可能丢失最后一个落盘窗口内的正文，不承诺断电耐久性。4 Mi 字符总量上界或存储失败会提示并保护当前页面。生成与保存互斥；生成中内部导航/原生关闭需确认终止，拒绝则继续，保存中或草稿写失败仍阻止离开。刷新使用系统离开确认，实际卸载时取消；清除草稿有二次确认。

成功但未保存的结果再次点击“重新生成”时，弹窗提供“取消”“保存后重新生成”“确定重新生成”；只有明确放弃或本地保存成功才发送新请求。保存失败保留结果与弹窗，不调用 AI；已保存或卡库已存在相同内容时可直接重新生成。Desktop Direct 默认不设应用层连接、空闲或总时长硬超时，用户可终止，系统网络错误及 Provider 自身限制仍有效。

只有保存到 SQLite 卡库的角色参与 portable archive 和整库备份。问卷草稿、未保存结果和部分正文不在其中。重复保存不覆盖现有记录或恢复墓碑；回收站界面尚未交付。

## 实机记录待填写

以下各项均为 **待验**，自动化模拟不等同于实机通过。使用专用测试库；不要将 API key、完整私人问卷或凭据写入记录。

| 项目 | 操作与预期 | 当前证据 |
| --- | --- | --- |
| 无配置离线编辑 | 断网冷启动，首页进入问卷，填写/切题/返回，再进入后明确恢复；无项目请求 | 待验 |
| 草稿恢复 | 关闭重启后恢复回答和结果；取消恢复不自动发送；清除需确认 | 待验 |
| Direct-local | 真 loopback 端点完成生成；显示本机接收方；结果未签名 | 待验 |
| Direct-remote | 真公网端点完成生成；显示外部接收方；仅主动请求该 Provider | 待验 |
| 取消与异常 | 等待响应头及流中取消；模拟截断/格式错误；保留已接收正文且不自动再发 | 待验 |
| 长生成与 UTF-8 | 本机慢模型超过原 180 秒仍可继续；中文/日文/emoji 流无分块乱码或误报；手动取消结束上游 | 待验 |

| 流式响应性 | 长正文持续显示，IME/交互可用；取消或离开后恢复最近正文；异常退出仅保证已落盘部分 | 待验 |
| 本地保存 | 保存后重启并导出卡库；相同结果不重复、不覆写或恢复墓碑；失败可重试保存而不再调用 AI | 待验 |

| 产品表现 | 亮暗主题、键盘、IME、高 DPI、减少动态效果；问卷及结果可读可操作 | 待验 |
| 双层网络 | 记录 renderer 与 native 出站：编辑/恢复/保存无项目请求，生成仅访问所选 Provider | 待验 |
