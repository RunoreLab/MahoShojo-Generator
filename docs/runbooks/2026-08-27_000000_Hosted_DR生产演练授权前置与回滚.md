# Hosted DR 生产演练授权前置与回滚 Runbook

状态：`OPTIONAL / ARCHIVED / authorization-required`

适用范围：未来在新的 accepted ADR、预算和生产授权下，重新引入 Cloudflare Load Balancing 或等价 managed control plane 后，对 stable endpoint、Hono primary、Next/OpenNext DR 和生产依赖进行演练。

当前默认路径已经由 [低成本 Hosted DR 与客户端预检切换决策](../decisions/2026-08-29_070100_低成本HostedDR与客户端预检切换决策.md) 改为 `client-preflight`。本 runbook：

- 不是当前默认生产路径；
- 不是默认分支并轨或 production build 前置；
- 不授权购买/启用 Cloudflare LB、修改 DNS/Worker/Access 或执行 production cutover；
- 只作为未来重新引入托管 control plane 时的参考与恢复材料。

当前 `config/hosted-dr-capabilities.json` 的 `controlPlane.provisioning` 仍可保持 `not-provisioned`。未获得新的 ADR、批准和下列生产授权前，不得连接生产 Redis、修改 DNS/LB/Access、写入 production D1、触发 production deploy/cutover 或使用真实用户的 non-idempotent operation。

## 授权前置

- 新 accepted ADR 说明为什么客户端预检不足、为何需要所选 managed control plane；
- 决策者书面批准产品、预算、变更窗口、值班 owner、观察者、回滚 owner 和停止条件；
- 所选 LB/DNS/Worker/Access 权限与审计范围明确，stable/primary/DR origin 已由 owner 核对；
- D1/R2 备份、恢复点、Redis ephemeral 影响、监控告警和日志保留已确认；
- 使用合成 safe/read 请求；generation、settlement、rating、auth 和其他 non-idempotent operation 不得作为首次切流探针；
- Hono 与 DR artifact、manifest contract、CORS、secret/binding、D1 session/bookmark 和版本兼容 gate 已通过对应 CI；
- 已验证产品级 retry/failover 不会让 non-idempotent POST 创建第二 Provider 或第二权威效果；
- 先定义可接受的 outage window、最大 probe 次数和绝对停止时间，禁止无限重试。

## 演练顺序

1. 只读核对 manifest、当前 deployment/version、健康探针、managed control-plane 配置和 client compatibility；
2. 在控制面记录 Hono primary healthy，确认新 safe/read 请求落在 Hono；
3. 在授权窗口内模拟 primary unavailable，让新 safe/read 请求进入 DR；记录首个成功响应的时间、placement、contract version、D1 provider 和请求数；
4. 对已 dispatch/unknown operation 观察其 fail-closed 或状态恢复，不重新提交原 POST；
5. 恢复 Hono，先验证健康，再将后续新请求切回；旧 operation 继续按 request/generation identity 查询或明确失败；
6. 记录每一步实际命令、时间、响应、告警、人工动作、费用影响和未验证项；不得用预计 RTO/RPO 替代实测值。

## 回滚

- 立即停止新流量切换，保留当前已经 dispatch 的 operation，不自动重放；
- 将 safe/read managed selector 回到最后一个已验证 placement；无法确认状态时保持 `fail-closed`；
- 恢复服务后只做 safe/read health probe 和 operation status lookup；不执行 Redis flush、D1 restore 或 schema rollback 作为常规回滚动作；
- 如数据或结算状态异常，暂停写操作，由数据 owner 依照独立 D1/R2/DO 恢复流程处理并留下审计记录；
- 若 managed control plane 本身异常，按新 ADR 的兼容计划回退到已验证 client-preflight 或明确降级；不得同时保留两个无主 selector；
- 演练结束后将真实证据存入受控审计系统，并把仓库中的 production status/evidence 更新作为另一个经批准的变更。

## 停止条件

任意预算/owner、secret/binding/CORS/actor/authority 不确定、provider outcome unknown、非幂等请求可能被重复 dispatch、D1/R2/DO 状态无法核对、监控缺失或回滚 owner 不可用时，停止演练并标记 `BLOCKED`；不得以“探针成功”覆盖高后果不确定性。
