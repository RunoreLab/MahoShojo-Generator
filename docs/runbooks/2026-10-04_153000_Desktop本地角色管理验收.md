## 当前交付

**D3.2a。** `/local-library` 在 Web 与 Desktop 挂载同一份 `@mahoshojo/ui-web/local-cards`：活动列表（标题/类型/ID 搜索、类型筛选）、详情（元数据与截断正文 JSON）、移入回收站（软删，可恢复）、回收站恢复与彻底删除（purge，二次确认）。来源标签只陈述记录字段，签名字段显示“本机未验证”。Desktop 上数据卡写入、归档与备份共用页面级维护互斥，整体恢复挂起后保持锁定；归档导入完成后列表重读。

**D3.2b。** Desktop `/character-manager` 编辑本地角色与情景卡（从本地库“编辑”进入，`?card=<id>`），或导入/粘贴单个 JSON 数据卡；字段编辑器与 Web 角色管理共源。只改标题时原记录整卡替换；改正文以新摘要另存为 `unsigned`/`edited` 新记录，原记录保留，可显式移入回收站；导入命中活动记录提示已存在，命中回收站需点击“从回收站恢复并打开”。编辑草稿只在页面内存中，有未保存修改时导航/关窗需确认放弃，重启不恢复。魔法少女角色提供正文预览。Web 选卡弹窗的导入自动保存命中回收站时提示到本地库恢复。

不包含：单卡导出、问卷与叙事历史卡编辑、模板转换、schema 校验、原生性与敏感词检测、选卡与 Web 包管理。回收站记录以“已删除”状态随整库导出与备份保存，彻底删除后才不再包含。

## 实机记录待填写

以下各项均为 **待验**；jsdom 与 IPC mock 不等同于实机通过。使用专用测试库，不要把私人卡内容或凭据写入记录。

| 项目 | 操作与预期 | 当前证据 |
| --- | --- | --- |
| 未登录浏览 | 断网冷启动进入 `/local-library`，问卷保存过的角色可见；详情可展开；本地库浏览本身不产生项目请求（2026-10-06 r2：后台会话/公告/消息请求不计入） | 待验 |
| 软删与重启 | 移入回收站后重启，记录仍在回收站且不在活动列表；恢复后重启仍在活动列表 | 待验 |
| 彻底删除 | 回收站中彻底删除需二次确认；重启后不再出现；此前导出的归档再导入可带回该记录 | 待验 |
| 维护互斥 | 导出/导入/创建备份进行中数据卡写入按钮禁用；整体恢复挂起后保持锁定 | 待验 |

| 双层网络 | renderer 与 native 出站：浏览、编辑、导入、软删、恢复、彻底删除均零网络 | 待验 |
