## 当前交付（D3.2a）

`/local-library` 在 Web 与 Desktop 挂载同一份 `@mahoshojo/ui-web/local-cards`：活动列表（标题/类型/ID 搜索、类型筛选）、详情（元数据与截断正文 JSON）、移入回收站（软删，可恢复）、回收站恢复与彻底删除（purge，二次确认）。来源标签只陈述记录字段，签名字段显示“本机未验证”。Desktop 上数据卡写入、归档与备份共用页面级维护互斥，整体恢复挂起后保持锁定；归档导入完成后列表重读。

不包含：单卡导出、编辑、单卡导入、选卡与 Web 包管理。回收站记录以“已删除”状态随整库导出与备份保存，彻底删除后才不再包含。
