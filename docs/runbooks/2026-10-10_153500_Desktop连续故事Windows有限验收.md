## 隔离准备

`MAHOSHOJO_CLOUD_ORIGIN` 是 debug 编译期入口，编译前指向本人持有的 loopback mock，以吸收启动项目请求。仓库没有现成故事验收配置，先在测试树建立 `apps/desktop/.tmp/tauri-story.json`，再从仓库根 PowerShell 执行：

```powershell
$StoryConfig = (Resolve-Path 'apps/desktop/.tmp/tauri-story.json').Path
pnpm --filter @mahoshojo/desktop exec tauri dev --config $StoryConfig
```

Vite 为 1420，冲突时报告，不杀其它进程。可选本地产物复核：`pnpm --filter @mahoshojo/desktop exec tauri build --debug --no-bundle --config $StoryConfig`；不制作安装器。

上游只用本人持有的 `127.0.0.1` OpenAI-compatible mock、自定义模型名，无真实 Key；如界面必须填凭据，只用隔离 namespace 的固定假值。SSE wire 可参照 `ai_e2e_tests.rs` 现有 `choices[].delta.content` / `finish_reason:'stop'` / `data:[DONE]` 规则，准备正常、延迟终态、meta-only、EOF 四种合成模式。仓库没有可直接运行的一键故事 mock 服务脚本，不能把 Rust 测试函数当成 CLI；如另建临时服务，记录源码/hash/PID，日志仅保请求计数、model 与固定合成标记，不记凭据。

## W01 两页首章、续写与冷启动

在 `#/battle` 和 `#/arena` 各使用两张合成卡、章节计划“不限制”、显式 Direct 模型新建首章并续写一次。一次点击只增加一次 mock 请求，完成后按钮解锁。生成中手选旧章不被自动重开抢走；保存后 head 推进，下一次续写不报旧 revision。

更改普通单次草稿后，续写仍用冻结故事种子和独立下一章引导，普通草稿与原卡不被覆盖。关闭并以同 namespace 重开、跨两页读取共同目录，末章/旧章身份与内容正确，恢复/选择不新增模型请求。记录实际原生 begin/append/end 与 raw 响应，不能只用浏览器页面代替 Tauri。

## W02 停止、raw-only 与失败保文

mock 先给部分合成正文再延迟终态，点击“停止章节生成”。另测仅 `MAHOSHOJO_ARENA_META` 注释内容的取消/空正文失败，以及 EOF 缺终态。页面保留已收到 rawText 和可见结果，“导出完整原始输出”可用；源已存故事不变，未完成章不提交，停止后不自动重发模型。

检查未保存时的离页/关窗守卫，先导出再显式丢弃。导出 JSON 中的 rawText 逐字核对 mock 原文，不拿 JSON 外壳的文件 hash 代替原文字节比较。

## W03 保存未知回执

本项需要隔离测试树的可选诊断补丁，原界面没有现成注入开关。若未获准临时注入或不能定位真正成功的 end，记未测，保留已有 headless 证据并继续其它项。

利用 `battle-page.tsx::createStorySession` 的 `createIpcStoryNativePort(invoke)` 参数缝传临时包装器：照常 await 真 Tauri `end_arena_story_commit`，确认其真实成功返回后仅一次抛合成传输丢包错误；`query_arena_story_receipt` 仍实际调用，但暂时将结果隐藏为 null，覆盖自动查询和一次按钮查询。

应显示 unknown 并保全文；反复“查询原保存结果”不能出现新 begin/append/end 或模型请求。取消隐藏后查询确认原章只保存一次。保留补丁、命令计数与真实 receipt 身份；没有调用 end 不算“已落盘未知”。不要靠杀整个 Tauri 进程测试内存 pending 恢复：未保存原文本就不承诺跨关闭持久，重开只另核已提交章可读。

## W07 长文、长标题与真实视觉

以超过 `256 * 1024` 个 JavaScript 字符的合成正文、多字节超长标题，做 Desktop 与本机 Web 共享视图的普通长度/阈值/+1 对照。大章默认不挂报告 parser/card DOM，标题有明确缩短标记，保存原件不改；无需展开即可完整导出。Web 出口保共享判定追加/避免重复规则。手动展开/收起可用，切章不继承旧章展开状态，停止按钮始终可达。

原始输出 details 保留全文是既定行为，不能因此宣称所有 DOM 都小。记录真实主题切换、960×640 最小窗与 1180×800、可用缩放下的焦点、按钮、滚动、告警和目录可读性。Native/WebView 进程工作集分开记录；4 MiB 帧、256 Ki 字符阈值都不是 RSS 上限。系统 DPI 只记录当前值，不擅改系统配置。
