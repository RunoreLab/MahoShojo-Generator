# 魔法少女生成器桌面版 0.1.1

本次为问题修复与体验优化更新，延续 0.1.0 的 Windows x64 支持范围。

## 修复与优化

- 修复角色库连续选卡时分页意外跳回的问题，补齐本地翻页；多个列表支持输入页码直接跳转。
- 对齐两种竞技场页面的叙事历史操作，支持将历史中的角色直接导入本地库。
- 改善旧版情景卡的加载兼容性，Arena 与魔法茶会复用网页端消费规则，保留原卡的扩展与元数据字段。
- 修复模型选择菜单与页面滚动争抢造成的抖动。
- 改善 Direct 生成中断时的错误说明，保留可用于排查的安全诊断信息。
- 恢复在线房主对角色与情景的编辑，并修复房间进度读取过早推进生成状态的问题。

## 安装与升级

- 0.1.0 用户可通过“设置 → 高级 → 应用更新”手动检查更新，也可下载 `MahoShojo-Generator_0.1.1_x64-setup.exe` 覆盖安装。请先保存内容、备份重要作品并结束在途操作；不要先卸载或清理应用数据。
- 本次补丁未新增本地数据库 schema 迁移。旧 Beta 首次升级仍会执行既有图片库 schema 12 迁移；需要回退时使用升级前备份。
- 正式支持 Windows 11 x64；Windows 10 22H2 兼容情况继续结合实机反馈。本次不提供其他平台安装包。
- 安装包提供 Tauri updater 签名、`SHA256SUMS.txt` 与 GitHub 来源证明。Windows 发行者代码签名仍暂缓，可能出现未知发布者或 SmartScreen 提示；请从官方入口下载，无需关闭系统安全防护。
- 缺少 WebView2 时需要联网安装运行时；线上能力仍需网络。网页与桌面本地数据不会因登录同一账号自动同步。
