# 魔法少女生成器桌面版 0.1.4

本次更新改善竞技场日常模式的叙事、线上战报的首段等待和网页版的停止生成体验。

## 竞技场更新

- 桌面与网页版共用的日常模式提示词更重视生活互动、角色关系与前情连续性。缺少引导时优先从一件小事切入，也能承接战前出游、巡逻间隙或赛后休整等背景。
- 优化角色双重身份、信息视角和口语表达的指引。免费模型对照中日常情节更稳定，仍观察到偶发章节缺失、结构化 JSON 需要修复和人物表现偏差。样本与限制见[日常模式验收报告](https://github.com/RunoreLab/MahoShojo-Generator/blob/desktop-v0.1.4/docs/reports/2026-11-18_132138_日常模式提示词优化与真实验收.md)。
- 线上竞技场可恢复战报等待模型首段内容时，沿用后续读流的空闲上限，修复系统渠道和自带 Key 的线上生成过早超时。取消与总超时继续生效。
- 网页版停止接收战报后立即恢复生成按钮。服务器尚未确认旧任务停止时，重新生成会提示等待或确认开启新任务；服务器也会拦截在停止请求之后才到达的同一任务。

## 安装与升级

- 0.1.0–0.1.3 用户可在“设置 → 高级 → 应用更新”手动检查，或下载 `MahoShojo-Generator_0.1.4_x64-setup.exe` 覆盖安装。升级前请保存内容、备份重要作品并结束在途操作，保留原应用数据。
- 本次没有新增数据库迁移、服务端环境变量或更新公钥变更。旧 Beta 首次升级仍按既有流程迁移至本地图片库 schema 12，回退需使用升级前备份。
- 本版提供 Windows x64 安装包，正式支持 Windows 11 x64。Windows 10 22H2、缺少 WebView2、其他 DPI、多屏与物理输入法仍需独立验收。
- 安装包附 Tauri 更新签名、`SHA256SUMS.txt` 与 GitHub 构建来源证明。Windows 发行者代码签名仍暂缓，系统可能显示未知发布者提示。
