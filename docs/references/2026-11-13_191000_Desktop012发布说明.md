# 魔法少女生成器桌面版 0.1.2

本次更新增加显示与阅读设置，并改进数据卡界面和叙事规则；延续 0.1.1 的 Windows x64 支持范围。

## 新增与改进

- 主窗口支持 80%–200% 整体缩放，可在“设置 → 外观与交互”调整，也可使用 Ctrl + 加号/减号、Ctrl + 0 和 Ctrl + 鼠标滚轮。倍率保存在本机，独立作品窗口仍沿用原有行为。
- 新增正文阅读设置：字号、系统字体类别、行距与长文宽度，并提供即时预览。角色与情景正文、普通战报及历史、连续故事、魔法茶会和百科共用偏好；卡片与战报图片导出跟随阅读排版，原始 JSON/Markdown 不变。
- 精简数据卡详情的操作区，优先展示正文；“管理员推荐”移入公开库高级筛选，修正公告横幅遮挡模态框的问题。
- ModelScope 的非秘密参数表单共源，系统模型目录加入四款已核验 Step 模型；模型实际可用性仍由服务端配置和上游状态决定。
- Arena 与魔法茶会共用设定忠实性、内容边界和事实记录规则，将稳定规则与角色资料分层发送，保留各模式和输出协议的差异。

## 已知边界

叙事规则调整不保证模型始终遵循长设定。真实对照仍出现人物弱点误判、元叙事胜负误读、茶会标识或摘要身份混淆，以及个别输出格式失败。请核对重要生成结果；本次没有通过放宽解析或自动再次生成掩盖这些失败。详细范围见[真实验收报告](https://github.com/RunoreLab/MahoShojo-Generator/blob/desktop-v0.1.2/docs/reports/2026-11-13_185500_叙事提示词共源与真实验收.md)。

## 安装与升级

- 0.1.0 / 0.1.1 用户可在“设置 → 高级 → 应用更新”手动检查，或下载 `MahoShojo-Generator_0.1.2_x64-setup.exe` 覆盖安装。请先保存内容、备份重要作品并结束在途操作，不要先卸载或清理应用数据。
- 本次未新增数据库 schema 迁移、服务端环境变量或更新公钥变更。Desktop 配置仍为 version 1，旧配置缺少缩放字段时默认 100%；阅读偏好独立保存在当前设备。Web 与 Desktop 的本地数据和偏好不会因登录同一账号自动同步。
- 旧 Beta 首次升级仍会执行既有图片库 schema 12 迁移，需要回退时使用升级前备份。
- 正式支持 Windows 11 x64；Windows 10 22H2、其他 DPI、多屏、物理输入法及缺少 WebView2 的环境不借本机结果宣称已验。本次不提供其他平台安装包。
- 安装包附 Tauri updater 签名、`SHA256SUMS.txt` 与 GitHub 来源证明。Windows 发行者代码签名仍暂缓，可能出现未知发布者或 SmartScreen 提示；请从官方入口下载，无需关闭系统安全防护。缺少 WebView2 时需要联网安装运行时，线上能力仍需网络。
