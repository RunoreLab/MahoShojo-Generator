# 魔法少女生成器桌面版 0.1.3

本次为兼容性与稳定性补丁，修复“我的角色”详情崩溃，并更新共享界面和运行依赖；延续 Windows x64 发行范围。

## 修复与维护

- 修复桌面端“我的角色”打开部分角色详情时崩溃的问题，兼容服务端返回的逗号分隔标签 ID，并保留既有数组格式。
- 修复档案馆用户中心在窄屏下的内容错位，改善小窗口布局。
- 保持 Web 与 Desktop 对 Unicode 字符串长度的校验一致，避免依赖更新后出现同一份数据在两端校验结果不同。
- 更新桌面构建链、共享校验与 AI 相关依赖；Web 同步更新 Next.js、Cloudflare 适配器和 Better Auth，保留现有认证表结构与登录接入。
- 线上 Arena 严格排位（Web 与 Desktop 服务器执行）至少需要一名参战角色属于发起者，不能仅用他人角色开启严格排位。

## 安装与升级

- 0.1.0–0.1.2 用户可在“设置 → 高级 → 应用更新”手动检查，或下载 `MahoShojo-Generator_0.1.3_x64-setup.exe` 覆盖安装。请先保存内容、备份重要作品并结束在途操作，不要先卸载或清理应用数据。
- 本次未新增数据库 schema 迁移、服务端环境变量或更新公钥变更。桌面配置与本地库格式沿用现有版本；Web 与 Desktop 的本地数据和偏好不会因登录同一账号自动同步。
- 旧 Beta 首次升级仍会执行既有图片库 schema 12 迁移；需要回退时使用升级前备份，不要让旧 Beta 直接读取升级后的库。
- 正式支持 Windows 11 x64；Windows 10 22H2、其他 DPI、多屏、物理输入法及缺少 WebView2 的环境仍需单独验收。本次不提供其他平台安装包。
- 安装包附 Tauri updater 签名、`SHA256SUMS.txt` 与 GitHub 来源证明。Windows 发行者代码签名仍暂缓，可能出现未知发布者或 SmartScreen 提示；请从官方入口下载，无需关闭系统安全防护。

0.1.2 的叙事模型及社区 Web 包输出格式限制仍然适用，本次未重新宣称这些真实生成案例全部通过。详见[上一版说明](https://github.com/RunoreLab/MahoShojo-Generator/releases/tag/desktop-v0.1.2)。
