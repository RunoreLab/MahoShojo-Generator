# 魔法少女生成器桌面版 0.1.0

首个 Windows 桌面正式版，包含 Beta 测试期间完善的创作、竞技场、本地作品库与在线账户功能。

## 本次正式版收尾

- 设置页提供手动检查更新、版本说明、下载进度与取消。更新包验证签名后才允许安装。
- 安装更新前提示保存作品，并在生成、写库、备份或恢复仍进行时阻止安装。
- 改善小屏窗口适配，随安装包提供可离线阅读的第三方开源许可。
- 官网提供统一下载入口、安装和本地数据指南。

## 安装与升级

- 正式支持 Windows 11 x64。Windows 10 22H2 的兼容情况需结合实机反馈；本次不提供其他平台安装包。
- 使用本 Release 的 `MahoShojo-Generator_0.1.0_x64-setup.exe`；可对照 `SHA256SUMS.txt` 核对下载文件。
- Beta 用户需先备份重要作品，再手动运行安装包覆盖升级。应用标识和数据目录保持不变，请勿先卸载或清理应用数据。
- 旧 Beta 的本地库会在首次启动时自动迁移到当前图片库格式（schema 12）。升级后不要直接用旧 Beta 打开该库；需要回退时请使用升级前备份。
- 缺少 Microsoft WebView2 的设备安装时需要联网下载运行时。在线账户、公开内容与云端 AI 仍需网络。
- 首版暂未进行 Windows 发行者代码签名，可能出现“未知发布者”或 SmartScreen 提示。请从官方入口下载并核对 SHA256，无需关闭系统安全防护。
- 网页端与桌面端的本地数据不会因登录同一账号自动同步；本地 AI 连接与密钥需独立配置。

后续版本可通过“设置 → 高级 → 应用更新”手动检查。安装更新会关闭应用；请先保存内容并结束在途操作。
