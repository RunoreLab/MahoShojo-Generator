## 🖥️ 魔法少女生成器桌面版 v0.1.0 正式发布！

经过 Beta 测试和社区反馈，《魔法少女生成器》迎来了第一个 Windows 桌面客户端正式版！

现在可以打开[桌面端下载页](https://mahoshojo.colanns.me/download)，获取官方 Windows 64 位安装包。

### 桌面版能做什么？

- 在独立窗口中使用创作、竞技场和本地作品库等已支持功能。
- 管理保存在电脑上的数据卡、图片、Web 包与相关本地内容。
- 按页面支持的选项使用在线模型，或配置自己的 AI 服务。
- 登录后联网访问账号、公开数据卡等在线服务。

网页端仍会继续维护，大家可以按自己的使用习惯选择。

### 安装前请注意

1. 首发提供 Windows x64 安装包；其他平台可继续使用网页版。
2. 网页本地库与桌面本地库不会因登录相同账号自动同步。已有重要作品的用户，请先备份。
3. Beta 用户首次升级需要手动下载安装包并覆盖安装。不要先卸载或删除本地数据；按最终发布的升级说明操作。
4. 首版暂未进行 Windows 发行者代码签名，系统可能提示“未知发布者”或 SmartScreen 警告。
   请从官方下载页获取安装包并核对 SHA256，无需关闭系统安全防护。
5. 缺少 WebView2 的设备安装时需联网下载运行时；在线账号、公开内容及云端 AI 仍需要网络。

安装、更新与本地数据说明见[桌面客户端使用指南](https://mahoshojo.colanns.me/encyclopedia/desktop-client)。
