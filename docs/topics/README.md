# 主题入口

更新时间：2026-03-25
状态：`active`

`docs/topics/` 用来提供稳定主题的入口。

它不是新的结论源，也不是把旧报告重写一遍，而是承担三件事：

1. 说明某个主题当前到底覆盖什么范围。
2. 指向该主题最值得先读的 `decision / spec / architecture / report`。
3. 汇总该主题当前已经稳定的口径与仍未解决的问题。

## 使用顺序

建议按以下顺序阅读：

1. 先理解全局稳定结论。
2. 再进入本目录对应主题页，理解某个主题的当前共识、核心文档与未决事项。
3. 需要稳定单点结论时，跳转到 `docs/decisions/`。
4. 需要细节论证、设计过程与推演背景时，跳转到 `docs/specs/`、`docs/architecture/`、`docs/reports/`。

## 与其他目录的关系

- `docs/decisions/`
  - 放单点稳定决策，适合被长期引用。
- `docs/specs/`
  - 放规范性定义与后续 schema 草案。
- `docs/architecture/`
  - 放系统边界、仓库边界与跨层约束。
- `docs/reports/`
  - 放时间戳推演、专题研究与阶段综合分析。
- `docs/references/`
  - 放来源盘点、其他仓库证据与外部资料。
- `docs/logs/`
  - 放过程记录，不作为稳定结论源。
