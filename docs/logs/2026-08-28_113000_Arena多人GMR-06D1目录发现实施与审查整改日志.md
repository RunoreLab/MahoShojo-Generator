## 2. 关键设计与 authority 边界

- `RoomDirectoryEntry/Page/Query` 只暴露 roomId、title、visibility/status 与时间；`hostUserId` 和
  `roomEpoch` 只存 server-owned D1 记录，不进入 public discovery wire。
- D1 migration `0014_arena_multiplayer_rooms.sql` 建立 public/host/reconciliation 实际查询路径的索引；
  public/host 查询和清理都是有界 keyset page，write 不对非幂等操作盲目重放。
- lookup/discovery 对每个 D1 candidate 重新读取 Redis checkpoint；只有 open、exact epoch、exact host
  才能返回。checkpoint absent/closed/unavailable 不会让 D1 提升为 authority。
- Redis registration v2 显式记录 `pending-create`、`projecting`、`active`、`closing`，并保留
  target/projected epoch。D1 write 成功但 confirm 失败时，predecessor 仍可恢复；recovery 切换
  epoch 只能 exact-advance。
- create 先写 pending registration；Room checkpoint `SAVE` Lua 在同一 CAS 中要求 exact v2 pending
  registration，并与 checkpoint 同时切换为 projecting。cleanup-first 不能再提交 Room。
- cleanup 不使用过期的 absent/terminal 观察。absent 模式在 `MARK_CLOSING` Lua 内要求
  checkpoint 仍不存在；terminal 模式由严格 parser 生成 canonical checkpoint raw，Lua 只允许
  raw absent 或 exact-equal。任何 concurrent save、malformed raw 或 epoch/lifecycle 替换都 fail closed。
- D1 delete 失败保留 closing tombstone，只在 exact-epoch D1 删除并二次确认 absent 后删除
  registration。registration reconciler 与独立 D1 reconciler 都是低频、有界、不重叠执行，
  并在 graceful shutdown 时停止。
- rolling upgrade 的 v1 registration 只经 strict parse + exact-CAS 迁移为 v2 pending；不会
  无声遗弃旧 namespace，也不改写 Room public wire。

## 6. Independent review 与关闭状态

三路独立审查累计发现并关闭：

- recovery target 前进时丢失 projected predecessor；改为先保留旧 target，confirm 成功后再 active；
- D1 write 成功但 confirm 失败、close delete 失败时补偿不完整；增加可恢复 phase 和
  closing tombstone；
- pending create cleanup-first 竞态；将 pending registration 验证/切换与 checkpoint save 合并为同
  Lua CAS；
- pending cleanup save-first 竞态；将 checkpoint absent/terminal fence 放入 `MARK_CLOSING` 同一 Lua；
- partial terminal parse 仍可让 malformed checkpoint 误删；最终改为严格 parser 生成 canonical raw
  并 exact-equal，真实 Redis 注入 partial closed raw 回归；
- v1 registration namespace 未迁移、registration 丢失后 D1 orphan 无扫描；增加 strict exact-CAS
  migration 和独立 D1 reconciler；
- 测试最初只覆盖 adapter 故障/单一 get 迁移/立即完成 timer；补充真实 Redis EVAL
  故障、v1 `list()` 迁移和 deferred timer/cursor/error retry。
