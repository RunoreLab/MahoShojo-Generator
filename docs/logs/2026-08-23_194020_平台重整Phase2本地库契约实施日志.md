## 本批完成

- 新增 `@mahoshojo/local-library`，通过显式 exports 导出 `record / repository / migration / archive`，仅依赖 `@mahoshojo/contracts` 与 Zod，不依赖 app、UI、数据库、文件系统、网络或具体 runtime。
- 建立版本化 `LocalCardRecordV1`：
  - 本地记录 ID、`storageLocation: 'local'`、线上卡类型、标题、JSON-safe payload、algorithm-tagged content digest、provenance、可选 cloud reference 与时间戳均由 strict schema 校验；
  - 本地副本和云端引用保持正交，不把云端 slot 或签名状态等同于本地所有权；
  - 约束 `createdAt <= updatedAt <= deletedAt`，解析时对 JSON payload 做防御性复制，避免调用方修改通过校验后的持久化输入。
- 建立 `CardRepository` 端口：
  - `get` 可返回 tombstone，`list` 默认排除已删除记录；
  - `put` 必须经过 schema 校验和复制，不能隐式清除既有 tombstone；
  - `delete` 为幂等软删除，恢复只能通过显式 `restore`；
  - 不在领域端口中猜测 IndexedDB/SQLite transaction、网络同步或云端配额。
- 建立 `LocalCardMigrator`：只接受安全正整数版本、唯一且连续的 `n -> n + 1` 路径；每步输出重新验证 JSON-safe 与目标版本；失败只暴露稳定错误码，不透传原始异常，并保证调用方输入不被修改。
- 建立 archive manifest v1：
  - 记录格式版本、库 schema 版本、导出时间、cards/assets 数量、路径、byte length、内容摘要和原始字节 SHA-256 checksum；
  - card 路径限制为安全小写 `cards/*.json`，拒绝路径穿越、大小写歧义、Windows 保留设备名及尾随点；
  - asset 路径从小写 SHA-256 digest 派生，checksum 必须与 content digest 一致；
  - 拒绝重复 card ID、重复 archive path、计数不一致和超过 100,000 条的清单。
- `@mahoshojo/contracts/json-value` 增加正式子路径 export，供本地库复用同一 JSON-safe contract；package README 与 lockfile importer 同步。
