## 1. Objective 与 stopping condition

本 Goal 已行为等价完成 legacy root Next/OpenNext 应用 relocation：`apps/web` 现独占 source、manifest、
test/lint/build、静态资产、环境与 Cloudflare deployment lifecycle；root production dependencies 清零，只保留
workspace 编排、统一门禁与跨 runtime route/migration tooling。

以下保护性终点没有移动：客户端继续不可信；Hosted/签名/排位/线上数据继续服务器权威；Legacy/Better Auth
兼容、Arena v1 request identity/SSE/resume/cancel/unknown replay、D1/R2/Redis authority 与非幂等操作不盲目跨
runtime 重放均保持原语义。Next/OpenNext DR adapter 保留，但没有启用自动 failover。

stopping condition：`PASS`。没有开放的 Critical、Important、Minor 或 blocker。

## 3. 关键实现与文档决策

- 1,642 个 rename；其中 1,627 个是 Git R100，15 个仅因跨 runtime 相对路径/config owner 调整而变化；
- `apps/web/package.json` 持有 Next/OpenNext/React/Web runtime 与 app-local tooling，root runtime dependencies 为零；
- Cloudflare workflow 显式使用 `pnpm --filter @mahoshojo/web` build/deploy；生产/preview environment 与 bindings 不变；
- `@/*` 在 Web 内仍解析 `apps/web/*`，root Drizzle generator 也通过 root tsconfig alias 解析同一 schema；
- app/explicit env 高于 ignored root fallback；helper 只在 server config/operation 路径使用，不进入客户端 bundle trust boundary；
- root D1 migration/status 工具固定使用 lockfile 内 `@mahoshojo/web` Wrangler 4.125.0，不再通过 `npx --yes` 产生网络/版本漂移；
- MONO-009 同时识别 root legacy 与 `apps/<app>/app/api` / `pages/api`，禁止 Hono adapter 直接或间接回导 relocated Next handler；
- Web lint policy 由 `apps/web/eslint.config.mjs` 单点持有并以 effective-config contract 冻结，lint CLI 直接使用 ESLint；
- root boundary gate 扫描 `scripts/**`、`tests/**` 与根级 TS/JS tooling，按 root tsconfig alias、相对路径、baseUrl 与 app package name 禁止 root→app source import；
- Web readiness 不新增绕过真实 capability 的假 health endpoint，以 test/lint/Next/OpenNext/D1 config/preview dry-run 证明发布前可构建性。

权威文档同步更新：平台 topic、主 Goal 计划、Hosted 插入计划、G25D accepted 设计/实施计划与 app/package README。
没有新建或 supersede ADR，因为 trust/data/replay/deployment authority 均未改变。
