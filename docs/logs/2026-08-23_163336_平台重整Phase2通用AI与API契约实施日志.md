- 实施范围：完成 Phase 2 的一个独立共享契约切片——冻结 runtime-neutral `AiExecution` request/result v1、通用 API v1 success/error envelope 和 JSON-safe wire value；未实现 `AiExecutionPort`、stream event、Direct Provider Profile、`ai-core`、运行时 adapter 或 legacy API 响应迁移。

## 本批完成

- 为 `@mahoshojo/contracts` 新增显式 `./ai-execution` 与 `./api` 子入口，并从 package 根入口导出。
- `AiExecutionRequest` 使用稳定 `contractVersion`、`requestId`、执行模式、标准化消息和非秘密通用生成参数；请求 schema 为 strict，不包含 Profile ID、Endpoint、header、Cookie、authkey、activity token 或 API Key。
- Thinking 语义与现有 `default / disabled / enabled + effort` 口径一致，effort 覆盖 `minimal / low / medium / high / xhigh / max`；非法的 disabled + effort 组合被拒绝。
- `AiExecutionResult` 以 `completed / failed / cancelled` 判别联合表达明确终态，并携带 request correlation、执行模式和 contract version；completed 结果必须包含非空文本或 JSON-safe structured output，reasoning 不能单独伪装成成功输出。
- AI 执行错误码与 HTTP/API transport 错误码分离；错误 envelope 只允许稳定 code、脱敏 message 和有限 retry metadata，不接受 cause、stack、raw upstream payload 或 credential 字段。
- 通用 API contract 冻结 `API_CONTRACT_VERSION = 1`、supported range、success/error envelope 和稳定 transport error codes；本批不套用到 legacy handler，避免改变现有 wire response。
- JSON value validator 使用非递归遍历，拒绝非有限数字、稀疏数组、循环引用、accessor、symbol/non-enumerable own property、Date、BigInt、Function 和非 plain object，同时允许合法的非循环共享引用和深层 JSON。
- root、`./ai-execution` 与 `./api` 的 Node/browser/neutral bundle 测试证明契约不读取环境变量，也不引入 React、Cloudflare 或 Node runtime。
