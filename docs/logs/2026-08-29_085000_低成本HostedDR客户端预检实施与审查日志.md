## 1. Objective 与停止条件

本 Goal 在不相对默认分支成本基线新增付费产品、不执行生产操作的前提下，把 Hosted DR 默认选择从未纳管的 managed
control plane 改为 Web 每个新 generation intent 的 pre-dispatch client preflight。停止条件是代码、production build、
真实隔离 fault evidence、文档与独立审查全部完成，且没有开放 Critical/Important finding。

本 Goal 不部署 production，不创建或修改 Cloudflare LB/DNS/monitor/Worker route，不修改 Access、secret、D1/R2/Redis
生产数据，不发布 release/tag，不 push 或重写历史。

## 2. 实现范围

- manifest/source of truth：增加 `defaultMode=client-preflight`、`managedControlPlane=optional-disabled` 与 1500 ms timeout；
  生成公开 routing 与 route/method/request/replay/contractStatus 最小投影；validator 拒绝 credential/query/internal/IP origin、
  projection drift、secret/binding、fail-closed widening 与伪 production evidence；
- primary readiness：Hono `/api/health/ready` 向后兼容增加 `service`、`placement=hono-primary`、共享
  `contractVersion` 与 `Cache-Control: no-store`，`/api/*` CORS 继续 exact allow-origin、无 credential；
- selector：每个 intent 一次 primary probe；primary non-ready 后只有 verified safe-read/new-request-only 最多执行一次 DR
  probe；未登记、pending 与 fail-closed operation 不进入 DR；decision/probe 均不可变且没有跨 intent 正向缓存；共享
  contract version helper 接受当前/前一兼容版本并拒绝超出窗口的 readiness；DR probe 发送 canonical capability/method，
  服务端用同一 guard 校验目标 operation 的 secret/binding/database provider/consistency，客户端只接受精确回显；
- dispatch：`createGenerationApiIntent` 只允许一次 dispatch；primary 使用公开 Hono origin 且不带 Cookie，DR 使用同源 Next
  且保持既有 auth/activity header；React intent latch 跨 rerender/重复 callback 持有同一意图，直到 response body 明确结束或
  ambiguous terminal 才释放；业务 fetch 一旦调用，写操作 transport/未知 5xx、stream/cancel 与 SSE EOF-before-done 记录为
  ambiguous，明确 SSE `done` / `error` 分别记录成功/失败，所有路径零跨 runtime replay；
- UX/telemetry：新增稳定安全文案与低基数 selection/terminal event；不记录 URL query、prompt/body、Authorization、Cookie、
  Provider credential 或用户自由文本；observer exception fail-soft；
- build safety：Next 与 OpenNext build 都在新产物生成后扫描客户端静态 chunk；要求完整 public routing projection 存在，
  在所有客户端 JavaScript 拒绝 manifest secret/binding 名称与静态 `.internal` / `.local` / localhost/无点/IP endpoint；
  hostname 规范化尾随点/IPv6，scheme 大小写无关，拒绝 credential/query/fragment URL 且错误不回显值，仅精确豁免
  framework URL parser/snapDOM synthetic fixture；contract gate 同步校验 route ID、规范化 pattern 与 methods，mutation
  tests 固定扫描和构建顺序；
- fault evidence：真实 loopback HTTP verifier 覆盖 primary ready、primary transport down + eligible DR、primary down +
  fail-closed、primary ready + POST socket disconnect，并输出 operation identity、placement、probe/POST count、latency 与 terminal。

   扫描并加入 split-token mutation tests，同时排除框架 URL parser fixture 的误报；

5. contract gate 只比较 route ID，未比较 pattern/method：由 `5bc346b3` 补齐动态 segment 规范化和 method 集合校验；
6. 实施日志与当前证据漂移：本次文档收口更新 checkpoint、测试计数、审查与 build evidence。

代码整改后的独立 code-only 复审曾确认前五项 `open Critical/Important=0`。其后的全 diff 独立审查又报告 5 个 Important：

2. 尾随点 internal/IP origin 可绕过 validator/scanner：`63fb56a5` 统一移除尾随点并规范化 IPv6，增加 manifest/bundle mutation；
