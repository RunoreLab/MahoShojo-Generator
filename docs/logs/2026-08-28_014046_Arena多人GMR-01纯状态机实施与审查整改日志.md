## 1. Objective 与 stopping condition

本切片在不引入 Hono、Redis、Node WebSocket、D1 I/O、生产配置或 UI 的前提下，为 `packages/multiplayer-core` 建立可由后续 Redis adapter 使用的 Arena Room 权威纯状态机。最终 stopping condition 已闭合：create/close、membership、host publish、Proposal、generation reservation/mirror、epoch/revision/control sequence fence、predecessor/next-state 与稳定错误语义均有实现和回归测试；公开 Arena v1 wire 未改变。

## 2. 实际实现与设计决策

- 新增严格版本化的内部 `ArenaRoomAuthorityState`，以 `authorityStateVersion=1` 保存 lifecycle、公开 snapshot、member authority、generation ledger、terminal Proposal tombstone 与 collaborative provenance sidecar。
- 所有 transition 为 runtime-neutral pure function；成功结果显式携带 predecessor、next state 和安全公开事件，失败不携带 events 且不修改输入。
- authority-changing 路径同时校验 `roomId + roomEpoch + revision + controlSeq` 所需的前驱信息；generation reservation/publisher capability 绑定 Room incarnation、request/generation/attempt、revision/digest 与 expiry，并通过进程内 identity 防止客户端 JSON 冒充。
- generation expiry 使用 adapter 签发的可信服务端时间；command timestamp 必须与该时间一致，拒绝 lifecycle 时间回退，并在 `now >= expiresAt` 时 fail closed。
- generation snapshot digest 固定为 `sha256:<64 位小写 hex>`；内部 checkpoint 缺失 replay sidecar、包含 terminal Proposal、非 canonical digest 或 aggregate oversized snapshot 时均拒绝 hydrate/transition。
- exact replay fence 采用有界 Room-incarnation ledger；配额耗尽返回稳定 `capability-denied`，保留 host close 和已提交状态，不在同 epoch 清空 tombstone/ledger。
- collaborative influence 从“某 revision 是否发生协作”收紧为当前 shared config 上仍有实际作用的已接受 change provenance；host 覆盖对应字段会清除来源，无关发布保留来源。

accepted 文档同步新增 `ROOMRT-006A bounded Room incarnation / exact replay fence`，并在首发实施计划中固定“配额耗尽后显式 close + 新 Room/new epoch”的 runtime 责任。这是对首次内部 checkpoint/rollover 语义的补全，不是对既有公开 wire 的不兼容变更。

## 4. Fault / negative coverage

- create 仅允许空前驱；closed Room 和 old epoch command fail closed；
- host/member/account authority 不匹配、序列化 capability、伪造 trusted time、secret 字段注入均拒绝且不反射 secret；
- stale revision、stale control sequence、old publisher epoch、attempt/identity mismatch 无法覆盖当前 state；
- 非幂等 publish/resolve/withdraw/leave 不盲目重放，exact generation reservation retry 保持幂等；
- generation 只允许既定状态图，terminal metadata 冲突和 terminal regression 均拒绝；
- 回填旧 timestamp、时间回退、late/equal expiry 均拒绝；
- terminal Proposal ID、member/generation history 与 collaborative provenance 不因 checkpoint hydrate 静默丢失；
- digest poisoning、缺失 v1 sidecar、terminal Proposal checkpoint、aggregate oversize 与 Room-incarnation quota exhaustion 均 fail closed，并验证失败无 events、输入不变。

## 6. Independent review 与关闭状态

实施后使用三个独立上下文分别审查 architecture/contract、security/authority、compatibility/replay/data 与 test adequacy。审查中发现并关闭的主要风险包括：

- authority capability 可序列化冒充、scope/expiry 不完整；
- generation callback 缺少 Room epoch、attempt、terminal metadata 或 trusted-time fence；
- member/generation/Proposal replay ledger 静默丢失或无界增长；
- exact reservation retry 被后续 revision 错误拒绝；
- collaborative provenance 被 revision boolean 误判；
- internal digest poisoning、v1 sidecar 缺失后 tombstone 复活；
- aggregate oversized hydrate 与拒绝路径无副作用断言不足。
