## 部署与回滚

本批只建立独立手工部署入口，不新增自动生产部署 workflow。生产部署仍需显式执行 app/root 兼容 deploy 命令，
并在部署前由运维确认现有 Cloudflare Access policy 与 Worker secret。代码迁移可独立 revert 本提交；若后续已部署
新 Worker version，则使用 Wrangler 明确指定旧 version rollback。回滚不依赖 Web/Hono 搬迁，也不修改 schema、
secret 或 Access 策略。
