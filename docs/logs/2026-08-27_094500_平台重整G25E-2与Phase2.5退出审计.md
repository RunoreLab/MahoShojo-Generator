## 5. Builder self-review 与整改

初始 Builder 审查范围为 G25E-2 基线 `61e691f6..2a97a06a`，后续整改与最终审查覆盖至 `5d6b952e`，重点复查 accepted ADR/spec、依赖边界、secret/authority、
replay/effect identity、producer/consumer/schema、workflow fail-closed、rollback 与测试充分性。结论如下：

| 严重度 | Finding | 处置 |
| --- | --- | --- |
| `Critical` | `provisioning=not-provisioned` 时 production client 仍默认启用尚无 DNS 的 stable origin，会使 shared Hosted route 进入不可用 hostname。 | `5bc1beb7` 冻结 activation 设计，`7dee8cce` 增加 client projection、显式 deployment target 与 production build fail-closed；targeted contract/Web tests 已关闭。 |
| `Important` | 把 not-provisioned 自动解释为 same-origin fallback 会把 manifest 中 `drMode=fail-closed` operation 放到不可执行的 Next placement。 | control-plane provisioning 与 fallback artifact/placement 分离；validator 在存在 fail-closed operation 时拒绝 `artifactReadiness=verified`。 |
| `Important` | `D1_GATEWAY_ALLOWED_ORIGINS` 与 URL 由同一 env owner 管理，不形成独立 trust boundary，且生产现状未配置它；同时 preflight 与 Node transport 的 URL 校验原本不共享实现。 | `30e6d6fc` 撤回重复变量，以一个 parser 同时拒绝不安全 URL 并要求 HMAC/Bearer；更强 allowlist 留给独立 deploy/platform egress owner。 |
| `Important` | 完整 hosted-runtime typecheck 发现直接调用 finalization port 的 adversarial fixture 未补新增 `idempotencyKey`。 | `2a97a06a` 按 effect identity contract 补齐 fixture；57 个 runtime test、316 项断言和 package build 通过。 |
| `Important` | 独立审查发现 production/preview target、origin/root/prefix、binding-only authority、真实 Redis/SQLite 证据和 CI 执行关系仍有若干可绕过或证据不足之处。 | `5d6b952e` 统一 deployment target parser，移除生产默认 target，约束 target↔origin↔root↔Redis prefix，令 Web production/preview D1 与 reconciliation 只使用 binding，并以真实 Redis、SQLite 与 workflow contract 补齐证据。 |
| `Minor` | naming workspace gate 仍报告 1376 条历史 report-only snake_case 审计项。 | 本批未引入命名迁移，也不影响行为/安全/退出门禁；保留为既有非阻断审计，不为本 Goal 扩大范围。 |

整改和最终复审后没有开放的 Critical/Important finding。外部规格审查中“必须使用显式 deployment target”与
“not-provisioned 不能自行授权 same-origin”成立并已落实；“当前 preview origin 会被 production 接受”的描述不符合
已有负向测试，但移除 `NODE_ENV` 推断仍关闭了相邻真实风险。

## 8. Rollback、影响与 stopping condition

回滚按原子提交逆序执行：先回退出审计/审查整改，再回 `2a97a06a` fixture、`30e6d6fc` Gateway 信任边界、
`7dee8cce` stable activation gate；不得在回滚中修改 production DNS/LB/Access、secret、D1 schema/data、Redis 数据或
release。回退 stable activation gate 会重新引入已确认的 production routing 风险，不能作为生产上线方案。

本 Goal 没有数据库 migration、production deploy/cutover、远程生产写入、secret 变更或 release/tag 影响。发布影响是：
production Web artifact 在 control plane 或 fallback artifact 未经独立验证前故意 fail closed；preview 在专用资源和
schema evidence 未纳管前故意拒绝部署；Hono 下一 release 不再要求同 trust owner 的 Gateway origin allowlist，但仍要求
严格 HTTPS root origin 与 HMAC/Bearer credential。
