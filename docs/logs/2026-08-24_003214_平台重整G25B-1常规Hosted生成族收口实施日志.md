## 实际范围与 capability 裁决

本 Goal 保留并迁移 5 条已经位于 Hono manifest 的常规 Hosted generation capability：

- `generate-game-card`
- `generate-free`
- `generate-free-stream`
- `generate-scenario`
- `generate-scenario-stream`

这些 route 没有新增 Hono 覆盖面。保留理由是：它们已经承担 Hosted 主执行面的成本与可靠性责任；Free/Scenario 流式 route 有长连接、中断传播和 Cloudflare CPU 价值；非流式同族可复用同一安全、限速、Provider、活动记录和回滚 composition。当前没有逐 capability 证据证明从 Hono 退出会更可靠或显著降低成本，因此本 Goal 没有退出 capability。

启动预检没有按路线数机械迁移全部候选。Creator、残兽、魔法少女详情、升华四对 handler 合计约 4,500 行，并分别带有 questionnaire/DataCard/build-rule/native signature/sublimation finalize 差异；Arena/session/battle/Tavern/Tea Party/regenerate 还有状态、写入、结算或非幂等副作用。把这些并入本 Goal 会明显越过约 5 小时的 stopping condition，因此依据 `GOAL-011` 重排到 G25B-2..5。

## 实现与架构

- `@mahoshojo/hosted-api` 新增 Game Card、Free、Scenario application service 与显式 exports。package 只依赖 Web Standards 与 Zod v3 compatibility，不读取环境变量、不持有 Provider secret，也不导入 Next、Hono 或 legacy root。
- package service 负责不可信请求解析、method/body/default/上限、限速/安全/生成/活动/输出或签名 response 的顺序、短路与 legacy 错误 wire；runtime port 返回显式 completed/response step，不靠异常表达正常拒绝。
- `lib/hosted-api/*` 承接唯一一份生产 runtime composition：Provider/model resolution、AI prompt/schema、内容安全、输出遮罩、签名、AI meta、活动记录与日志。Game Card 保留既有 custom Provider `SEQUENTIAL` 行为；Free/Scenario 保留 custom Provider `CUSTOM`、system/model override 与 stream reasoning bridge 行为。
- 五个 Next handler 变为薄兼容导出，五个 Hono adapter 与 Next 绑定同一默认 service composition；公开路径、method surface 和 Web 调用方式未变。
- manifest 从 `1 shared / 23 legacy` 原子移动到 `6 shared / 18 legacy`，总路由数仍为 24；generated registry 对这五条只加载 `server/adapters/*`。
- `MONO-009` 门禁会递归扫描 Hono adapter 可达的本地静态依赖图，拒绝直接/间接 `app/api`、`pages/api` 回导，也拒绝可达的非字面量 `import()` / `require()`，防止用 bridge 或动态路径制造假 shared seam。
