## 实施内容

- 新增 `@mahoshojo/hosted-api` source-export package，以 Web Standards `Request` / `Response` 和显式依赖端口承载 Hosted application service；package 不读取环境变量，不导入 Next、Hono、Redis、数据库、服务器秘密或 legacy root app。
- 将 `generate-magical-girl` 的输入校验、限速 -> 安全 -> 生成 -> 活动记录 -> 签名顺序、成功/错误 wire response 移入共享 service；既有 AI Provider、Prompt/schema、内容安全、限速、签名和日志实现继续由服务器 runtime composition 注入，没有改变响应字段或用户流程。
- Next `app/api/generate-magical-girl` 保留薄 Route Adapter；Hono 新增独立 adapter。Hono 不再动态 import 该 Next route，两个 adapter 调用同一 service。
- `config/hono-api-routes.json` 改为互斥 `sharedRouteIds` / `legacyRouteIds`；生成 registry 明确输出 adapter 类型，并验证 shared adapter 文件存在。路由总数保持 24，当前为 1 shared / 23 legacy；Tachie、普通 CRUD 和其他 route 未加入 Hono。
- 将通用 route dispatcher/registry 从 `server/legacy` 收口到 `server/routes`；删除旧 generated registry 与 legacy 命名实现，不保留第二份执行路径。
- 补齐 workspace boundary 盲区：真实 `apps/*` 现在禁止导入 legacy root 的 `app/components/config/drizzle/lib/pages/public/server/styles/types`；这会在 Phase 2.5C 阻止 `apps/api -> root app/api` 或 `apps/api -> root lib/server` 假边界。

## 未完成项与临时兼容

- 23 条 `legacyRouteIds` 仍由 Hono 动态加载 root Next route module；Phase 2.5B 只有在它们全部进入职责清晰的 shared service + adapter 边界、Hono 核心入口不再依赖未来 Web 内部源码后才可结束。
