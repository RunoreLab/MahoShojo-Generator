## 主要实现

- 新增 `packages/contracts`，导出 Arena Room shared config、snapshot/event、typed Proposal、GenerationBridge、generation snapshot、版本矩阵、错误契约、限制常量与 raw frame parser。
- DataCardRef 强制 `versionToken`，并按 character/scenario/material 收窄；collection key 必须与 ref/stub identity 对应，host-local entry 不保留同义双 key/guidance。
- Room snapshot 强制唯一 active host、唯一成员/Proposal ID、Proposal room/author 关联与成员 pending 上限；terminal stale Proposal 不占 pending quota。
- control/story parser 的运行时通道和 TypeScript 返回类型保持一致；story 的 attempt 由 Room runtime 分配唯一 `generationId` 并与 active generation 比对，不扩张权威 `generationId + chunkSeq` envelope。
- current/old/new peer、snapshot、event、GenerationBridge fixtures 明确隔离版本差异；v0/v2 snapshot payload 除版本字段外与 v1 相同。
- 更新 `packages/README.md`，说明 config/contracts 的职责、source-export 边界与不可包含的 runtime 能力。
