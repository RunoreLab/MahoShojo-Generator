## 3. 关键设计与实现

### 3.1 Typed subscription 是唯一 generation producer seam

`ArenaGenerationService.createSubscription()` 返回带稳定 generation/request identity、原始 Redis event
ID、headers 与 typed `GenerationStreamEvent` 的订阅。既有 `create()` 只把 typed events 编码为公开 SSE。
live replay、snapshot bootstrap、D1/R2 terminal fallback、cursor 单调与 single-producer reservation
继续由 G25R service 持有，companion 不复制 Provider/finalization pipeline。

### 3.2 Non-stream projector 与本地卡片投影

两条 non-stream route 收集同一 typed event 序列，投影为兼容的 `report`、`updatedCombatants`、
`adjudicationResults`、`impacts` 与 `generationId` JSON。stream/terminal/projection 失败不会返回半成品成功，
并保留已分配的 stable generation ID。

本地 `updatedCombatants` 只在服务器重新验证 native signature 后重签；arena history/current state 以
generation ID 与 base revision 识别重复应用，世界线 ID 和发生时间对 replay 稳定。它不提升客户端
`isNative`，不写服务器 DataCard authority。

### 3.3 Session typed orchestration

连续战报的 plan/context/prompt/digest 纯逻辑进入 domain package，Web 原 import path 只 re-export。
session service 生成 server-signed internal guidance，直接映射 typed events 并保留上游 event ID；
`session_meta`/`chapter_digest` 是 session 自有事件。subscriber disconnect 只取消该 reader，不取消
generation producer；lease、reader 与 lifecycle telemetry 均 exactly-once 收口。typed error、incomplete
EOF、reader rejection 与 cancel 有独立回归测试。

### 3.4 Authority、兼容与 telemetry

- actor 仍由 G25R Legacy/Better Auth/activity/anonymous resolver 判定；请求体 user id 不成为权威；
- public `internalGuidance` 被删除，session/PVP 仅通过服务器签名 header 恢复受信引导；
- BYOK key 只进入 Provider boundary，不进入 semantic hash、事件、telemetry、D1 extra 或响应；
- public `isDowngrade` 保持 `custom > strict-ranked > downgrade lite > default` 模型优先级；
- adapter response marker 与 structured observation 都使用 runtime composition 派生的受信 operation/
  placement，不接受 payload 自报；session observation 等待 typed terminal，而不是把 HTTP 200 建链伪装成功。
