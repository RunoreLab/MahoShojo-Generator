## 本批完成

- 新增 `@mahoshojo/ai-core`：
  - strict `AiStreamEvent` 覆盖 `started / text-delta / reasoning-delta / usage / result`；
  - 每个事件携带 request ID、AI contract version、execution mode 和连续 sequence；terminal result 的 identity 必须与事件一致；
  - `collectAiStreamResult` 拒绝缺少/重复 started、序号跳变、跨请求/版本/模式、terminal 后事件及缺失 terminal；上游迭代器异常映射为脱敏 `source-failed`，不透传 raw error、event 或 delta；
  - stream 默认限制为最多 100,000 个事件、单 delta 65,536 字符、累计 delta 1,000,000 字符、terminal 正文 1,000,000 字符和 structured result 10,000 节点，超限返回稳定 `limit-exceeded`；
  - 迁入既有 `parseStructuredJsonWithSchema` 与 `buildStructuredJsonInstructionFromZodSchema`，保留 JSON candidate、repair、unwrap、key normalization、schema coercion 和 telemetry 行为；
  - 在 schema/coercion 前增加 250,000 字符、64 层、10,000 节点的默认硬限制，并拒绝任意深度的 `__proto__ / prototype / constructor`；错误只暴露稳定 code，不回显 raw output、repair error 或 Zod issue；该兼容 parser 公共面显式接受 `zod/v3` schema，不将尚未实现的 Zod v4 repair adapter 描述为已支持。
- 新增 `@mahoshojo/ai-direct`，仅导出 accepted 架构中的 runtime-neutral `AiExecutionPort`：`execute(request)` 与 `stream(request, signal)`。
- 根 Web 的 `lib/ai/utils/structured-json` 改为兼容转发；现有 `lib/ai.ts` 生产生成路径继续使用相同入口，实际实现来自 `@mahoshojo/ai-core/structured-json`。
- 结构化 JSON 行为测试迁入 package，自身可独立运行；根测试保留 compatibility export identity 检查。
- `package.json`、workspace lockfile 与 package README 已同步，`ai-core`/`ai-direct` 使用显式 exports，不引入 app、框架、Provider、数据库、环境变量或服务器秘密。
