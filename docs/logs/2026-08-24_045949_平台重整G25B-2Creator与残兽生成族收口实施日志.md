## Objective 与 stopping condition

本 Goal 将 Creator 与残兽 generate/stream 四条深 composition route 从 Hono `legacy-next` 收口为 `@mahoshojo/hosted-api` shared application service + root runtime composition + Next/Hono thin adapter。四条 route 不再由 Hono 动态导入 Next handler，Next wrapper 与 Hono adapter 绑定同一默认 service；Hono registry 保持 24 条 capability，不扩面，由 `6 shared / 18 legacy` 变为 `10 shared / 14 legacy`。

以下 stopping condition 已满足：

- Creator build-rule runtime results、server recompute、persisted `creationInputs` / `buildState` 与 request validation 保持 contract；
- 残兽 questionnaire preset/DataCard、`nativeAllowed`、required answer、lore、原生签名与既有 wire 保持 contract；
- 非流式/流式 Provider resolution、限速、安全、AI meta、活动记录、签名、原始 stream body/header 和 abort signal 均有 package、adapter 或真实 Hono dispatcher 证据；
- manifest、dependency boundary、package/server/workspace、Next/OpenNext build 与独立 review 满足 `GOAL-061`。

## Capability 决策

实际从 `legacy-next` 迁移到 `shared-service` 的 capability：

- `creator/generate`；
- `creator/generate-stream`；
- `generate-canshou`；
- `generate-canshou-stream`。

本 Goal 没有 capability 退出 Hono。Creator/残兽仍属于官方 Hosted 生成：服务器承担 Provider secret、成本/限速、安全、原生 questionnaire/DataCard 复核、build-rule 事实计算、签名与活动审计；两条 stream 还需要长连接和 abort 传播。当前没有逐 capability 证据证明退出 Hono 会更可靠或显著降低成本，因此保留 Hono 主执行面，同时保留 Next/OpenNext 同 business core 的 DR adapter。

## 实现与设计

- `@mahoshojo/hosted-api` 新增显式 Creator/残兽 service factory，并以 `questionnaire-generation` pipeline 表达 prepare、Provider、rate、safety、generate、activity、response 的 route-specific 顺序与短路；package 只依赖 Web Standards/Zod，不导入 Next、Hono、数据库、环境变量或 secret。
- 根 `lib/hosted-api/*` 提供四个唯一默认 runtime composition，注入现有 AI、Provider、rate-limit、安全、questionnaire/DataCard、build-rule、签名、活动与 logger 实现；四个 Next handler 变为 thin export，四个 Hono adapter 引用同一实例。
- 共用 questionnaire runtime 负责 selection/questionnaire 规范化、安全 preset path、DataCard、`nativeAllowed`、required questionnaire、lore、答案解析与长度限制；残兽旧 stream 对重复 `questionId` 的 first-match 语义显式命名为 `legacy-first-match`，未借重构改变行为。
- Creator 非流式保留 Provider 在 rate/safety 前解析；Creator stream 与残兽两路保留 rate -> safety -> Provider。各 route 的 malformed JSON、正常拒绝、busy error 与 stream response wire 分别保留。
- `config/hono-api-routes.json` 与生成 registry 更新为 10 shared / 14 legacy；未新增 route、生产依赖、跨 runtime replay 或持久化格式。

没有证据要求推翻 accepted ADR，故未新增 superseding ADR。权威 topic、主 Goal 计划、`packages/README.md` 与 `server/README.md` 已同步当前 10/14 事实；详细原子步骤见 [G25B-2 实施计划](../plans/2026-08-24_043641_G25B-2Creator与残兽生成族shared-service收口实施计划.md)。
