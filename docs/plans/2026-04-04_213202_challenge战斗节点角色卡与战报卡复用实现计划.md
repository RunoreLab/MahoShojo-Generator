# Challenge 战斗节点角色卡与战报卡复用 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `/challenge` 的战斗、精英、Boss 节点复用现有角色卡组件和竞技场流式战报卡，支持图片导出与 Markdown 导出，并在无法补查原卡时稳定回退为通用角色卡快照。

**Architecture:** 新增一层挑战专用的敌方展示解析器，把 `enemySnapshot` 解析成“原卡模板展示”或“通用角色卡快照”；控制器维护敌方展示状态与战报卡状态；节点页只消费稳定 props，并把 AI 流式正文、reasoning、telemetry 直接交给 `StreamingBattleReportCard`。页面级图片预览 modal 复用竞技场既有承接方式。

**Tech Stack:** Next.js Pages Router、React 19、TypeScript strict、Bun test、Tailwind 4、现有角色卡组件、现有 `StreamingBattleReportCard`

```tsx
export function ChallengeEnemyCardSection(props: {
  state: ChallengeEnemyDisplayState | null;
  onSaveImage?: (imageUrl: string) => void;
}) {
  if (!props.state || props.state.status === 'idle') return null;
  if (props.state.status === 'loading') return <div>正在解析敌方角色卡...</div>;
  if (props.state.status === 'error') return <div>{props.state.message}</div>;
  if (!props.state.card) return null;

  if (props.state.template === 'magical-girl') {
    return <MagicalGirlCard magicalGirl={props.state.card as any} gradientStyle="linear-gradient(...)" onSaveImage={props.onSaveImage} />;
  }
  if (props.state.template === 'canshou') {
    return <CanshouCard canshou={props.state.card as any} onSaveImage={props.onSaveImage} />;
  }
  return <GeneralCharacterCard general={props.state.card as any} onSaveImage={props.onSaveImage} />;
}
```
