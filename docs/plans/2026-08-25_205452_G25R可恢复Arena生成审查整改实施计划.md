状态：`active`

## 1. 交付边界

本计划闭合 `f100413ebdd74cf576c2379a15aa854f7aa86088` 审查确认的四项 cutover blocker：

1. post-claim finalization 失败不得改写真实 Provider terminal；
2. initial POST 结果未知时不得 blind replay；
3. content-policy 命中必须显式取消 server-owned producer；
4. reused create 必须复用 generation-scoped 随机 metadata。

每项先增加能以预期原因失败的回归测试，再做最小实现、运行受影响 workspace 的测试/类型检查/lint，
最后形成一个原子提交。不得在本计划中执行生产部署、远程迁移、DNS/LB 切流或 secret 变更。

## 3. 提交二：传播 content-policy cancel

### 测试先行

- `components/arena/hooks/useBattleEngine` 的就近 hook/行为测试：敏感输出分支 abort generation controller，

## 5. 提交四：冻结 generation-scoped metadata

### 测试先行

- replay-store 测试：reservation `created` 原子保存 seed，`reused` 返回同一 seed，`conflict` 不泄漏 seed；
  旧 entry 缺 seed 时返回兼容的 `undefined`，不得生成替代 seed。
- mixed-version 测试：新实例读取旧 seedless reservation 时只恢复并省略 metadata；旧 preparation 路径读取新
  seeded reservation 时必须 conflict，不得返回重新生成的 header 或启动 Provider。
- `packages/hosted-api/tests/arena-generation-service.test.ts`：deterministic preflight 先于 reserve，只有
  `created` 启动 Provider；created/reused 使用同一 seed materialize；materialization 在 Provider 前失败时只释放
  自己的 reservation。
- `packages/hosted-runtime/tests/arena-generation-runtime.test.ts` 与 prompt 测试：相同 seed 生成相同 adjudication、
  reporter metadata 和 Provider prompt；不同 seed 可产生合法差异；相关路径不调用全局 `Math.random()`。
- fault-injection：并发/重复 create 的响应 header 与唯一 Provider payload 一致，无 secret、prompt 或完整 input 写入 Redis。
- runtime/service 贯通测试：真实 adjudication 与 reporter materialization 生成的 response header 必须与唯一一次
  Provider prompt 使用同一裁定结果。

先运行上述新增用例，确认 reused 路径会 reroll 且 reservation 不携带 seed。

### 实现

- 将 hosted executor preparation 拆为 deterministic preflight 和 seed materialization；
- server 使用 CSPRNG 生成带版本 seed candidate，reservation owner 原子冻结；
- 对 seeded reservation hash 增加固定协议域，使旧 preparation 路径在滚动部署期间 fail closed；新实例仅在
  actor-owned state 证明 legacy hash 相同时兼容旧 seedless reservation；
- 修改 memory/Redis replay store 的 reservation state/result，optional-expand 解析旧 entry；
- 在 `packages/hosted-runtime/src/arena-generation/runtime.ts` 注入 deterministic PRNG；
- 修改 `packages/hosted-runtime/src/arena-generation/prompt.ts` 及 adjudication/reporter selector，移除该路径对
  全局 `Math.random()` 的依赖；
- reused 无 seed 的旧 entry只返回可恢复状态并省略随机 presentation metadata，不 reroll、不启动 Provider。
