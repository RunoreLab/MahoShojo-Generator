# /challenge 界面英文文案中文化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `/challenge` 页面暴露给用户的不合适英文展示文案替换为中文，同时保持内部枚举和接口不变。

**Architecture:** 仅在挑战页面展示层增加中文映射，避免修改 `StrengthTier`、`riskHint`、`rewardHint` 等内部协议值。通过组件级测试锁定 SSR 输出，防止后续再次把英文枚举直接暴露到界面。

**Tech Stack:** Next.js, React, TypeScript, Bun test
