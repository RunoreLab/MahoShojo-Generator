# 卡牌工坊插图裁剪与数据卡入口实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为卡牌工坊加入可选插图比例、可拖拽/缩放的裁剪工作台，并复用线上数据卡浏览模态框完成数据卡选择输入。

**Architecture:** 将图片比例、cover 布局和位移边界收敛到可测试的 `lib/game-card/image-crop.ts`；新增受控 `ImageCropEditor` 处理指针交互；`CardForgePage` 只协调输入、裁剪状态与 `BattleDataModal`。`GameCardFace` 和卡牌元数据 schema 共享同一套比例/变换类型，保证预览、导出和重新导入一致。

**Tech Stack:** Next.js App Router、React 19、TypeScript strict、Tailwind 4、现有 `BattleDataModal`、Vitest、浏览器 Pointer Events/ResizeObserver。

在 `lib/game-card/image-crop.ts` 提供：

```ts
export type ImageSize = { width: number; height: number };
export type CropViewport = { width: number; height: number };
export type CoverLayout = {
  width: number;
  height: number;
  maxPanX: number;
  maxPanY: number;
};

export const DEFAULT_GAME_CARD_IMAGE_ASPECT_RATIO: GameCardImageAspectRatio = '4:3';
export const DEFAULT_IMAGE_TRANSFORM: ImageTransform = { scale: 1, x: 0, y: 0 };

export const getAspectRatioValue = (value: GameCardImageAspectRatio): number => {
  const [width, height] = value.split(':').map(Number);
  return width / height;
};

export const getCoverLayout = (
  image: ImageSize,
  viewport: CropViewport,
  scale: number,
): CoverLayout => {
  const baseScale = Math.max(viewport.width / image.width, viewport.height / image.height);
  const width = image.width * baseScale * scale;
  const height = image.height * baseScale * scale;
  return {
    width,
    height,
    maxPanX: Math.max(0, (width - viewport.width) / 2),
    maxPanY: Math.max(0, (height - viewport.height) / 2),
  };
};

export const clampImageTransform = (transform: ImageTransform, layout: CoverLayout): ImageTransform => ({
  scale: Math.min(3, Math.max(1, transform.scale)),
  x: layout.maxPanX > 0 ? Math.min(1, Math.max(-1, transform.x)) : 0,
  y: layout.maxPanY > 0 ? Math.min(1, Math.max(-1, transform.y)) : 0,
});
```

`getCoverLayout` 的 `maxPanX/maxPanY` 以图片中心为原点；渲染层将归一化的 `x/y` 乘以对应最大位移。`normalizeImageTransform` 对导入 JSON 做有限数字、范围和默认值校验，禁止旧/外部 JSON 让组件进入非法状态。

## Task 3: 实现受控图片裁剪编辑器

**Files:**

- Create: `components/card-forge/ImageCropEditor.tsx`

- [ ] **Step 1: 创建受控组件骨架并保留失败类型检查**

组件 props 固定为：

```ts
interface ImageCropEditorProps {
  imageUrl: string;
  imageAspectRatio: GameCardImageAspectRatio;
  imageTransform: ImageTransform;
  onAspectRatioChange: (value: GameCardImageAspectRatio) => void;
  onTransformChange: (value: ImageTransform) => void;
  onReset: () => void;
}
```

组件使用 `ResizeObserver` 获取视窗尺寸，`HTMLImageElement.naturalWidth/naturalHeight` 获取图片尺寸，通过 `getCoverLayout` 计算实际绘制宽高和最大位移。图片以绝对定位居中渲染：

```tsx
<img
  src={imageUrl}
  alt="插图裁剪预览"
  draggable={false}
  style={{
    width: layout.width,
    height: layout.height,
    left: '50%',
    top: '50%',
    transform: `translate(-50%, -50%) translate(${imageTransform.x * layout.maxPanX}px, ${imageTransform.y * layout.maxPanY}px)`,
  }}
/>
```

视窗叠加三分网格，且设置 `touch-action: none`。指针按下时保存 pointer 起点并调用 `setPointerCapture`；移动时将像素增量换算成归一化 `x/y`，再用 `clampImageTransform` 限制范围。

- [ ] **Step 2: 增加缩放、捏合和键盘可达控件**

缩放滑块范围固定为 `1` 到 `3`、步进 `0.05`；滚轮按 `0.1` 调整。两个 pointer 同时存在时保存初始距离，按距离变化调整 scale，并在每次变化后重新限制 transform。精细调整使用两个 range：

```tsx
<input aria-label="图片水平位置" type="range" min={-1} max={1} step={0.01} ... />
<input aria-label="图片垂直位置" type="range" min={-1} max={1} step={0.01} ... />
```

比例 `<select>` 的选项来自 `GAME_CARD_IMAGE_ASPECT_RATIOS`，重置按钮带 `type="button"` 和 `aria-label="重置图片裁剪"`。
