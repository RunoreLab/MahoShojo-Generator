- [ ] **Step 1: 新建废土行迹问卷预设 JSON，写入题目与 lore**

关键内容：

```json
{
  "id": "magical-girl-wastetrace-traveler",
  "kind": "magical-girl",
  "title": "废土行迹世界观向：旅人角色问卷",
  "description": "不需要预先了解设定，按直觉作答即可；推荐用于创作台 / 通用角色卡（Markdown）",
  "version": "1.0.0",
  "nativeAllowed": true,
  "questions": [
    {
      "id": "WT-01",
      "question": "你的名字、代号，或者路上别人怎么称呼你？"
    }
  ]
}
```

要求：

- 题量控制在轻中量，约 15~17 题。
- 题型以 `select + allowCustom` 和短文本为主。
- `loreMarkdown` 必须明确：
  - 世界结构为 `聚居地 + 通路 + 危险区`
  - 角色优先按旅人视角生成
  - 输出目标是通用角色卡，不套魔法少女术语
  - 地点既可引用已有设定，也可在既有地域/聚居地/势力约束内合理补完
  - `nativeAllowed` 按业务要求设为 `true`
