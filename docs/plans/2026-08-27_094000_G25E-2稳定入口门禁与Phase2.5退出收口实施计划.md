# G25E-2 稳定入口门禁与 Phase 2.5 退出收口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: 实现阶段按风险使用 test-driven-development，完成前使用 verification-before-completion；用户已要求在当前工作区执行，不创建 worktree。

**Goal:** 修复未纳管 stable origin 会被生产客户端启用的问题，撤回无独立信任价值的 D1 Gateway allowlist，并以可审计证据完成 G25E-2 与 Phase 2.5 退出收口。

**Architecture:** Hosted DR manifest 同时声明 stable control-plane provisioning 与 production same-origin fallback artifact readiness；客户端只消费不含 physical origin 的生成投影，并由显式 compile-time deployment target 决定 stable、preview、local-disabled 三种互斥放置。D1 Gateway 使用单一 trusted parser 校验 HTTPS exact root origin 与 transport credential，不再接受同一 runtime env owner 自证 allowlist。

**Tech Stack:** TypeScript、Node.js ESM、Vitest、Next.js/OpenNext、Hono、pnpm workspace、GitHub Actions、JSON machine contract。

- [ ] **Step 3: 先写客户端 deployment-target 失败测试**

  测试公开 resolver 返回完整 placement：

  ```ts
  { enabled: false, origin: hostedDrStableOrigin, target: 'local' }
  { enabled: true, origin: hostedDrPreviewOrigin, target: 'preview' }
  ```

  production + `not-provisioned/deferred`、production + preview origin、preview + stable origin、未知 target 必须抛错；未声明 target 不得读取 `NODE_ENV` 推断 production，而是 local-disabled；显式 loopback local 才启用跨 origin。

- [ ] **Step 4: 运行客户端 RED**

  Expected: FAIL，原因是当前 resolver 仍只返回 origin、默认 enabled=true 且回退到 `NODE_ENV`。

- [ ] **Step 5: 实现最小 machine contract 与安全投影**

  在 manifest 增加：

  ```json
  "productionFallback": {
    "mode": "same-origin-next",
    "artifactReadiness": "deferred",
    "productionPlacement": "not-observed"
  }
  ```

  生成投影只增加 `hostedDrControlPlaneProvisioning` 与 `hostedDrProductionFallbackReadiness`，不得生成 `primaryOrigin`/`drOrigin`。validator 必须双向校验投影，并在 fallback 标为 verified 时拒绝任何客户端可能放置到同源但 `drMode=fail-closed` 的 operation。

- [ ] **Step 6: 实现显式 target resolver**

  `apps/web/config/hono-api.ts` 只接受 `production|preview|local|test`。未声明 target 归一为 `local`，不使用 `NODE_ENV`。规则：

  ```text
  production + provisioning=production + valid evidence -> stable enabled
  production + provisioning!=production + fallback=verified -> same-origin disabled
  production + 其他状态 -> throw
  preview + explicit previewOrigin -> preview enabled
  local/test + no origin -> same-origin disabled
  local/test + explicit loopback -> loopback enabled
  ```

  production/preview 不得互相接受对方 origin；physical origin 永远不进入投影。
