## 1. 执行原则

- 先写失败测试，再做最小实现；每个 checkpoint 独立可回滚。
- 复用既有 Proposal schema/diff/selection/apply/state-machine，不建立第二套 JSON Patch 或 client authority。
- API 只读取 DataCard metadata；卡正文、private payload、Provider secret 不进入 Room plane。
- 每批运行受影响 package 的 targeted tests + typecheck/lint；跨 package contract 完成后运行 build/boundary。
- production/preview flag、远程 D1/Redis、secret、release 与 push 均不在本计划授权范围。

测试 old epoch/role/kick、same-target conflict、dependency/atomic partial、concurrency/CAS、Redis unavailable/unknown 与 no event/
no ack before checkpoint。

### GMR08-D：Hono routes 与真实 composition

### GMR08-E：Web client、controller 与 unknown/replay

unknown no-replay，则停止实现并提交需人工裁决的提案，不移动验收标准。普通可逆实现选择、测试修复和原子重构不等待确认。
