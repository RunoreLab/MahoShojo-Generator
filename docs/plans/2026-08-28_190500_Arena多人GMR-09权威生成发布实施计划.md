## 1. 执行原则

- 先写失败测试，再做最小实现；每个 checkpoint 可独立回滚。
- 复用 G25R generation reservation/lease/replay/finalization，不复制 AI lifecycle、SSE parser 或 D1/R2 persistence。
- Room checkpoint/wire 只保存 frozen safe metadata；完整 host payload与 Provider secret只临时交给 generation service。
- 所有 mutation 均保持 epoch/current generation/capability fence；unknown 先对账，不自动重放。
- 每批运行受影响 package targeted tests + build/lint；跨 package完成后运行真实 Redis和 workspace gates。

## 3. Stop / blocker 规则

若证据要求放宽 server authority、PVP/actor ownership、secret隔离、generation single producer、epoch/attempt fence、D1/R2 final
authority或 unknown no-blind-replay，则停止实现并形成需人工裁决的完整提案，不移动验收标准。普通可逆接口、队列、projection、
恢复与测试选择自行决策。
