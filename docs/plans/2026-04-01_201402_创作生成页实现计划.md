# 创作生成页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于已批准 spec 落地 `/creator` 创作生成页，在复用 `/details` 与 `/free` 现有能力的前提下，新增多规则车卡输入、独立 creator API，以及 `creationInputs` / `buildState` 持久化链路。

**Architecture:** 页面层以 [`pages/details.tsx`](/home/notuhao/code/MahoShojo-Generator/pages/details.tsx) 为问卷工作流母版，补入来自 [`pages/free.tsx`](/home/notuhao/code/MahoShojo-Generator/pages/free.tsx) 的模板选择和多模板生成边界。规则层新增文件化 build-rule preset、运行时校验/派生/投影模块；服务端新增 creator 专用 API，统一整理 prompt 与结构化留痕。结构化数据卡 schema、验证与转换链路先扩容，再接入保存与显示。

**Tech Stack:** Next.js Pages Router, React 19, TypeScript strict, Bun test, Zod v3, Cloudflare Edge Runtime, existing AI SDK wrappers, existing questionnaire engine.

```ts
export function evaluateBuildRuleState(input) {
  const blockResults = normalizeBlockResults(input.inputs);
  const derived = {
    HP: Math.ceil((blockResults.coreAttributes.CON + blockResults.coreAttributes.STR) / 10),
    MP: Math.ceil(blockResults.coreAttributes.MAG / 4),
    Radiance: Math.ceil(blockResults.coreAttributes.WILL / 5),
  };
  const validationSummary = validateBudgetsAndRequiredBlocks(blockResults, derived);
  return { ruleId: input.ruleId, version: '1.0.0', blockResults, derived, validationSummary };
}
```

```ts
export function projectBuildRulesForPrompt(params) {
  const primary = params.rules.find((rule) => rule.ruleId === params.primaryRuleId) ?? null;
  return {
    primary: primary ? buildPrimaryStructuredProjection(primary, params.template) : null,
    references: params.rules.filter((rule) => rule.ruleId !== params.primaryRuleId).map(buildReferenceProjection),
  };
}
```

```ts
export function validateCreatorRequest(input) {
  if (input.buildRules.length > 0 && !input.primaryRuleId) throw new Error('PRIMARY_RULE_REQUIRED');
  if (input.buildRules.length === 0 && input.questionnaires.length === 0 && !input.freeformBrief.trim()) {
    throw new Error('FREEFORM_BRIEF_REQUIRED');
  }
}

export function buildCreatorPromptInput(input) {
  return {
    userIntent: input.freeformBrief?.trim() ?? '',
    questionnaireSummary: summarizeQuestionnaires(input.questionnaires, input.questionnaireAnswers),
    buildRuleProjection: projectBuildRulesForPrompt(input.buildStateLike),
  };
}
```
