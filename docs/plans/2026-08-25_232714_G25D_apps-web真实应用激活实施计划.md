完成 `apps/web` behavior-equivalent relocation 与 root ownership 收口。只有以下条件全部为 `PASS` 或 `NOT_APPLICABLE` 才完成：

- `apps/web` 自有 source/manifest/build/test/lint/static/env/deploy；
- root 不再持有 Web/Hono/D1 runtime dependencies，只保留 workspace orchestration、统一 gates 与跨 runtime data tooling；
- alias、tests、Next/OpenNext/Wrangler/Cloudflare workflow 从 app cwd 等价工作；
- Legacy/Better Auth、schema、Arena v1 authority/wire/resume/replay/data semantics 无变化；
- Next DR adapter seam 保留，自动 failover 未启用；
- 不包含 local-library/Admin/UI 重构；
- targeted、Cloudflare build、root/workspace tests、boundary gate、no-new-regression 通过；
- independent review 的 Critical/Important 全部关闭，Minor 修复或记录非阻塞理由；
- 变更形成可独立 revert 的原子 checkpoint，主题与实施日志反映最终事实。
