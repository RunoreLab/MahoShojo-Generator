# Battle Story Character Parameters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 统一竞技场故事生成提示链路，忽略 `creationInputs`，仅以“角色参数”名义向模型暴露 `buildState`。

**Architecture:** 在提示词构建边界增加一层仅供故事生成使用的数据裁剪与重命名逻辑。普通战报与连续战报会话共享同一规则：删除 `creationInputs`，保留并重命名 `buildState` 为“角色参数”，同时保持既有的历战记录与当前状态读取开关。

**Tech Stack:** Next.js, TypeScript, Bun test
