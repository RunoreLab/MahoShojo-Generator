# 消除排位结算循环实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让排位结算只发生在生成主链路，由 SSE 直接下发安全 DTO，并将 generation-ranking GET 收敛为可缓存的纯读取恢复接口。

**Architecture:** 抽取一个服务端 ranking 查询/DTO mapper，统一负责将内部 eligibility snapshot、combatants、rating events 和 ratings 映射为公共响应。生成完成后先结算、再调用该 mapper 并发送 `ranking` SSE；GET 只调用 mapper，不再触发任何写操作。客户端把 SSE 结果写入 TanStack Query 缓存，只有缺少 SSE 终态结果时才启用恢复轮询。

**Tech Stack:** Next.js 15 App Router、TypeScript strict、Cloudflare Workers/D1、React 19、TanStack Query 5、Vitest。
