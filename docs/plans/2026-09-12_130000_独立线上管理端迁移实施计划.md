# 独立线上管理端迁移实施计划

状态：`accepted`；执行状态：本地代码迁移完成，生产待受控验收
日期：2026-09-12；基线：`2c5318e7`；旧功能来源：`origin/feat/admin@73cbc27c`。

## 已确认设计

本计划由维护者确认，正式开始平台 Phase 3 Admin 业务迁移。继承 [Admin 安全规格](../specs/2026-08-29_Admin回归安全与迁移规格.md) 与 [复杂度预算 ADR](../decisions/2026-09-01_193200_平台复杂度预算与故障降级决策.md)，不恢复历史源码摘要、证据注册或 G3-P0 禁止业务能力的临时限制。

- 新业务管理入口为 `admin.mahoshojo.colanns.me`。`homura-admin.colanns.me` 是 Arcane / Local Docker 管理入口，与本项目业务后台不同；旧材料中把两者混用的推断不再适用。
- 独立 React/esbuild UI 与 Hono Worker BFF 同源部署。Access 采用本人邮箱验证码与精确允许名单，Worker 验证 JWT，D1 principal 使用 issuer/subject/kind 逐请求授权。
- Worker-first 保护静态资源与 API，关闭 workers.dev/preview URLs。无公开 bootstrap、通用 SQL、Provider 密钥编辑或部署控制台。
- canonical Drizzle schema 和纯 DB factory 提取到 hosted-runtime，Web 保留兼容出口；业务 repository/service 按真实复用逐域提取。
- 新业务协议使用 `/api/admin/v1/`，列表默认 50、上限 100，显式 DTO/字段过滤；用户凭据不出服务端。
- D1 mutation、幂等记录、通知和成功审计同批次原子写入，CAS 失败禁止后续副作用；跨 R2/AI 副作用使用持久作业、Queue 和有界恢复扫描。
- 审计保留 180 天；未完成作业关联记录在终结前保留。私有导出默认 24 小时过期，BFF 下载重新授权。
- 原生性、审核、排位继续采用当前 accepted 规则；AI 审核只给建议，不自动裁决。
- AI 审核后续补齐统一预设渠道选择：`system` 下可选默认或任意已配置模型；BYOK 密钥仅本次同源请求内存持有。系统继续 Queue，BYOK 采用请求内执行加持久操作/结果查询；其队列恢复仅终结丢失凭据的未执行作业，不能重放付费请求。这是对上述跨 AI 作业要求的执行方式细化，无凭据存储设施。
- AI 建议通过仅在输入完整且版本匹配时预填，通过/拒绝均经人工确认；拒绝建议默认不填。单次最多 10 项，待审更新绑定自身与父卡版本。内容对照及选中导出复用已有读模型、CAS 与私有作业，不扩大到其他管理域。
- 旧 PVP 保留受控管理写入，新 Arena 多人仅只读观测，不能混用 D1 PVP 与 Redis Room authority。

## 迁移映射与提交单位

旧分支的 22 个页面入口、59 个 API 路径按业务行为迁移，不要求复刻重复页面或旧安全缺陷。

| 顺序 | 范围 | 处置与验收 |
| --- | --- | --- |
| 1 | 文档、域名、分支 | 当前计划与导航，独立分支，保留旧 ref |
| 2 | schema / DB factory | 机械提取；零数据库结构变化 |
| 3 | 安全壳 / principal / audit | 独立构建、Access/RBAC/CSRF、bootstrap/revoke、deny-all 回滚 |
| 4 | dashboard、users、user-accounts、data-cards | 显式投影、有界分页、真实只读闭环；首次上线节点 |
| 5 | 内容与更新审核、公开/封禁/推荐、问卷原生许可、标签 | 审计、CAS、幂等、通知；标签单独提交 |
| 6 | 消息、举报、申诉、众裁、巡查员 | 共享状态转换，晚到结果不覆盖人工裁决，通知不重复 |
| 7 | 用户属性、徽章、兑换码 | 逐域迁移，安全字段白名单与唯一约束 |
| 8 | 活跃分析、快照、AI可用性、AI审核 | dry-run 不写，历史回填最多30天且注明估算；AI付费请求不盲重放 |
| 9 | ratings、events、risk、generation、旧 PVP | 当前评分/签名规则；恢复不先删除状态再CAS |
| 10 | 新 Arena Room 观测 | Hono 窄化只读接口；独立服务JWT，不写TTL/actor/checkpoint |
| 11 | 导出、大对象、业务维护 | 私有下载、范围预览、作业恢复、终态/保留期保护 |
| 12 | 最终验证与上线记录 | 完整CI/build、恢复与绕过验证；不将未上线写成已上线 |

维护范围：`battle_report_generations`、`battle_report_generation_combatants`、`arena_rating_events`、`pvp_rounds`、`pvp_room_chat_messages`、`pvp_room_hands`、`pvp_room_submissions`、`pvp_room_card_snapshots`、`pvp_round_choices`、`large_objects` 按终态与引用约束重写。`auth_audit_logs`、`auth_password_reset_tokens`、`ba_verification`、`user_auth_links` 仅必要安全计数，不进入通用清理执行列表。

旧信任假设统一退出：localhost 即可信、整行用户返回、匿名 catch-all、dry-run 建表、审计失败继续删除、R2 失败继续删元数据、前端隐藏即授权。

## 验证与执行状态

每批先做针对性行为测试和边界检查，再原子提交；机械提取、migration 与业务行为分开。最终运行 `ci:verify`、`build:cf`、API bundle/runtime 验证、Admin build/dry-run、本地 D1 migration/恢复、`git diff --check`，记录实际 warnings 与未验证项。

重点故障：未授权/错误JWT不访问业务数据、撤权生效、CSRF/XSS、CAS 0行无副作用、重复幂等键、审计故障回滚、通知一次、R2分步失败、AI未知结果不重放、只读Room无写。

生产部署、Access/credential 配置与远程 migration 在具体产物就绪后单独获得维护者确认。本地开发不等待生产配置，默认使用合成数据。按域关闭 writer、Access deny-all 或回退独立 Worker 即可回滚，不删除旧表。

当前已实施共享 schema、安全主体与审计、各业务域、独立工作台及持久作业。逐域功能去向、兼容影响、实际验证和本机环境限制见 [迁移交付记录](../migration/2026-09-12_144000_独立管理端功能迁移与交付记录.md)，生产动作和恢复验收见 [部署 runbook](../runbooks/2026-09-12_143000_独立管理端部署与恢复验收.md)。规划阶段的 47/11 项测试仅属历史基线，不代表本轮最终结果；尚未发生生产动作。不维护逐文件 hash 清单。
