# Arena 战后角色可编辑修复实施计划

日期：2026-09-01  
状态：`ACTIVE / implementation-plan`  
计划标识：`PLAN-arena-post-battle-dual-trust-v1`  
依据规格：`SPEC-arena-post-battle-dual-trust-v1`

**目标：** 在不改变 G25R 权威对账的前提下，恢复 Arena 战后角色 metadata 的手工与 AI 可编辑修复，并保证正常 repair 调用链只产生 unsigned、non-canonical 角色派生版本。

**架构：** `@mahoshojo/domain` 提供无 runtime/签名依赖的精确 generation PATCH；新的 Web AI endpoint 只生成带 roster index 的 patch；客户端负责草稿、明确确认、应用 derivative 和更新当前 session roster。旧 redo 保持退役。

客户端流程：

```text
manual meta / AI patch
  -> index-aware normalize
  -> native/canonical derivative confirmation
  -> domain dry validation
  -> missing effect explicit second confirmation (if needed)
  -> unsigned apply
  -> setCombatants + setUpdatedCombatants
  -> disable same-generation authoritative retry
```

## 5. 安全回归与交付

重点审查：

- repair 是否存在到 `applyPostBattleUpdates()`、签名实现或 D1/rating 的依赖；
- modified wrapper 是否仍携带 preset/DataCard/Room canonical identity；
- duplicate name 是否仍通过名称 `.find()` 错绑；
- history/current state 是否会猜测其它 generation；
- strict reconciliation、same-generation retry 与 Room member 权限是否退化；
- AI 草稿是否会自动应用或绕过显式确认。
