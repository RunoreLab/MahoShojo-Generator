# D1、R2、Redis 存储优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:test-driven-development` task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 让新战报正文退出 D1、在 R2 有限保留、正常过期不伪装成服务故障，并在既有 Redis TTL/budget 内提高 completed snapshot 可恢复率。

**Architecture:** D1 保留权威终态与 pointer，R2 Standard 保存 540 天候选窗口的完整正文，Redis 只保留现有 generation replay。Hono/Next 使用 typed object-store result 区分 not-found 与 temporary failure；Hono 健康检查不再每 5 秒放大 D1 readiness。

**Tech Stack:** TypeScript、Vitest、Hono、Cloudflare D1/R2、Redis、Wrangler 4.x。
