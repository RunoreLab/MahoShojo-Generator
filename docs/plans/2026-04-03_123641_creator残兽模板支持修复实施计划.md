# /creator 残兽模板支持修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `/creator` 在残兽结构化模板下正确切换问卷、生成残兽结构化结果并渲染 `CanshouCard`，同时让通用模板显示全部预设问卷。

**Architecture:** 采用“模板驱动”接线：前端按模板决定预设问卷范围与默认问卷替换策略，后端非流式接口按模板分流到魔法少女/残兽结构化 schema，结果区再按模板分发卡片组件。优先复用现有 `/api/generate-canshou` 逻辑，避免复制两套残兽业务规则。

**Tech Stack:** Next.js pages router、React 19、TypeScript、Bun test、现有 creator/questionnaire 基础设施。
