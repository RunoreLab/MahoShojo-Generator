# battle 简洁版深色模式修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 `/battle` 简洁版页面在深色模式下的白底卡片、低对比说明文字和局部浅色硬编码问题，同时保持浅色模式视觉稳定。

**Architecture:** 通过在 `BattleLitePage` 根节点引入 `battle-lite-shell` 作用域，并在 `styles/globals.css` 中增加该作用域专用的视觉 token，统一接管简洁版页面的面板、说明框、链接、按钮和模态层样式。组件层仅做最小替换，把 battle-lite 链路中已知高风险的浅色硬编码改为 token/class 驱动，不改动业务逻辑与数据流。

**Tech Stack:** Next.js Pages Router、React 19、Tailwind 4、全局 CSS 变量、Bun test、ESLint
