# 流式生成停止与安全截断 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为所有用户可见的流式生成入口增加可停止能力，并将输出敏感词命中改为“逮捕令 + 提前截断”，同时尽量把中断传递到上游模型以节约成本。

**Architecture:** 方案分三层推进。第一层在 `lib/stream/*` 增加统一的 abort 与输出安全工具，并让 AI SDK 真正接收 `abortSignal`。第二层在各 `pages/api/*-stream.ts` 与 PVP/竞技场代理链路上传递 `request.signal`。第三层在各用户可见流式页面接入停止按钮、区分手动停止与敏感词自动截断，并把当前流式内容固化为可继续保存的非完整结果。

**Tech Stack:** Next.js 15, React 19, Bun test, Edge Runtime, Vercel AI SDK 5.x
