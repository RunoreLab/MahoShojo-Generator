# Challenge 战斗判定去关键词化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 移除 `/challenge` 战斗节点里基于关键词/正则的本地胜负预判，把 `resolverEnvelope` 收缩为纯约束层，并把 system fallback 改为不读取文本语义的 deterministic baseline，同时保持现有 `playerInput` 与页面/API 输入契约不变。

**Architecture:** 生产代码只改两处核心链路：[`lib/challenge/resolver-envelope.ts`](/home/notuhao/code/MahoShojo-Generator/lib/challenge/resolver-envelope.ts) 负责删除 `recommendedOutcome`、引入 deterministic fallback 评分与去掉动作/文本驱动的固定收益；[`lib/challenge/server/adjudicate-stream.ts`](/home/notuhao/code/MahoShojo-Generator/lib/challenge/server/adjudicate-stream.ts) 负责重写裁定 prompt，让模型把 `recommendedActionId` 与 `note` 视为“待验证意图”。测试层分别锁定 envelope/fallback 语义回归和 prompt 契约，最后用现有 API / stream 测试确认输入契约未回归。

**Tech Stack:** Next.js Pages Router、Cloudflare Edge Runtime、TypeScript strict、Bun test、现有 challenge adjudication / stream meta / progression 流程
