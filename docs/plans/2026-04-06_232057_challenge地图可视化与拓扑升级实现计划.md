> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `/challenge` 地图页从节点卡片列表升级为可规划的真实路径图，并在不破坏现有 challenge 推进契约的前提下，把地图拓扑从固定骨架升级为受约束生成。

**Architecture:** 本次实现分两阶段推进。第一阶段先新增独立的地图布局 helper 与地图子组件，用“HTML 节点 + SVG 连线”重做 [`components/challenge/ChallengeMapPage.tsx`](/home/notuhao/code/MahoShojo-Generator/components/challenge/ChallengeMapPage.tsx)，但先兼容旧拓扑输出；第二阶段再升级 [`lib/challenge/map.ts`](/home/notuhao/code/MahoShojo-Generator/lib/challenge/map.ts) 的拓扑生成规则，并让新布局 helper 消费更成熟的节点/边分布。现有推进逻辑如 [`lib/challenge/progression.ts`](/home/notuhao/code/MahoShojo-Generator/lib/challenge/progression.ts) 与 [`components/challenge/hooks/useChallengeController.ts`](/home/notuhao/code/MahoShojo-Generator/components/challenge/hooks/useChallengeController.ts) 继续只依赖 `layer`、`nodeType`、`edges` 与节点可见状态，不重写 challenge 规则层。
