# G25H-1 Arena Companion AI Routes Re-entry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `arena/generate`、`generate-battle-story`、`arena/session/generate-next` 精确归位为复用 G25R typed generation core 的 Hono primary + Next DR shared services。

**Architecture:** 从现有 Arena replay reader 抽出 typed subscription，SSE 变成边缘 adapter。Non-stream projector 将同一 typed event 序列投影为兼容 JSON，session projector 在 typed event 层添加 session metadata/digest；三者共享 stable identity、single producer 和 finalization。

**Tech Stack:** TypeScript、WHATWG Request/Response/ReadableStream、Hono、Next/OpenNext、Redis Streams、D1/R2、Vitest、pnpm workspace。

---

执行方式：用户已授权同一会话自主实施，采用 `superpowers:executing-plans` inline checkpoints。用户明确
禁止创建 worktree，因此覆盖该技能的 worktree 默认；用户只要求最终独立审查，实施阶段不分派 worker。
