# 邮箱单独找回账号实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 允许用户在忘记用户名和密码时，仅凭邮箱地址发起密码找回，同时对历史重复邮箱账号保持保守处理。

**Architecture:** 调整恢复处理器为“邮箱必填、用户名可选”的识别模型。后端仅在邮箱唯一命中时自动发出重置邮件；若检测到重复邮箱，则保持统一成功响应但不发送邮件。前端找回页同步改为邮箱主入口文案，并保留对旧请求格式的兼容。

**Tech Stack:** Next.js Pages Router, Edge Runtime Route Handlers, Drizzle D1 Repository, Bun Test, React SSR tests
