> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于已批准的补充规格，为 `/creator` 先补齐规则底座与模板分流能力，再接入 `arena-trpg-lite` 简化 TRPG 规则输入、creator API 与页面交互。

**Architecture:** 继续以 [`pages/creator.tsx`](/home/notuhao/code/MahoShojo-Generator/pages/creator.tsx) 作为 `/details` 的增量改造页，但先抽入 [`pages/free.tsx`](/home/notuhao/code/MahoShojo-Generator/pages/free.tsx) 中与模板选择、流式边界、结果分流直接相关的能力。规则层新增静态预设、运行时校验和 AI 投影模块；服务端通过 `lib/creator/*` 统一请求验证、prompt 组装与结构化留痕，最终把 `creationInputs` / `buildState` 接入页面提交与结果保存链路。

**Tech Stack:** Next.js Pages Router, React 19, TypeScript strict, Bun test, Zod v3, Cloudflare Edge Runtime, 现有问卷系统与 AI SDK 包装层。

const PRESET_MAP = {
  'arena-trpg-lite': arenaTrpgLite,
} as const;

export function loadBuildRulePresetIndex() {
  return presetIndex.presets;
}

export function loadBuildRulePresetById(id: string) {
  const preset = PRESET_MAP[id as keyof typeof PRESET_MAP];
  if (!preset) throw new Error(`BUILD_RULE_PRESET_NOT_FOUND:${id}`);
  return preset;
}
