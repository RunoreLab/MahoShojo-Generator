> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `/creator` 接入 `dnd-5e-lite` 与 `coc-7e-lite` 两套经典 TRPG 规则预设，并把现有 `arena-trpg-lite` 对齐到一套可复用的规则 block / runtime / summary 基础设施上。

- [ ] **Step 3: 在默认输入初始化中按 block 类型生成基础值**

```ts
export function createDefaultBuildRuleInputs(ruleId: string): Record<string, unknown> {
  const preset = loadBuildRulePresetById(ruleId);

  return Object.fromEntries(
    preset.blocks.map((block) => {
      if (block.type === 'select') {
        const first = block.options?.[0];
        return [block.id, block.defaultValue ?? first?.value ?? ''];
      }

      if (block.type === 'stat-array' || block.type === 'number-group') {
        return [
          block.id,
          Object.fromEntries((block.fields ?? []).map((field) => [field.id, field.defaultValue ?? 0])),
        ];
      }

      if (block.type === 'multi-select') {
        return [block.id, []];
      }

      return [block.id, {}];
    })
  );
}
```
