# 角色卡角色参数实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让可保存为图片的角色卡基于 `creationInputs.buildRules` 与 `buildState.rules` 展示可切换的 `初始 / 当前` 角色参数，并在导出长图时隐藏交互控件但保留当前来源标识。

**Architecture:** 新增一层独立的角色参数解析 ViewModel，把 creator 元数据转成卡面可消费的通用展示结构；再新增一个可复用的角色参数区块组件，统一渲染 block 列表与来源切换；最后把该组件接入 `MagicalGirlCard`、`GeneralCharacterCard`、`CanshouCard`，并在截图时切换到导出模式。实现按预设 `blocks` 驱动，不绑定现有三套规则 ID，只对已知 block 类型做精确渲染，对未知 block 做保守降级。

**Tech Stack:** Next.js Pages Router、React 19、TypeScript strict、Bun test、现有 creator build-rule preset/runtime、现有角色卡截图链路 `capturePngBlob`

```ts
// lib/creator/character-parameter-view.ts
load source snapshots from creationInputs.buildRules and buildState.rules
normalize sources => [{ key: 'initial' | 'current', label: '初始' | '当前', rules }]
for each rule:
  load preset by ruleId
  walk preset.blocks in order
  map block type to display sections:
    select => use option label
    multi-select => use selected item labels
    point-buy/stat-array/number-group => use field labels + numeric values
    derived => use preset fields if present else fallback derived keys with local friendly labels
    section => use description text
    unknown => fallback key-value or skip
  append validation summary footer
set default active source => current if exists else initial
return null when no sources/rules are displayable
```

- [ ] **Step 4: 改造截图流程，确保导出态生效**

当前三张卡的截图流程只会手动隐藏 `.save-button` 与 `.logo-placeholder`，不会等待 React 重新渲染参数区块。

实现要求：
- 在截图前切换 `isExportingImage = true`
- 确保 DOM 已反映导出态后再调用 `capturePngBlob`
- 截图完成后恢复 `isExportingImage = false`

推荐实现：

```tsx
import { flushSync } from 'react-dom';

flushSync(() => setIsExportingImage(true));
await new Promise((resolve) => requestAnimationFrame(() => resolve(undefined)));
const blob = await capturePngBlob(...);
flushSync(() => setIsExportingImage(false));
```

注意：
- 不要把导出态切换做成全局状态。
- 不要移除现有 `save-button` / `logo-placeholder` 的 DOM 隐藏逻辑，参数区只是补充导出态，不替换现有截图兼容策略。
