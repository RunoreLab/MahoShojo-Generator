# G25E-1 Hosted DR 契约与稳定入口实施计划

状态：`completed`（2026-08-26）

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task in the current workspace. 本 Goal 明确禁止创建 worktree；每个 task 完成后检查 diff、运行列出的验证并形成原子提交。

**Goal:** 建立显式 DR capability/control-plane manifest、Hono/Cloudflare DatabaseProvider 一致性契约、代表性 safe/read 双入口与无需客户端重发版本的稳定逻辑入口 seam。

**Architecture:** route inventory 继续拥有 Hono placement，新的 DR manifest 拥有 replay/secret/provider/contract/activation 语义。`@mahoshojo/hosted-runtime` 提供 primary 与 D1 binding/Sessions provider，`@mahoshojo/hosted-api` 提供 readiness 与纯选择 contract；Hono/Next 只注入 runtime adapter。生产 Next adapter 由同一 guard fail closed，客户端只读取 manifest 中的 stable origin。

**Tech Stack:** TypeScript、Zod、Vitest、Hono、Next.js/OpenNext、Cloudflare D1 binding/Sessions、pnpm workspace、Node `.mjs` validator。
