# 治理后台适配实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `feat/admin` 后台补齐消息、举报案件、申诉、众查等治理域入口、基础 API、核心页面与内容管理联动。

**Architecture:** 采用“治理子域拆页 + 共享后台读模型/动作层”的方案。后台首页、仪表盘和内容管理页只保留导航与必要联动；具体治理能力落到独立 `/admin/*` 页面和 `/api/admin/*` 接口，由 `lib/admin/*` 负责聚合 service / repository / schema 数据。

**Tech Stack:** Next.js Pages Router, Edge Runtime, TypeScript, Drizzle/D1, Bun test, Tailwind
