# D5.1d-2：结果私有云副本最小实施合同

状态：实施前冻结；本文件限定已接受规格的本轮切片，不改变服务端权限或数据卡政策。

依据：[双端产品规格 DESK-PARITY-004/005、DESK-SET-002](../specs/2026-10-06_084200_双端产品对齐与设置共源规格.md)。阶段归属仍以[唯一 Desktop 计划](./2026-09-30_160100_Desktop客户端阶段实施计划.md)为准。

## 当前与目标

Web 已有 SaveToCloudButton / SaveCardModal；Desktop 已有固定 data-cards.create 原生路由与本地库上传端口，/details 结果仅本地保存。本轮只接通完成的 /details 结果显式创建新的私有云数据卡，保留现有本地保存及结果。名称最多 20、描述最多 300 字符；传输 character、name、description、完整 data、isPublic:false，不生成签名或改变来源字段。

从现有 Web SaveCardModal 提取真实受控字段与展示，Web 实际回用；鉴权、敏感词检查和导航留在宿主。复用既有模态生命周期和操作守卫，禁止依赖 useState 独自防重复。修复保存中关闭、异步准备串结果和旧容量响应。

## 传输与状态边界

- 复用 CARD_LIBRARY_ROUTES 固定 POST /api/data-cards；只追加必要的 GET /api/user-capacity typed allowlist，不提供任意代理。
- 一次提交冻结账号、credentialEpoch、结果与表单；Native expectedUserId 在发出前核对账号，迟到 401 不清除新会话。创建请求禁止自动重放。
- 只有 2xx 且 success:true 且有效非空 id 才确认成功；既有 uploader 同步收紧。
- 容量读取失败显示未知，不能当作 0 已用/默认总量。300KiB 槽位与 1MiB 正文估算不是服务器承诺：服务端还注入作者元数据并最终校验。
- 明确业务拒绝 400/401/403/413/429 保留草稿；网络、超时、无法识别的成功响应和 5xx 标记结果不确定。服务端可能先 insert 再因后续处理返回 500，不能声称未保存。
- 不确定状态禁止自动重试；提示用户检查“我的云端卡”，由用户显式决定是否再次新建。不宣称防重复或 exactly-once。
- 账号或来源更换使旧异步操作失效；旧结果不能改写新表单/成功提示。保存失败、关闭或离开均不删除本地结果。

## 非目标与验收

不实现替换、删除、公开发布、自动保存、购买槽位、服务端幂等或新签名；不更改既有 Web 这些功能的授权政策。本轮不操作真实用户云卡或生产凭据，不部署，不推默认分支。

验收覆盖两向固定 wire、Native 账号 fence/迟到 401/无 POST 重放，严格 success/id，来源和账号切换，重复点击和保存中关闭，失败保留输入，未知容量。使用 mocks/本地服务器；共享 exports 必须纳入边界检查，最终独审、完整 ci:verify 与 Rust touched gates 才可申请 feat 发布窗口。Windows/Tauri 真实图形未测项独立记录，不用单测替代。
