# 页面级本地草稿自动保存与恢复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `/scenario` 与 `/character-manager` 补齐刷新后可恢复的本地草稿能力，并沉淀一层可复用的页面级本地草稿存储边界。

**Architecture:** 采用“轻通用层 + 重页面边界”的方案：新增一个页级草稿存储工具统一处理 `localStorage` 的安全读写、版本、TTL、损坏兜底与清空，再分别为情景页和角色管理页新增专用草稿模块，承载各自的 payload 归一化与恢复优先级规则。页面本身只负责接线、自动保存时间提示与清空入口，不直接重复实现底层存储细节。

**Tech Stack:** Next.js Pages Router、React 19、TypeScript、Bun test、ESLint、浏览器 `localStorage`

---
