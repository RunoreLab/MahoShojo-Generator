# Web 包生成目标形态的作者可控示例决策

状态：`accepted`

日期：2026-09-29

决策标识：`ADR-web-package-target-example-v1`

适用范围：Prompt Projection 中目标文件结构示例的来源、预算与信任层级；以及 Arena 宿主提示中对"字数要求"的适用范围。

本 ADR 修订 [WebPackage 统一架构与后续开发规格](../specs/2026-09-22_165900_WebPackage统一架构与后续开发规格.md) §13 的 projection 形状。Package identity、Overlay 语义、渲染器权限边界与授权模型不变。

---

## 1. 背景

第三方包 `quequan-game` 的 `generation.target` 是 `static/events.json`，包内同时带了一份 36KB、65 条真实事件的 `static/events.json`，而 `generation/instructions.md` 只有 263 字节，字段列表之外没有任何形态说明；`generation/schema.json` 只约束了 5 个 required 字段，`accept`/`reject` 的 `{attr1..attr4}` 结构完全没写。

这种情况下模型很可能输出战报纯文本或 HTML，而不是事件 JSON。一种直觉做法是"把包自带的默认目标文件当示例传给模型"。实测该直觉不可用：

- 内置竞技场新闻的 base `index.html` 只有 387 字节，内容是「这里等待 AI 生成完整新闻网站。本包提供可选的样式、交互脚本、组件示例及素材，不含预制网站。」。自动注入等于教模型复现占位页。
- quequan 的 `static/events.json` 有 36KB。全量注入是一笔可观的上下文成本，而且模型可能直接照抄作者的原始事件，而不是按本场战斗重写。

## 2. 决策

### 2.1 `generation.example` 由作者显式声明

manifest 新增可选 `generation.example`（包内文件路径），语义与 `instructions` / `schema` / `assetCatalog` 一致：必须在包内存在、投影进 Prompt Projection、32 KiB byte budget 之外直接拒绝。

宿主 block 新增一句：`example`（若存在）是目标文件的一段结构示例，只说明大致形态；必须按本场实际内容重新创作，不要照抄其中的人名、情节或措辞。

`example` 落在 untrusted creator material 块内，与其余 creator 字段同级——它没有引入新的信任面，只是多了一份同类的不可信文本。规格 §13 的 projection 形状与 trust boundary 图同步更新，并写明宿主 MUST NOT 自动注入 base target。

### 2.2 数据类目标不再收到"字数要求"

Arena 宿主提示在 `web-package-target` 合约下仍然附加【字数要求】「请将故事正文的长度控制在 约600字 左右」。这条要求描述的是散文正文；当唯一输出是一份 JSON 数据文件时，它和包自己的 instructions 正面冲突，是把模型推向"输出战报纯文本"的一个直接诱因。

现在：当 output contract 是 `web-package-target` **且** target mediaType 是 `application/json` 时，不发出【字数要求】。`text/html`、`text/markdown`、`text/plain` 目标不受影响——新闻页、故事页确实需要长度指引。

【角色更新元数据】段落保留：其中的 `impacts` 数组位于 Arena control trailer 内，与目标文件是什么类型无关。

## 3. 不采用的方案

- **自动注入 base target**：见 §1，对内置预设是负收益。
- **自动注入 base target 的截断片段**：截断后的 JSON 不是合法 JSON，作为形态示例反而会教出坏格式；截断 HTML 更无从判断边界。
- **对所有 `web-package-target` 一律取消字数要求**：会削弱竞技场新闻这类散文型目标的质量，且没有必要。
- **在宿主 block 里复述包的目标结构**：宿主不应解释包要什么，那正是 creator material 的职责。

## 4. 仍然属于包作者的部分

平台侧到此为止。quequan 这类包要真正好用，还需要作者自己：把 `instructions` 写清楚、把 `schema` 加强到约束 `accept`/`reject` 的结构、把 `example` 指向一份 3–5 条的样本。平台不代猜这些内容——它们是创作决策，不是可以自动推断的元数据。
