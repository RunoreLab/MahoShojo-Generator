# 现有页面交互共源与草稿恢复修订

状态：accepted（维护者 2026-10-09 本轮明确要求与 A/B 行为决策）
适用：现有 Web / Desktop 问卷、情景、自由生成、创作工房及角色管理页面
基线：`feat/desktop` 的 `6ae19b015867abcd1176538b5ec903b057faec69`

## 决策与边界

延续[双端产品对齐决策](./2026-10-06_084100_双端产品对齐与设置共源决策.md)，共同页面的布局、标题、问卷设置、题号导航、保存操作和返回首页入口由共享视图负责，宿主只提供真实的路由、下载、草稿与本地/云端保存能力。不能仅在两份 JSX 中复制相同 className 作为共源完成证据。

本轮精确更新旧实施记录中“每次先选择恢复/清除草稿”“损坏草稿阻断填写和生成”的正常产品行为。旧报告保留作为当时事实；以下规则不涉及 AI Key、配置文件、公开缓存的 fail-closed 安全策略。

以下草稿保留原则适用于五个生成页及角色管理。角色管理继续保留合法草稿与指定数据卡的身份仲裁，不因简化 UI 丢失未提交修改。

### 正常草稿静默恢复

- 首次可编辑之前，通过已有解析器恢复合法草稿，不自动生成，不覆盖尚未读完的旧记录。
- 移除 Desktop 独有的常驻长篇维护说明、无变更提示和强制恢复选择；必要的不确定执行、写入失败与未保存离开保护继续可见。
- 简洁提示使用两端准确的“本机”用语。清空操作范围与 Web 同语义：问卷/创作工房答案清空不隐式删除已有结果、本地卡库或凭据。
- 保存时间来自真实成功的存储写入。旧草稿没有时间戳时不伪造；v1 草稿兼容可选保存时间，不把时间混入生成输入。

### 损坏草稿保留且允许继续创作

- 原始存储记录保持原样，不迁移、不自动覆盖、不隐式删除。
- 页面以最小提示说明新工作暂不自动保存；新输入、生成结果可留在内存并通过正常本地库保存/导出取得副本。
- 单独的持久化保护标记不得再充当表单或生成资格门禁。重试、取消、关闭与组件卸载也不能回写覆盖原损坏记录。
- 用户开始新工作后，离开保护必须反映尚未持久化的输入/结果；仅发现一份坏旧记录但尚未开始新工作不制造虚假“新修改”。不在保存/生成在途时，可明确确认放弃本页内存工作后离开，不删除或覆写原坏记录，不能把持久化失败变成无法退出的死路。
- 如页面提供显式的整份草稿删除，须以真实成功删除为准；失败保留原记录和保护状态。问卷/Free 的“清空答案/提示词”不是整份草稿删除，不解除坏原文保护；未能写入时只确认当前内存已清空，不得声称旧存档已清除。

### 问卷末题按 Web 自动提交

末题完成时使用与显式生成相同的完整提交入口，继续执行当前问卷校验、Provider/Key 准备、旧结果覆盖确认、single-flight、取消与 uncertain 警告。自动提交只源于真实用户完成末题，不源于恢复草稿、切换视图、加载问卷或普通重渲染。

## 其余共同能力

- Scenario 同时提供结构化结果和通用 Markdown 情景编辑。共享编辑器处理呈现，宿主分别实现文件、本地库/云端保存，保留未保存提醒及元数据/签名事实。
- Web Scenario 补齐现有 Tokens 指示器；估算不是实际账单或供应商精确计量。
- Free 的提示词复制、清空存档与布局顺序共源；恢复就绪前不得以初始空值覆盖旧存档。
- 角色管理共用操作区，Web 通过既有本地库写入入口补保存；下载/复制不等于隐式保存到本地库或签名验证。
- 已完成的字体 token、结果 Surface、易读预览/完整 JSON、公告及文件宿主策略继续保留。宽屏重设计、未实现的平台页面、真实 Provider 调用不在本轮范围。

## 验收

具体变更与验证记录进入唯一 Desktop 计划和本轮报告。自动测试覆盖恢复/写入失败/坏原文保留、末题提交保护、平台保存能力与共享 UI 装配；真实 Windows WebView2 视觉及操作验收必须另有实测证据，不由 DOM 测试或构建通过推定。
