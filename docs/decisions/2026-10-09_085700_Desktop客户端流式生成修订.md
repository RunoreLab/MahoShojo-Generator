# ADR：Desktop 客户端流式生成修订

- 日期：2026-10-09
- 状态：accepted（维护者明确要求在本地 AI 链路验证后实施）
- 范围：`feat/desktop`，`/details`、`/canshou`、`/scenario`、`/free`、`/creator`
- 前置：[预设与 BYOK 修订](./2026-10-09_010600_DesktopAI预设独立身份与服务器BYOK修订.md)、[本地链路实测](../reports/2026-10-09_084100_Desktop本地AI链路实测与协议修复.md)

## 精确取代关系

本修订取代 [AIP ADR](./2026-10-08_173300_DesktopAIProvider选择器与多模型连接体验统一.md)中客户端固定非流式及禁用流式按钮的阶段限制；[AIP 规格](../specs/2026-10-08_173400_DesktopAIProvider共源选择器、快速配置与多模型连接.md)历史实现记录不重写。执行位置、目标身份、凭据准备及可信出站边界不变。

## 输出形态与执行位置正交

- 客户端继续使用 `direct-local` / `direct-remote`，新增可选 `generationMode` 表达本次输出形态；旧调用省略时仍为结构化生成，不迁移旧 Profile、凭据或结果草稿。
- 流式复用 Web 同家族的 Markdown 提示构造、通用卡构造与已有正文预览。不是将原来的 JSON SSE 运输改名为产品流式。
- `/details`、`/canshou` 流式输出通用角色卡，`/scenario` 输出通用情景卡。Free/Creator 仅支持与 Web 一致的 `general` / `general-scenario` 流式模板；其他结构化 Schema 不隐式当 Markdown 解析。
- 两执行位置共用生成方式控件；改变执行位置不清除模型/参数或偷偷切换 Schema。生成中继续锁定同一意图，准备 Key、派发、防双击和取消沿用既有机制。

## 结果与失败边界

- 接收正文 delta 后实时更新已有预览；reasoning 不混入可保存正文。只有正常结束并通过家族卡构造/校验才发布完整结果卡。
- 截断、过滤、工具调用结束、异常流与取消保留收到的正文，不能冒充完整成功，不自动重试。
- 本地流式结果无官方签名；恢复草稿不会触发生成或将签名字段升级为可信状态。
- 输出资源上限、Native SSE 大帧分片、UTF-8 解码及跨源重定向拒绝复用当前契约，不增加流式专属截断上限。原始文本、usage 和 finishReason 保持可核查。

## 验收

覆盖生产页面模式选择与派发、生成前参数冻结、终态前正文、reasoning 隔离、取消与异常、最终通用卡/保存/恢复，并回归非流式与服务器通路。本地模型测试使用合成输入、无真实 Key，监督脚本确认请求数、终态及 owned process 清理。源码/Mock/headless 核验证不得冒称 Windows Tauri GUI、IPC 与操作系统凭据验收。
