# 决策记录

更新时间：2026-03-26
状态：`active`

`docs/decisions/` 用来保存稳定单点决策。

## 目的

这层文档用于解决两个问题：

1. 某个重要边界已经确定，但现在只能在长报告里找到，难以长期引用。
2. 某个结论已经进入文档记录，但缺少背景、备选方案和影响说明。

因此，这里的文件应当：

- 每份只表达一个决定。
- 适合作为稳定链接被其他文档反复引用。
- 允许后续被替代或废弃，但必须留下取代关系。

## 状态约定

- `proposed`
  - 已提出，但尚未视为仓库稳定口径。
- `accepted`
  - 已被当前仓库采用，可作为稳定引用地址。
- `superseded`
  - 已被新的 ADR 取代，但仍保留历史价值。

## 编写规则

建议每份 ADR 至少包含：

1. `状态`
2. `日期`
3. `## 背景`
4. `## 决定`
5. `## 影响`
6. `## 关联文档`

## 与其他目录的关系

- `docs/topics/`
  - 作为主题级入口页，汇总该主题相关 ADR。
- `docs/reports/`
  - 保留推演过程、对比分析与阶段性综合讨论。
