# Gemma 4 模型接入设计

## 目标

为项目中现有的 Gemma 系列模型入口补充 `gemma-4-31b-it` 与 `gemma-4-26b-a4b-it`，并同步更新严格排位默认回退策略、最小必要测试与站内推荐文案。

## 现状

- 前端与配置层的 Gemma 模型目录集中在 `lib/ai/constants.ts` 的两个 provider 模型列表中。
- 严格排位模型策略位于 `lib/arena/ranked-model-policy.ts`，当前仅将 `gemma-3-27b-it` 与 `gemma-3-12b-it` 纳入默认回退链。
- 站内百科文案 `public/encyclopedia/community-rules.md` 仍只推荐旧版 Gemma 3 轻量模型。
- 现有 Gemma 特判逻辑以 `includes('gemma')` 为主，新增 Gemma 4 模型无需额外适配 JSON mode 限制判断。

## 设计决策

### 模型目录

- 在所有已有 Gemma 模型列表中新增：
  - `gemma-4-31b-it`
  - `gemma-4-26b-a4b-it`
- 排序上置于 `gemma-3-27b-it` 之前，体现新模型的更高优先级。

### 严格排位策略

- 将 `gemma-4-31b-it` 纳入严格排位默认回退链，并放在 Gemma 回退链首位。
- 保留 `gemma-3-27b-it` 与 `gemma-3-12b-it` 作为后续回退。
- `gemma-4-26b-a4b-it` 不加入默认回退链，但保持为正式可选模型，且不列入黑名单。

这样可以满足完整接入，同时避免把 `a4b` 量化版本直接放进最核心的默认排位路径。

### 测试策略

- 仅更新最小必要测试：
  - 严格排位默认回退顺序断言。
  - provider 目录中新增模型存在且不重复的轻量断言。
- 不为纯展示文案补充额外测试。

## 影响范围

- `lib/ai/constants.ts`
- `lib/arena/ranked-model-policy.ts`
- `tests/strict-ranked-model-policy.test.ts`
- `tests/ai-provider-catalog.test.ts`
- `public/encyclopedia/community-rules.md`

## 验证

- 运行针对性测试，确认新模型顺序与唯一性正确。
- 运行 `pnpm lint` 进行静态校验。
