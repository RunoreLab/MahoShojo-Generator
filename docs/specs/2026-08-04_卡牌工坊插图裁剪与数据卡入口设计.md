# 卡牌工坊插图裁剪与数据卡入口设计

## 背景

卡牌工坊当前的插图调整依赖三个独立滑块，预览图又被限制为较小的缩略图，用户难以判断最终卡面构图。数据卡输入虽然已有文本框和本地文件入口，但缺少与其他数据卡入口一致的线上浏览选择路径。

本次改动聚焦两个目标：

1. 提供比例明确、可直接拖拽和缩放的卡面插图裁剪工作台，并让编辑结果同步到卡面预览和导出图片。
2. 让数据卡输入同时支持原生粘贴、本地 JSON 和线上数据卡浏览选择。

## 设计取舍

采用内嵌裁剪工作台，不引入第三方裁剪库。它保留卡面预览在页面右侧的连续反馈，也能在移动端使用 pointer/touch 事件完成构图调整。

线上数据卡直接复用现有 `BattleDataModal`，不新增数据卡查询接口或复制权限逻辑。模态框使用单选模式，允许角色、情景、叙事历史、问卷四类数据卡；登录用户可查看“我的 / 公开 / 收藏”，未登录用户由现有模态框逻辑降级为公开数据卡。

## 交互设计

### 插图裁剪工作台

“插图设置”仍保留“上传图片”和“AI 立绘生成”两个来源标签。获得图片后显示放大的裁剪视窗，替代当前 `max-h-32` 的小缩略图。

比例选项为：

- `4:3`：默认值，兼容当前卡面插图区域。
- `1:1`：方形构图。
- `3:4`：竖向构图。
- `16:9`：宽屏构图。

比例会同时作用于裁剪视窗、`GameCardFace` 的插图区域和最终导出截图，避免所见与成品不一致。卡面整体宽度与文字区域保持不变，仅改变插图窗口的高度。

图片可在视窗内直接拖拽移动，缩放滑块作为键盘和无指针设备的稳定入口；滚轮和触摸捏合可作为增强操作。水平、垂直微调保留为“精细调整”控件，默认收起，避免主界面回到滑块堆叠状态。所有交互提供可见 focus ring 和按下反馈。

拖拽位移必须限制在 cover 图片不会露出空白的有效范围内。切换比例时尽量保留当前视觉中心，再根据新视窗重新限制位置；更换或移除图片时恢复当前默认比例下的居中状态。

### 数据卡输入

输入面板保留文本框作为主输入区，原生支持粘贴 JSON。操作区提供：

- `导入本地 JSON`：读取 `.json` 文件并填入文本框。
- `浏览线上卡`：打开线上数据卡浏览模态框。
- `示例`：填入现有内置示例。

线上模态框的配置为：

- `selectedType="all"`；
- `allowedTypes={['character', 'scenario', 'history', 'questionnaire']}`；
- `visibleTabs={['my', 'public', 'favorites']}`；
- `initialTab="public"`；
- `selectionMode="single"`。

选中线上卡后，使用现有 `mapPublicDataCardRowToBattleSelectionPayload` 得到选择 payload，再使用 `stripBattleSelectionTransportMeta` 移除 `_cardId`、作者、可见性、统计数字等传输元数据，仅将数据卡正文格式化为 JSON 写回文本框，并关闭模态框。未登录时不改变现有公开数据卡权限行为。

## 组件与状态边界

新增 `components/card-forge/ImageCropEditor.tsx`，作为受控组件负责裁剪视窗、比例选择、拖拽、缩放和重置。新增纯函数工具模块负责比例配置、cover 基准计算、位移边界限制和比例切换后的中心保持，这些纯逻辑可独立测试。

`CardForgePage` 负责保存并协调 `imageTransform`、`imageAspectRatio`、线上数据卡模态框开关和输入回调；`GameCardFace` 接收可选 `imageAspectRatio`，未传入时使用 `4 / 3`，保证旧调用方行为不变。编辑器和卡面预览共享同一变换状态，保存图片继续通过现有 DOM 捕获链路导出。

卡牌元数据 JSON 增加可选的 `imageAspectRatio` 和 `imageTransform` 字段。导入旧版元数据时字段缺失则使用默认比例和居中变换；导入非法值时回退默认值，不阻塞整个卡面导入。

## 错误与降级

- 图片读取失败显示插图设置区域内的行内错误，不使用 `alert`。
- 线上数据卡解析失败沿用 `BattleDataModal` 的选择错误提示，不关闭页面级输入区。
- 没有图片时继续显示上传引导，不显示空的裁剪工作台。
- 未登录线上浏览只显示公开卡；我的卡与收藏由现有权限和标签页逻辑控制。
- 触摸/指针交互不可用时，比例选择、缩放滑块和精细位移控件仍可完成完整调整。

## 测试与验收

自动化测试覆盖：

1. 比例配置到 CSS aspect ratio 的转换；
2. 图片尺寸和视窗比例的 cover 基准计算；
3. 拖拽位移边界限制及比例切换后的中心保持；
4. 新旧卡牌元数据的裁剪字段导入、导出与默认值；
5. 线上数据卡选择 payload 去除传输元数据后生成可读 JSON。

手动验收覆盖横图、竖图、方图在四种比例下的拖拽/缩放、触摸和键盘操作，右侧卡面预览与保存 PNG 的一致性，本地 JSON、粘贴 JSON、公开卡、我的卡和收藏卡的输入流程，以及未登录公开卡降级。

本次范围不新增第三方裁剪库、不改生成卡面 API、不改变数据卡查询或权限规则，也不重构其他数据卡入口。
