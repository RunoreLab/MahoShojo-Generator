# 废土行迹旅人问卷预设设计

日期：2026-04-19 10:24:09  
状态：已完成设计讨论，待人工评审  
范围：为现有问卷预设库新增一份“废土行迹”世界观向角色问卷预设，挂载在魔法少女问卷类别下，但主要服务于创作台的“通用角色卡（Markdown）”生成链路。

---

## 1. 本轮目标

本轮设计聚焦四个结果：

1. 新增一份可直接选用的“废土行迹世界观向”预设问卷。
2. 问卷题目保持轻设定、低门槛，不要求用户预先熟悉该世界观的专有名词。
3. 通过 `loreMarkdown` 为 AI 注入稳定、克制、足够车卡的世界观边界与生成要求。
4. 保持现有问卷系统、创作台与详情页链路不变，不新增专用页面、专用 schema 或专用解析逻辑。

本轮不是要把现有“魔法少女结构化问卷链路”重写成“废土角色专属系统”，也不是要一次性落地“废土行迹”的整套问卷卡 + lore 卡矩阵。

---

## 2. 非目标

本轮明确不做以下内容：

1. 不新增“废土行迹”专用路由或专用问卷分类。
2. 不改造 `/details` 的非流式魔法少女结构化输出，使其原生适配废土角色字段。
3. 不拆分出多张 lore-only 设定卡。
4. 不新增 UI 徽标、特殊筛选器或废土专属引导组件。
5. 不把问卷做成世界观考试，不强制用户理解势力名词、地区名词、技术体系名词后才能填写。
6. 不为了“设定感”强行把每个角色写成高规格组织成员、超科技精英或创伤主导型角色。

---

## 3. 已确认的事实边界

### 3.1 接入位置

- 该预设仍然放在现有 `public/questionnaires/presets/` 目录下。
- 该预设在索引中使用 `kind: "magical-girl"`，从而出现在现有魔法少女问卷预设列表中。
- 该预设不设为默认问卷，不影响现有默认预设选择。

### 3.2 主要服务链路

- 该预设优先服务于 `/creator` 的 `通用角色卡（Markdown）` 输出。
- 在 `/details` 中它仍可被选中，但不作为“废土角色结构化输出”的主推荐路径。
- 预设标题和描述需要明确提示：推荐用于创作台或流式通用角色卡。

### 3.3 原生性判定

- 该预设虽然会注入“废土行迹”世界观 lore，但本轮按业务要求仍提供原生许可。
- 因此该预设应显式标记为 `nativeAllowed: true`。
- 这是一次明确的产品规则选择，而不是由“是否含 lore”自动推导出的默认结论。

### 3.4 世界观使用边界

本预设引用的“废土行迹”稳定设定，以本地设定源中已经确认的高层结论为准，主要包括：

- 世界整体采用 `聚居地 + 通路 + 危险区` 的混合空间结构。
- 世界重点不只是战斗，而是判断、调查、探路、记录、通报与带回结果。
- 旅人是该世界自然产出的流动人口，不只是少数浪漫主义冒险者。
- 稳定旅人类型包括：
  - 商路旅人
  - 信息旅人
  - 路线旅人
  - 事务旅人
  - 迁徙旅人
  - 边缘旅人
  - 武装旅人
- 常见队伍更接近围绕一次上路目标临时拼成的混合队，而不是固定职业团。
- 首轮稳定地区可优先落在：
  - 硅晶之路
  - 铁火地带
- 涉及地点时，应同时允许两种来源：
  - 直接选择或引用已有稳定设定中的地点、地区、节点或聚居地；
  - 由 AI 根据已知设定边界补完新地点，例如按地域特色、聚居地类型、控制势力、开放度与旅途接口生成合理地点。
- 主要大型组织方向可优先挂接为：
  - 世界调查协会
  - 重建委员会分支或遗留任务链
  - 地方聚居地 / 地方政权 / 驻屯体系
  - 学城 / 研究共同体 / 知识节点
  - 企业或商业联盟体系
  - 救世军相关背景
  - 无正式归属的地方网络、人情网络或临时雇佣关系

## 4. 方案选择

本轮采用“单一主问卷 + 强 lore 注入”的方案。

### 4.1 采用方案

- 新增 1 份可答题问卷 JSON。
- 问卷本体负责收集用户的行为倾向、上路动机、未知处理方式、队伍功能、组织倾向与个人痕迹。
- `loreMarkdown` 负责提供 AI 生成角色卡所必需的稳定世界观边界与输出要求。

### 4.2 不采用的方案

#### 不采用“多张 lore 卡拆分方案”

原因：

- 本轮目标是快速落地一个可直接使用的预设。
- 多张 lore-only 卡会增加选择复杂度。
- 当前阶段世界观仍在持续扩展，先用单问卷压住使用体验更稳。

#### 不采用“强字段设定问卷方案”

原因：

- 用户已明确要求问题不要太重设定。
- 如果直接问“你来自哪个正式势力”“你属于哪类新人类”“你所在聚居地类型为何”，会显著提高使用门槛。
- 本轮更适合通过行为题、价值排序题和角色定位题，让 AI 再映射到世界观内的合理位置。

## 5. 用户体验设计

### 5.1 预设名称与描述

- 建议标题：
  - `废土行迹世界观向：旅人角色问卷`
- 建议描述：
  - `不需要预先了解设定，按直觉作答即可；推荐用于创作台 / 通用角色卡（Markdown），生成废土旅人、调查者、护送者、熟路人等角色。`

### 5.2 使用定位

- 用户不需要先理解完整世界观，只需要回答“如果你在那样的路上，你会怎么做”。
- 问卷整体题量保持轻中量，建议控制在 `15~17` 题。
- 题型以 `select + allowCustom` 为主，搭配少量短文本题。
- 每道题尽量允许用户用一两句补充，而不是被迫只选定死选项。

### 5.3 结果倾向

问卷应帮助 AI 推断下列内容，而不是让用户逐项背填：

- 成长环境或出身节点
- 上路动机
- 旅人类型
- 队伍定位
- 对未知技术与风险的处理方式
- 对组织、秩序与技术的态度
- 可视化个人痕迹
- 可继续展开的故事入口

---

## 6. 问卷结构设计

建议采用四组结构。

### 6.1 第一组：上路前的你

这一组负责给角色提供最基础的称呼、方向与上路前状态。

建议题目：

1. `你的名字、代号，或者路上别人怎么称呼你？`
2. `一句话概括：你想要怎样的角色？`
3. `你原本更像在什么环境里活下来的人？`
4. `你为什么会离开原地？`
5. `你更像哪种长期在路上的人？`

设计要点：

- 第 1 题必须放在最前面。
- 第 1 题要兼容本名、外号、路上代称、队伍称呼。
- 第 3 题不直接使用“聚居地类型”术语，而用更直觉的环境描述承接成长背景。
- 第 5 题可映射到稳定旅人类型，但用户看到的表述应该口语化，例如“跑货送补给的人”“记事查线索的人”“看路试路的人”等。

### 6.2 第二组：遇险时的判断

这一组负责提炼角色在废土语境下的行动逻辑。

建议题目：

1. `面对自己看不懂的东西，你第一反应是什么？`
2. `一条熟路忽然不对劲，你会怎么做？`
3. `队里有人坚持继续前进，但你觉得前面可能有大问题，你会怎么处理？`
4. `如果必须在“把结果带回去”和“让所有人活着回来”之间取舍，你更偏向哪一边？`
5. `你最怕哪种旅途代价？`

设计要点：

- 这组题目是整份问卷最重要的世界观映射层。
- 重点不是战斗强弱，而是观察、试探、撤退、通报、协商、止损、承担后果。
- 第 5 题的“代价”可以引出角色的禁忌、恐惧、责任或长期负担。

### 6.3 第三组：关系、归属与做事方式

这一组负责映射角色的队伍功能和组织关系。

建议题目：

1. `你在临时拼起来的队伍里通常担什么位置？`
2. `如果必须长期依附一个更大的系统，你更能接受哪一种？`
3. `别人会因为什么愿意带你一起上路？`
4. `你更相信什么能让人活下来？`

设计要点：

- 第 2 题不要直接把所有正式势力名摊到用户面前，而是用“重记录和调查的方法网络”“还相信旧计划和档案的人”“重利益和技术交换的商业体系”“地方聚居地本身”“谁都不跟”等说法承接。
- 第 3 题用于提炼角色的社会功能价值。
- 第 4 题用于稳定角色的生存哲学。

### 6.4 第四组：个人痕迹与角色底色

这一组负责给角色提供可视锚点和故事张力。

建议题目：

1. `你身上最像“护身符”或“职业痕迹”的东西是什么？`
2. `你对高度危险但可能有价值的旧技术或未知遗产，更接近哪种态度？`
3. `有哪条底线是你上路后也不愿跨过去的？`
4. `写一句更像你的话。`

设计要点：

- 第 1 题给角色卡提供视觉与物件锚点。
- 第 2 题可映射到“调查利用 / 收容守护 / 清洗摧毁 / 寻遗复兴 / 拒斥重建”等处置路线。
- 第 3 题用于稳定角色的人性边界。
- 第 4 题用于收束角色语言风格与信念句。

## 7. `loreMarkdown` 设计

### 7.1 世界底座

`loreMarkdown` 需要先告诉 AI：

- 《废土行迹》不是单纯荒野，而是高技术遗产、信息断层与地方生存秩序叠加后的长期废土。
- 世界基本结构是 `聚居地 + 通路 + 危险区`。
- 旅途的核心不只是战斗，而是判断、调查、探路、记录、通报与把结果带回去。
- 在这个世界里，知识、记录、经验、路线判断与补给、火力同样重要。

### 7.2 角色默认视角

`loreMarkdown` 需要限制 AI 不要把角色默认写成过强设定。

应明确说明：

- 角色默认更接近旅人、行路人、调查协力者、护送者、熟路人、迁徙者、边缘旅人等上路者。
- 不要默认所有角色都是英雄、军政高层、正式精英调查员或高规格超科技个体。
- 普通人、小人物、地方熟手、临时拼队成员、长期在路上活下来的人，都完全符合世界观。

### 7.3 角色落位维度

`loreMarkdown` 需要给 AI 一套可稳定映射的“角色落位维度”：

- 成长环境
- 上路动机
- 旅人类型
- 队伍定位
- 组织关系
- 地域背景
- 技术背景
- 风险处理倾向

这些维度要写成“可推断、可补完”的边界，而不是让 AI 生搬硬套术语堆砌。

### 7.4 地域与技术背景

`loreMarkdown` 应提供首轮稳定的地域差异，以便 AI 确定合适的地域：

- `硅晶之路`
  - 更容易出现接口、终端、脑机、智网、AI、人机结合相关遗产与危险。
- `铁火地带`
  - 更容易出现军团、军工、装甲、爆炸物、载具、长期战事与武装秩序。

同时需要说明：

- 角色地点来源既可以是现有稳定设定中的地点，也可以是 AI 在既有世界边界内补完的新地点。
- 若 AI 自行补完地点，必须同时满足：
  - 能与已知地域气质相容；
  - 能解释其聚居地类型、功能层和基本生存逻辑；
  - 能说明与某种地方秩序、控制势力或旅途网络的关系；
  - 不要写成会推翻现有世界格局的超大核心城市或万能中枢。
- 旧人类 / 新人类 / 人机共生型新人类 / 失稳新人类等设定可以出现，但不是默认起点。
- 如果用户答案没有明显指向，不要默认角色是新人类、神术师或高规格改造者。

### 7.5 组织与处置路线

`loreMarkdown` 应提供可挂接但不强绑的组织与立场：

- 世界调查协会或外围合作网络
- 重建委员会分支或旧任务链
- 地方聚居地 / 驻屯体系 / 地方政权
- 学城 / 研究共同体 / 知识节点
- 企业或商业联盟
- 救世军相关背景
- 无正式归属的人情网络、门路网络、临时雇佣网络

并告诉 AI：

- 如果答案未明确，不要强行给角色挂正式组织身份。
- 角色的“处置路线”更多应体现在其判断方式、语言、装备选择与关系冲突中，而不是只当一个标签。

### 7.6 结果输出要求

`loreMarkdown` 必须明确本预设的目标输出是：

- `废土行迹世界观下的通用角色卡`

并明确限制：

- 不要套用魔法少女术语。
- 不要把角色硬写成魔法少女或残兽字段逻辑。
- 优先生成“能继续写故事的人”，而不是百科词条或设定说明书。

## 8. 车卡输出结构要求

本预设服务的是 `通用角色卡（Markdown）`，因此应在 lore 中明确要求 AI 生成的角色卡至少稳定包含以下信息：

1. 角色称呼
2. 一句话定位
3. 出身与成长环境
4. 上路原因
5. 旅人类型与队伍定位
6. 所属、关系与来往网络
7. 装备、技术背景与身体状态
8. 面对未知与危险的方式
9. 底线、负担与主要矛盾
10. 至少一个后续故事钩子

建议在 lore 中直接给出推荐 Markdown 结构：

- `# 角色名`
- `## 一句话概括`
- `## 出身与成长环境`
- `## 上路原因`
- `## 旅人类型与队伍定位`
- `## 所属、关系与来往网络`
- `## 装备、技术背景与身体状态`
- `## 面对未知与危险的方式`
- `## 底线、负担与主要矛盾`
- `## 可展开的故事钩子`

---

## 9. 生成约束

为避免 AI 生成偏离，本预设的 lore 应加入以下约束：

### 9.1 不拔高

- 不要把角色默认写成全知全能、单人决定地区局势的顶级存在。
- 不要默认每个角色都拥有高规格组织资源、超科技权限或战争级能力。

### 9.2 不堆术语

- 不要为了显得有设定感而堆专有名词。
- 如果问卷答案偏朴素，输出也应保持朴素。

### 9.3 不强造创伤

- 如果答案没有明显创伤，不要强行编造创伤。
- “底线、负担与主要矛盾”优先写角色当前背着什么活着，例如责任、秘密、债务、长期风险、放不下的人或事。

### 9.4 合理补完

- 如果用户没有填写具体世界字段，AI 可以根据答案做世界观内合理补完。
- 但补完应服务于角色可写性，不应扩成整段世界设定介绍。

## 12. 风险与后续扩展

### 12.1 当前风险

- 单问卷 + 强 lore 方案会让单文件内容偏长。
- 若“废土行迹”世界观后续快速扩展，单份 lore 可能持续膨胀。
- 该预设挂在 `magical-girl` 类别下，用户可能误以为它适合非流式魔法少女结构化输出，因此标题与描述必须明确用途。
- 该预设按业务要求标记为原生许可，因此后续若继续引入更多外部世界观预设，需要额外明确哪些也适用这条规则，避免团队误把“含 lore 即非原生”当成隐含约束。

### 12.2 后续可扩展方向

如果该预设验证通过，后续可以继续拆分：

1. 世界与组织速查 lore 卡
2. 人类分野 / 技术与危险速查 lore 卡
3. 更偏“调查拼队”或“灰色流动型”的细分问卷
4. 真正面向废土角色的专用结构化 schema 或 build rule

这些都属于后续工作，不在本轮范围内。

## 13. 结论

本轮以最小侵入方式，把“废土行迹”世界观接入现有问卷系统：

- 入口层仍复用魔法少女预设分类；
- 使用体验上保持低门槛、轻设定；
- 生成层优先对齐通用角色卡；
- 世界观约束集中由 `loreMarkdown` 承担；
- 系统原生性上按业务要求明确标记为 `原生许可`。

该方案改动面小、可直接落地，同时为后续把“废土行迹”继续扩展成多张 lore 卡、专用结构化车卡或更完整模块保留空间。
