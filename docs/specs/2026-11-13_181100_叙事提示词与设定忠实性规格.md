# 叙事提示词与设定忠实性规格

状态：accepted；用户于 2026-11-13 批准本规格所述方向及实施范围。

## 目的与范围

覆盖 Arena 单人、多人和相关续写生成链路，以及魔法茶会的正文、摘要与角色更新。统一共用语义，保留经典、羁绊、日常、情景模式及各输出/阶段协议的差异。角色创建、重制和成长升华不机械套用禁止改变能力的演绎规则。

## 创作规则

- 准确理解并在推演中考虑全部相关能力，正文无需逐项展示。不得为平衡、悬念或预想结局擅自删改能力、追加弱点/代价，或制造巧合使能力无故失效。
- 不以善恶、阵营、主角身份预定胜负，不强求势均力敌；允许优势明确的结果、僵持和平局。角色仍按自身知识、性格、目标及处境行动，不要求永远最优。
- 羁绊模式保留友情、信念及有设定或本场事件支撑的逆转、突破和奇迹，不凭空削弱对手。日常模式保持温暖基调，不强制关系改变或和解。
- 角色档案、世界书与情景先按职责兼容解释；确实不可调和时主情景优先，辅助情景/素材作补充。此优先级仅适用于虚构内容，不覆盖内容政策、应用权限及输出协议。
- 本场改编和暂时状态不自动成为永久能力/限制。摘要、历战和状态更新仅记录有事件证据的变化，区分事实、观点、推测、比喻与永久变化。
- 认真演绎规则、因果及元叙事能力，不因强大或命令式措辞就认定攻击。卡内创作协议仅在当前任务和阶段授权范围内采用，不能越权控制真实应用。
- 遵守[社区守则](../../content/encyclopedia/community-rules.md)。允许失落、牺牲、失败与严肃冲突，但避免持续绝望、猎奇折磨和渲染残酷；成人、血腥猎奇等红线不因忠实角色而豁免。普通冲突采用克制表现，不把安全转述固化为永久设定变化。

## 共源与兼容

- 共用内容边界、忠实性、资料职责和记录原则在 `packages/ai-core` 维护一次，按任务选取。不得新建全能 shared 包或让 domain 反向依赖 ai-core。
- 原作等级与世界观保留适用范围，通用角色不硬套原作模板。输出形态及控制尾注继续遵守既有 Arena/Web Package 规格；茶会保留玩家不被代演、阶段协议、JSONL/notice/choices 等约束。
- 稳定规则与用户资料最终分开为真实 system/user 消息。结构化运行时通过内部显式启用选项兼容旧消费者，并覆盖文本 JSON 回退；不全站切换默认行为。
- 茶会已有会话下次生成采用当前 builtin 预设；不重写已经保存的历史、角色卡或用户修改的情景快照。
- 不改变排位计分、输出 wire schema、持久化格式、鉴权、审核机制或发布配置；不新增自动二次 Provider 生成。

## 验收与证据

验证实际发送消息、输出/回退协议和跨端接线，并开展合成边界案例及热门公开卡新旧对照。设定错误、内容边界、格式、写作表现分别评价；小样本不得宣称普遍有效。真实卡仅选公开、审核通过、未删除记录；不导出账户/作者私密字段，原始数据及模型输出保留于忽略目录。

外部依据（核验日 2026-11-13）：[Anthropic 提示词指南](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices)、[CharacterEval](https://aclanthology.org/2024.acl-long.638/)、[ArcANE](https://arxiv.org/abs/2606.05553)、[REMP](https://aclanthology.org/2026.findings-emnlp.602/)。这些是方法依据，不代替本项目实测。
