# 显示与阅读设置首期规格

状态：`active`（维护者已批准目标；实现与验收状态见配套计划）
日期：2026-11-13
规格标识：`SPEC-display-reading-v1`

本规格补充[双端产品对齐与设置共源规格](./2026-10-06_084200_双端产品对齐与设置共源规格.md)的 DESK-SET-003..007，以及[双端视觉基线与工程契约规格](./2026-10-19_215200_双端视觉基线与工程契约规格.md)。规范词遵循 RFC 2119 / RFC 8174。

## 已确认的产品边界

维护者批准 Desktop 主窗口整体缩放与双端共用阅读设置，补充 Ctrl + 鼠标滚轮。图片导出跟随当前阅读样式。独立 Web 战报/Web 包作品窗口、窗口位置/尺寸记忆、全屏、自定义字体导入或枚举留到后续。

本轮不新增账号同步；同一台机器上 Web 与 Desktop 各自使用本机存储。既有主题、减少动效、自动定位、草稿、生成参数与数据保存语义保持各自所有权。

## DISP-001 主窗口整体缩放

- Desktop **MUST** 提供 80、90、100、110、125、150、175、200 百分比档位，默认 100。主 UI、菜单、弹窗、表单一同缩放；通过真实 WebView 缩放实现，不以 CSS transform 冒充页面缩放。
- 设置入口位于“外观与交互”，提供倍率选择、减小、增大和恢复 100%。Web 不显示此宿主专属控件。
- Ctrl + `+`/`=`、Ctrl + `-`（含小键盘）、Ctrl + `0`，以及 Ctrl + 鼠标滚轮 **MUST** 消费同一状态。滚轮向上放大、向下缩小；普通滚轮保持滚动。组合输入与已经被其他控件消费的事件让位。连发输入合并但不丢失最终意图。
- 手势由应用统一控制，不同时启用一套不回写应用状态的浏览器原生缩放。Ctrl + 滚轮使用非被动监听，仅在确实处理手势时阻止默认；连续滚动有界节流，避免瞬间穿过所有档位。
- 倍率通过既有 `config.json`/DesktopConfigStore 保存；新增字段采用 version 1 加法兼容。缺字段默认 100，非法值诊断并回退；未知字段继续保留。不得再向 localStorage 双写。
- 文件写失败、冲突、Native 应用失败 **MUST** 如实反馈，不能把期望倍率冒充实际倍率或把内存值冒充落盘值。启动尽早恢复；读取/应用失败保持可用的默认或上次有效倍率，不无限阻塞首页。
- 新 Native 能力限定主 UI 调用与主 UI 目标，不接受任意窗口/webview 标签，不为作品窗口授予 capability。

## READ-001 阅读偏好与存储

双端“外观与交互”内提供共同阅读卡，至少包含：

| 字段 | 档位 | 默认 |
| --- | --- | --- |
| 字号倍率 | 100/110/125/150/175/200% | 100%，保留现有字号 |
| 字体 | 沿用当前 / 系统无衬线 / 系统衬线 | 沿用当前 |
| 行距 | 原样 / 舒适 / 宽松 | 原样；后两档 1.75/2 |
| 长文宽度 | 原样 / 较窄 | 原样；较窄约 40 个全角汉字 |

共源设备偏好模块 **MUST** 作为唯一读写路径，采用版本化 localStorage，具有类型/枚举校验、确定默认、订阅更新与首屏初始化。设置页和预览读取同一状态。无存储或写失败可临时应用，但 **MUST** 提示未保存；恢复默认只清此组偏好，不清主题、草稿或数据。跨标签页变更应更新已挂载消费者。

字体使用本机字体栈和 CJK 回退，不加载远端字体。无衬线与衬线选项描述字体类别，不承诺某个未安装的具体字体。

## READ-002 正文消费与默认兼容

覆盖角色/情景正文、普通战报（含流式与历史）、连续故事章节、茶会消息、百科，以及对应本地库/历史详情。共享入口 **MUST** 同批覆盖 Web/Desktop 实际消费者，不能只改一个 Markdown 渲染器。

通过具名正文作用域接入；默认全部原样。非默认倍率、字体、行距分别覆盖相应阅读属性，不能粗暴修改根字号或对全页 `*` 统一覆盖。嵌套正文作用域不重复乘倍率。代码/完整 JSON、KaTeX 字体、交互控件与固定版式工坊卡面保留自己的排版；仅选择阅读设置不改变原始文本、生成请求或存档格式。

长文宽度只作用阅读区域，不能缩窄整页表单或操作栏。大字号应重新换行；标题层级仍能辨认。表格、代码等有二维语义的局部允许滚动，普通正文不依赖逐行横向拖动。

设置内的真实生产预览 **MUST** 包含中文、英文、标题和列表，样板间复用同一控件/样式。显示倍率与阅读倍率独立并可叠加，设置页说明其关系。

## READ-003 导出与运行中变更

卡片/战报图片导出跟随当前阅读排版，覆盖现有截图路径；检查长图、换行与字体就绪。原始 JSON/Markdown/存档内容不写入阅读样式。整体 WebView 缩放不应被额外当成图片尺寸倍率重复应用；图片依旧使用现有截图分辨率策略。

生成期间调整显示 **MUST NOT** 重建业务 owner、取消请求、丢失输入/草稿/结果或自动重放。阅读偏好只控制呈现。

## 验证与证据边界

每个切片包含契约、行为和对应静态检查；视觉 token/CSS、样板与 workspace 边界按既有门禁运行。双端 production build 验证共享 CSS 和首屏脚本实际进入产物。

实际 Windows WebView2 验收覆盖设置/快捷键/Ctrl+滚轮、普通滚动、亮暗主题、窄窗和高倍率、重启恢复、输入保护、正文与图片导出。系统 DPI/多屏/物理 IME/读屏等仅按实际覆盖报告；浏览器模拟不代表原生验收，不以像素黄金图作门禁。
