# 卡牌工坊上限与内容安全改进计划

## 目标

按卡面展示能力放宽属性数值，同时补齐卡牌工坊从生成、导入到立绘提示词的内容安全边界。

## 已确认范围

- 攻击力、防御力、生命值不再设置 `999` 的 schema 硬上限，保留非负整数约束。
- 卡牌工坊不再在任务配置中固定 `maxOutputTokens`，让实际模型/提供商配置决定输出预算。
- 暂不新增其他业务硬上限；容易需要恢复的边界在代码中保留说明注释。
- 图片大小只做用户可见的软提示，不因大小拒绝上传、导入或导出。
- 数据卡输入已有服务端敏感词拦截；新增生成结果敏感词拦截与屏蔽词递归遮罩。
- 导入卡面 JSON 先检查敏感词，命中时拒绝导入；未命中时对屏蔽词做遮罩。
- 立绘生成提示词在服务端接入现有文本安全检查。

## 非目标

- 不调整花费、图片尺寸选项、裁剪缩放范围或其他现有协议约束。
- 不将屏蔽词改为拦截词；不改变现有敏感词词表与屏蔽词词表。
- 不对卡面文本另行增加长度/数量硬上限。

## 验证

- schema 可以解析九位数属性。
- 卡牌生成响应会拦截敏感词并遮罩屏蔽词。
- 卡牌存档安全处理覆盖嵌套文本字段。
- 立绘提示词命中敏感词时不会请求上游服务。
- 图片软提示可识别大文件且不抛出拒绝错误。
- 执行相关 Vitest、`pnpm lint` 与 `pnpm build`。
