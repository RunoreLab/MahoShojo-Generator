## DESK-ONLINE-001 执行控件与有效选择

界面 **MUST** 使用「AI 执行：客户端｜服务器」区分执行位置，与现有「流式｜非流式」独立。Desktop 默认客户端；客户端可以是本机服务或远程直连，远程直连 **MUST NOT** 标为离线。局域网/远端自托管服务不得仅按名称标成本机。

内部 **MUST** 复用 `AiExecutionMode`、`AiExecutionPort`。有效选择由用户偏好、页面/玩法约束与真实宿主能力派生；原因可放在 UI 状态，不强行向现有 strict wire schema 添加字段。服务器权威来自服务端规则，不来自客户端提交的 `mode` 字符串。

无可用 Direct 配置时保留客户端偏好，引导设置，不自动改为服务器。Web 当前只有服务器执行，不渲染可操作却未实现的客户端选项。选模型/开设置/切换显示选项不自动发起生成。

验收：新安装默认客户端；Direct-remote 的接收方/联网说明正确；Web 无伪直连；流式开关不改执行位置；未配置可继续填问卷和管理本地数据。

## DESK-ONLINE-002 预设、自定义与模型所有权

项目预设及模型定义 **MUST** 共源、稳定标识且与用户偏好分离，不在两个 app 各维护一份列表。产品版本更新不得覆盖用户自定义项或取消隐藏偏好。

预设是项目维护的目录与模板，不是持久化连接身份：Web 预设渠道保留既有 BYOK——预设端点下允许填写/更新 Key、选模型（含自定义 `modelId`，见 DESK-ONLINE-003）及调整支持的生成参数，但 **MUST NOT** 原位修改名称、endpoint、adapter 等项目定义。Desktop 预设只展示已核验模型并作为复制模板，不承载凭据或运行时选择状态；Desktop 须经「复制为自定义连接」后修改，复制产出的自定义连接拥有 Key、模型与生成参数，不再回写预设，也不产生第二套预设凭据/状态体系。复制不默认复制 Key；连接的用户标识不能与项目预设碰撞。自定义连接可从空白创建，允许本机或远端 endpoint，均经过既有 Profile/native 出站校验。

Desktop **MUST** 支持预设供应商/模型隐藏与恢复、自定义供应商/模型新建/编辑/删除。模型身份按连接 + servedModelId 区分，不因同名跨供应商串用参数。隐藏不是禁用/删除；当前选择仍可显示为隐藏项，不自动换模。引用中的自定义项删除须显示影响并显式解除/替换引用；生成中锁定本次配置，编辑只影响后续请求。

当前实现状态：D5.0b 落地预设供应商级隐藏与恢复；预设内模型级隐藏按
`D5.0b deferred / post-MVP polish` 后移（其为本地选择器 UX，无在线能力依赖，
不绑定 D5.0c 阶段），届时在当前连接/预设之下管理可见模型，不新建第二套
凭据或选择状态。

验收：隐藏→重启→升级→恢复；复制改 endpoint 不改预设；删引用项无静默 fallback；相同 modelId 的两条连接各自保留参数；预设消失时旧引用可诊断而非悄悄选第一项。

## DESK-ONLINE-003 Web 范围与旧配置兼容

Web 本轮 Provider/endpoint 范围 **MUST** 限于项目预设，不开放任意 endpoint、自定义供应商实体管理或本机连接。**MUST** 继续保留现有“预设端点 + 自定义 `modelId`”能力：用户可选择目录内预设模型，也可在当前预设供应商固定 endpoint 下填写其他模型 ID；这不创建 Custom Connection，也不允许借模型输入改写 endpoint/adapter。服务器继续按既有业务边界校验供应商、模型 ID、参数与请求资格，UI 隐藏不是权限控制。Desktop 的自定义连接只可用于客户端执行，不能通过服务器模式上传 arbitrary endpoint。

当前 Web 的 `canUseCustomModelId` / `resolveAIProviderModel` 与选择器已经实现上述语义；本轮共源重构 **MUST NOT** 将其收窄为“只能选择目录列出的模型”，也 **MUST NOT** 把自定义 `modelId` 误建模为可修改 endpoint 的自定义供应商。

迁移必须保留手填入口、存量自填值、相关 localStorage/配置语义及旧客户端 wire。目录更新、模型隐藏或 UI 共源不得自动替换用户保存的自定义 `modelId`；若实际供应商不再接受该模型，应显示真实上游/服务端错误或可用性状态，而不是客户端静默改成预设模型。

旧 Web 命名空间、provider/model 选择、生成参数与 `system` wire 必须有迁移/兼容测试。Desktop 旧 `DirectProviderProfileV1` 作为用户已有配置处理，即使 endpoint 等于预设也不自动认领为 preset；保留 ID、secretRef、时间和参数语义。新旧配置不得双写成两个权威源；迁移失败保留原数据，重试幂等，当前引用不悬空。

验收：Web 新入口受控；存量手填与旧 wire 有明确测试预期；旧 Desktop profile/Key 引用不丢；重新保存但未重输 Key 不切断有效引用；载入已有连接真正载入内容而非只换 ID。

## DESK-ONLINE-004 协议、能力与 Key

目录项 **MUST NOT** 被当作当前 adapter 已实现证明。Direct 对已支持协议提供真实请求/流/取消映射；未知协议或不支持参数明确说明，不用 OpenAI-compatible 冒充其他 native adapter，不显示无实际发送效果的高级控件。

Web 现有转发专用 endpoint、项目服务 origin 或需要服务器内部身份的入口不得直接晋升为 Desktop Direct preset。可用 Direct endpoint 需独立核对公开协议与凭据要求；不支持的项目预设可见但说明不可用于当前路径。预设供应商目录并不授予 native 出站例外。

普通配置/导出/历史不含 Key 明文。Desktop 设置录入后交 OS SecretStore，后续只读存在状态/安全摘要，renderer **MUST NOT** 为服务器 BYOK 新增秘密读回能力。无需 Key、缺 Key、已配置、凭据存储失败须能区分；没有 Key 不等于连接必然不可用。

若实现模型发现，复用已保存连接与受控 adapter；`/models` 不是所有协议的共同接口。用户主动刷新，失败保留已存模型/手填路径；不为首版预建发现缓存平台。Web 项目链路可用性统计只能标注为服务器侧参考，不能冒称用户 Direct 的连通率，Direct-only 旅程不自动请求该统计。

验收：未实现 adapter 被阻止且原因准确；同一参数两端真实生效或明确不支持；日志/备份/Room 不含 Key；无需认证的本机模型正常可配；设置页与生成页共享同一配置状态。

## DESK-ONLINE-005 系统默认与服务器 BYOK

系统默认 AI **MUST** 只通过项目业务 API 正常生成，不产生可直连的项目上游 profile。服务器保留模型路由、Key、秘密 header、限流、预算、内容和资格校验；不接受客户端自称“官方应用”作为免检依据，不新增任意 Prompt/URL 的项目 Key 代理。

“系统默认 AI 仅服务端”**不等于“服务器只有系统默认 AI”**：Web 已有的预设渠道 BYOK 保留，Desktop 的服务器路径按对应业务同样适配。切换到服务器 BYOK 时 **MUST** 明示选定用户 Key 和输入将交由项目生成服务转发；普通账号/卡库/消息请求不携带 Provider Key。

Desktop 仅通过专用 native 生成适配解析选定 credential reference，绑定固定项目 origin 与业务路由；不是从 Direct Profile 放行项目域名。不得将未选中的 Key、任意 secretRef、header、URL 随一般请求注入；凭据不进入 Room DTO、request identity/hash、持久化请求、日志或审计。

旧 `system` ID 和公开可选模型先通过兼容映射接入新策略。项目公开模型描述和现有安全响应元数据可以保留，不把去除秘密调度配置误做成删除全部模型展示。

验收：Direct system 解析拒绝；通用项目 API 无 Provider Key；服务器 BYOK 仅发送所选 Key；伪造 endpoint/secretRef 不扩大访问；旧客户端 system 请求仍按其已支持契约工作。

## DESK-ONLINE-006 自动切换、严格排位与多人

用户明确启用一键严格排位时，客户端在 dispatch 前 **MUST** 自动将有效位置锁为服务器，显示锁定原因。多人第一版同样锁服务器；只在界面解析约束，不在加入房间时擅自上传当前本地草稿或触发 AI。

服务器继续检查严格排位模型、参数、线上卡身份、签名等全部资格。遇到本地卡不足资格，应展示既有阻断与显式上传路径，不能自动上传、伪造 `sourceDataCardId` 或只改 execution mode。服务器 BYOK 是否可用仍遵守对应玩法既有规则，不一刀切允许或禁止。

离开约束场景恢复原普通偏好及其配置；若原配置已删除，显示需重新配置，不静默选替代项。在途生成期间不能原地改变执行者；切换需先取消/完成并处理当前结果。

多人只复用当前 Room/generation 协议、host/member 权限、ticket、revision、冻结输入与重连恢复；不实现客户端结果上传/流式中继，不传播 Provider 配置。包 ref/overlay 的冻结及分发按既有 Web 包能力处理，不顺带实现尚未支持的本地包分发。

验收：strict/多人锁定与退出恢复；连续切房不污染普通偏好；仅切服务器无法绕过资格；成员绕过按钮仍不能发起房主命令；退出/重连不产生第二次生成。

## DESK-ONLINE-007 请求身份、恢复与错误引导

开始生成后 **MUST** 固定输入与有效配置，复用既有 request identity、取消、事件排序和唯一终态；不因超时、重挂载或网络恢复跨执行者自动重发。Hosted 的未知结果按既有 lookup/status/replay/cancel 处理，不把断开订阅等同于取消 producer。

项目执行预算/链路超时等可提示“保留输入，改用客户端重新生成”；这应是新的明确用户意图。原服务器任务仍可能执行时先尝试查询/取消，无法确认就说明重复费用/结果风险，由用户决定是否另开请求，不伪造旧任务已停止。原部分输出保留，不自动续接成新任务的正文。

Strict/多人不提供能直接绕过玩法约束的“改客户端”动作；可说明退出该玩法后再使用客户端。上游配额、认证失败或内容拒绝按真实原因提示，不把换位置描述为通用绕过办法。Direct 遵循 `DESK-032` 默认无应用层连接/空闲/总时长硬超时，系统网络及 Provider 自身限制仍可能中断。

验收：超时/unknown/取消/重新生成分离；新尝试有新身份，旧结果可保留；没有自动第二次 Provider 调用；strict 错误提示不开放非权威结算路径。

## DESK-ONLINE-008 TopBar、首页与在线状态

首页与 TopBar **MUST** 从 Web 既有展示/交互按需抽共享；保持名称、导航分组、主题、主要入口、用户菜单与消息入口语义。宿主 capability 决定是否可操作及原因，不另写“类似 Web”的 Desktop 版本。

Desktop 冷启动和本地旅程不自动发项目请求。共享组件不直接挂 Web auth、统计、挑战页、公告/消息轮询或远端头像；用户进入具体在线能力后由宿主启动必要查询，退出/注销后释放对应订阅。已保存身份不冒称当前仍已验证。

能力状态区分未配置、需登录、未连接/离线、服务失败、客户端未实现和版本不兼容，不统一显示“无数据”。离线不能隐藏已经支持的产品信息架构；未实现动作可隐藏或说明原因，不保留失效可点击链接。

验收：两端同一组件的主要操作、亮暗主题、键盘/焦点与窄窗体验一致；本地冷启动 renderer/native 项目请求为零；断网/未登录/未实现状态可区分；在线失败不封锁无关本地入口。

## DESK-ONLINE-009 `/details` 共源纵切

以 `apps/web/components/creation/DetailsPage.tsx` 及已抽出的问卷/结果控件为源，逐步共源页面布局、问题导航、预设/本地导入/线上问卷选择、高级 AI 设置和结果操作；不另建 Desktop 问卷体系。实际引用的问卷来源、条件题及批量回答行为与 Web 既有产品对齐，云端读取仍显式发生。

共享业务核注入已有 AI 执行、草稿/卡库、认证、问卷来源与文件宿主能力。Desktop 默认客户端、可手动选择服务器；Web 保持已有服务器路径。问卷输入不随执行位置切换丢失。成功生成、解析失败、保存失败、附加上传失败分别呈现，延续 D3.1 已有取消、重生成确认、草稿恢复与保留正文。

签名/原生性来自既有结果事实与服务端规则，不因选服务器强制画“已签名”，也不能让原 Desktop 的“未签名”硬编码错误覆盖 Hosted 结果。本轮不新增签名申请。

验收：同一问卷输入夹具在两个宿主产生一致业务请求；不要求模型正文逐字一致；切位置保留回答；保存失败不丢结果；取消恢复不自动生成；Web 既有操作不因共源回退。

## DESK-ONLINE-010 复用库模态框与数据归属

**MUST** 提取现有 `BattleDataModal` 和相关详情/问卷选择交互，保留「我的/公开/推荐/收藏/本地」等现有来源、筛选、摘要分页、正文按需加载和调用方 `visibleTabs` 限制，不新建两页签替代品。Web 包继续使用既有独立 `WebPackagePickerModal` 形态，不进入数据卡 `onSelectCard` 契约。

本地行不请求线上批量元数据或单卡接口、不带 `sourceDataCardId` 冒充线上卡、不要求登录。复制来源 `cloudRef` 是追溯信息，不是当前在线授权。Desktop 默认本地数据所有权，显式下载/上传副本；本地记录、账号私有缓存和可淘汰缓存分别管理。

注销/切账号取消对应在线请求并隔离缓存；迟到响应不得落入新账号或另一来源的列表。上传继续遵守卡槽、权限、审核、大小和版本规则；失败不回滚本地保存。线上版本 latest、preset 严格校验和生成时冻结沿用既有 Arena 规格。

验收：现有模态框回归在 Web 继续通过；Desktop 本地 tab 零项目请求；切 tab/账号竞态不串数据；选本地卡不伪造线上身份；包与数据卡的选择/删除契约不混淆。

## DESK-ONLINE-011 个人页与账号数据

个人页 `/me`、消息、历史和排行榜优先复用 Web 已保留的产品面，不复活 `/pvp` 专属功能。本机设置/本地库属于设备，线上账号资料/私有缓存属于账号，两者不可借登录绑定为同一所有权。

在线历史展示继承服务器的有限保留与权限规则；已过期正文明确提示，不把访问失败写成“暂无记录”，不承诺 Desktop 能自动恢复未下载的历史。保存本地副本是显式行为，结果的来源与存储位置分别显示。

验收：注销后本地数据仍在；换账号不显示前一账号私有历史；过期、无权限、失败与空列表分离；服务器历史下载失败不影响既有本地副本。

## DESK-ONLINE-012 原生认证与项目通路

首个在线私有读取/写入前 **MUST** 验证实际 Legacy/Better Auth 兼容、授权范围、会话过期/注销、Origin/CSRF、挑战和凭据持久化。不能复用 Web 同源 Cookie/localStorage 假设，不能用全局 CORS 放开或伪造 Origin 替代认证。

系统浏览器授权优先；采用 OAuth 授权码时按 RFC 8252 使用 PKCE，并校验回跳与本次请求绑定、短期一次性兑换和重放拒绝。该窄问题已由 D5.0c 落地为 `desktop-auth-v1` 协议：`/auth/desktop` 授权页 + `/api/auth/native/grant` / `/api/auth/native/exchange` 端点，loopback `127.0.0.1:<port>/callback` 回跳、一次性 120 秒 grant、原子消费；具体门禁见 `DESK-091`。回跳不可用的平台只提供明确浏览器入口，不偷偷加载有 native 权限的远端 UI。

账号 credential 与 AI Key 分命名空间及生命周期，均不得进入导出、URL query、日志或 Room 快照。项目服务使用固定受控 route/origin；新增 command/capability 前更新对应安全规格并验收。现有 Direct 的禁止项目域名、出站校验与重定向秘密保护保持不变。

验收：登录取消/错 state/兑换重放/过期/注销可诊断；原生私有数据未授权不得读取；账号凭据不进入 Direct；BYOK 例外仅按 005；未完成原生协议不得宣称 D5 在线总门禁通过。

## DESK-ONLINE-013 最小版本兼容与可用性

复用既有公开协议版本、能力/错误字段，为实际接入的操作提供最小兼容判断；需要新字段时以真实消费者为依据补契约。不建立全站 SDK、动态执行插件、大型远程配置 manifest 或额外证据平台。

兼容查询仅在主动使用在线能力时发生，不阻塞离线启动；查询结果不是授权凭据。旧客户端遇到不兼容写入时停止对应操作并说明升级需求；未知新增字段按既有契约处理，不能强行接受未来格式或因此清空本地配置。

验收：当前/已支持旧版本/不支持版本分别有结果；在线 schema 变化不破坏本地库；服务不可达时本地仍可用；主 UI 随签名构建发行，不运行期下载脚本。

## DESK-ONLINE-014 交付边界与公开性

实现按唯一 Desktop 计划细分，测试随行为交付；共源提取与 Web 回用同一提交闭合，Desktop 接线可紧随其后。阶段成功只以实际证据认定；实机工作可按维护者安排集中验收，不删除、弱化或倒填原门禁。

公开文档、示例、commit、测试 fixture 与截图不得出现未公开项目的可识别信息或私有素材；参考经验仅写非指向性描述。本规范本身不是发布公告，不得将拟实现能力写进面向用户的“已支持”清单。

验收：新增文件/链接/示例的公开性检查；改动范围与阶段一致；不把 D4b 在途工作带入 D5 文档提交；未运行实机/付费模型/生产测试时明确记录。
