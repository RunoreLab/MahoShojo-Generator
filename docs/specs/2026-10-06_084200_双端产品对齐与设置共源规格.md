## 0. 边界与当前状态

D5.1a-r1 已有实现、自动验证及请求 golden；本规格补其尚未共源的产品面，**不撤销当时已完成的交付记录，也不把实机 PENDING 改成通过**。源码基线及证据见[调研](../reports/2026-10-06_084000_Desktop共源对齐与后续功能调研.md)。

本地旅程不依赖、不等待项目服务；自动在线请求只在后台进行，不携带本地创作内容或 Direct 请求/Key（ADR §4 三原则，r2 起不再要求冷启动零项目请求）；Direct 与 Hosted 不混凭据；本地库与账号/公开缓存不混所有权；数据卡签名首期不新增机制；Strict/多人仍服务器权威。既有安全、资源限制、取消/unknown/no-replay 约束不因 UI 统一削弱。

## DESK-PARITY-001 共源闭包与对照范围

每个迁移区段 **MUST** 同时核对视图、状态转移、样式、图标/静态资源、导航、错误/空态与相关保存语义。共同部分进入实际共享 package；Web 同批回用。宿主不得通过复制文件或 app-to-app import 取得所谓共源。

抽取前记录“Web 当前行为 / Desktop 当前行为 / 目标 / 合理差异 / 回归用例”。未授权的产品改变不混入抽取；获授权的小改进在计划中点名、独立提交并说明双端影响。不能通过把 Web 降级为 Desktop 现状来获得一致。

验收：两端实际调用共享实现；共同流程有行为回归；所需 CSS/资源存在于两端生产构建。对照表是施工材料，不是永久全站 inventory 或源码形态 CI。

## DESK-PARITY-002 产品壳、主页与资源

TopBar 图标与首页标题 Logo 语义不同；前者共用 favicon，后者使用完整亮暗 Logo。AppShell **MUST** 明确 `undefined` 表示默认品牌、`null` 表示隐藏、自定义节点原样显示；修正当前 `brand ?? fallback` 与注释矛盾，Desktop 取消重复文字品牌。不得要求平台窗口标题同时隐藏。

首页 **MUST** 复用欢迎/账号欢迎区、新手推荐、功能分组网格、百科、页脚等共同区段；本地能力说明降为辅助状态，不替换产品欢迎语。账号未验证不显示已登录承诺。已实现的本地管理/设置入口始终可达。

产品目录拥有名称、分组、资源和路径；宿主仅投影交付/可用性及真实平台专属项。目录更新不自动开放未注册的路由。类别内无可用项可隐藏，不留空网格或死链接。

CSS 随组件消费闭包抽取：包括 HomeFeatureGrid 所需 `.feature-grid`/`.feature-button`，问卷页的主题作用域及结果卡外层。复用现有 `@source` 和构建测试，检查层叠顺序、选择器泄漏、窄屏/暗色/reduced-motion。不要整个复制 Web globals，也不要认为共享组件的 utility class 已编译就等于自定义 CSS 完整。

验收：断网首页；亮/暗主题；窄窗、缩放；共同入口名称/图标/主要 CTA；不双滚动；Web 原页面样式无非预期变化。

## DESK-PARITY-003 Footer、链接与公告

页脚静态文案、社群与赞助/反馈/百科/源码入口共源。当前源码入口使用 `RunoreLab/MahoShojo-Generator`；作者、赞助、历史引用不做全局替换。

站内链接使用 canonical 路径与宿主 Router；Web 普通点击及 Ctrl/Cmd/Shift/Alt/中键语义不退化。Desktop 明确内跳/系统浏览器动作，不把产品相对 URL 送到外部浏览器；未迁移线上页面仅以“在浏览器打开”明确入口处理，必要时提示不会自动携带本地内容。

native 打开能力只接受验证后的网页协议及当前所需目的地；固定产品链接可按标识映射。拒绝 `file:`、`javascript:`、任意自定义协议、含凭据的 URL 和路径注入。不为外链引入泛化 shell。当前 renderer 没有可调用的打开命令（`open` 只在登录流程的 Rust 内部使用），P1 新增的窄命令继续登记 handler/AppManifest/capability 三方清单。

非固定链接（Markdown、公告、卡片内容等来源）默认先展示完整目标域名并请用户确认；`externalLinks.confirmContentLinks=false` 时直接打开。固定产品链接不弹确认。关闭确认不影响上述 native 校验。Web 不提供该设置，链接行为不变。

公告视图与内容共源，数据获取由宿主注入。Desktop 先显示内置/已缓存公告及快照时间。默认 `announcements.checkPolicy="on-launch"`：每次启动在首屏可交互后请求一次固定公告资源；服务器提供 validator 时使用条件请求；失败保留旧公告并在公告区标注，不重试循环、不阻塞启动。用户可改为 `"manual"`，此时只在手动刷新时请求。两种策略都保留手动刷新入口，失败都保留旧公告。保留 pinned/dismiss 行为，关闭状态按公告标识持久化。兼容旧公告没有平台字段：作为“Web 发布记录”解释，不默认宣称该 Desktop 版本支持公告中的功能。新内容可带最小平台标记，但不建设远程功能开关平台。

公告 Markdown 为受控文本；外部图片/视频默认转为显式打开或加载提示，未同意不发请求。弹窗可键盘打开/关闭、焦点正确返回，不遮住正文操作。

## DESK-PARITY-004 当前问卷与结果完整交互

P2 对齐至少包含：当前页标题/布局；预设目录浏览、粘贴/文件导入、本地/云问卷选择；多问卷与 lore 开关；条件题/跳题、批量填充/角色卡导入/答案导出；快速随机；流式/非流式及位置选择；reasoning/错误/取消；结果卡外层、JSON/图片导出、本地保存；已有设置面板和有效页尾链接。

本地行为 **MUST** 共源，读取线上数据仍显式发生。选择器可进入离线表单，不以登录或 Provider 配置为前置。已有回答、草稿、未保存结果在来源切换/重载/离开时按既有语义保护，不因追求 Web 外观删除 Desktop 数据保护。

云端保存另在 D5.1d 的相应在线切片接线；图像生成另按图像能力迁移；resign 不在本范围。未完成的在线动作可隐藏或说明，不伪造按钮。字数建议、签名资格限制、传输/内存资源上限分别解释，不能把 `nativeAllowed` 当成本地可生成许可。

结果自动定位采用同一可复用行为：同一结果会话最多定位一次，已可见或用户已经滚过不拉回，尊重 reduced-motion。保存失败保留结果，含签名但未经验证的缓存/草稿不声称已验签。

沿用已有 domain golden，补到实际页面 dispatch/IPC 边界；把可见流程、闭合题拒绝、输入映射、字段省略和宿主专属字段做真实断言。不得因两端模型正文不相同误判共源失败。

## DESK-PARITY-005 已迁管理与百科

角色管理、本地库、百科 **MUST** 对照 Web 查缺：字段编辑/类型、卡片预览、导入导出、回收站、筛选/详情、页签、文章导航与错误面。只共源相同业务，不机械给账号库套设备所有权。SQLite 与 IndexedDB 的状态/空间提示允许不同，但动作名、成功与失败解释一致。

既有数据不因样式、分类或模板呈现变化重写摘要、ID、签名字段和 provenance。云端副本上传失败不回滚本地保存。新功能如模板转换/schema 校验若尚未迁移，必须作为可验收业务子项排期，而不是装饰性 disabled 按钮长期占位。

## DESK-PARITY-006 通用生成、历史与本地工具

Canshou 复用已稳定问卷区段；Free/Scenario 分别迁移输入、附件/模板、生成与结果；Creator 复用其实际工作台区段，不强行套问卷布局。不同生成族的 Hosted 请求与可恢复性逐条核对，不能把 Arena lookup/replay 能力推断为所有端点共有。

Sublimation 迁移先隔离既有 NarrativeHistory 的读取、选择与参考合成；只抽实际端口，不把整个 Arena store 导入 Desktop。普通本地卡成长不要求先有排位/多人。

Tavern、组队、问卷编辑、工坊、茶会各独立纵切，声明草稿/会话/图像的持久化及导出范围。文件/PNG/JSON 导入不得自动创建 Provider、授权 Web 包或调用 AI。不存在 UI 的底层储存能力不能宣称该旅程已交付。

## DESK-PARITY-007 Desktop Esc 快捷菜单与统一 Escape 层级

**范围与开关。** 菜单视图与层级逻辑在 ui-web shell 共享，只有 Desktop 装配启用；Web **MUST NOT** 默认挂载。Desktop 由 `desktop.escapeMenu.enabled`（默认 true，见 DESK-SET-007）控制；关闭后 Esc 只关闭弹出层，不打开菜单。

**统一层级。** Escape 在 shell 内只有一个 document 级分发点。现有消费者——BaseModal 栈、CardLibraryModal（含其详情子层）、TopBar 移动抽屉与桌面下拉、custom-select 等——**MUST** 在启用菜单前迁入同一「最高层优先」顺序；以扩展 BaseModal 已有的弹窗栈为准，不新建通用输入/命令框架。规则：

- 只有 `key === 'Escape'` 且非 `repeat`、非 `isComposing`、未 `defaultPrevented` 时才分发；
- 一次 Esc 至多由一层消费；最高层消费（或明确阻断）后立即停止，不同时关闭下层或打开菜单；只有被消费/阻断时才 `preventDefault`；
- 菜单是最低层：没有任何层消费、焦点不在原生文本输入（input/textarea/contenteditable）时才打开，避免长文本作答时误触；
- 迁入后原组件不得保留自己的 document 级 Escape listener；元素内部的局部按键（如下拉方向键）可以保留。

**非破坏语义。** Esc 与菜单 **MUST NOT** 取消生成、放弃草稿、触发保存/上传或任何网络请求；菜单打开期间在途生成继续。菜单内跳转走宿主 Router，受现有 `useLeaveGuard`/路由 blocker 约束；被拦截时关闭菜单并显示守卫提示，不绕过守卫，不提供「强制离开」。

**内容与可达性。** 首版动作：继续（关闭）、首页、本地库、百科、设置；只列出 Desktop 已交付路由，当前所在页标记为当前项而非跳转。每个动作 **MUST** 能通过可见 UI 到达，Esc 只是加速器。菜单使用 BaseModal 语义：`role="dialog"`、初始焦点在「继续」、Tab 约束、Esc 关闭、焦点返回打开前元素；上下方向键可以在项目间移动。退出应用不在首版（需要新增窗口关闭 capability，另行评估）。

**与既有债务合并。** 计划中 TopBar 下拉缺 Escape dismiss、移动抽屉缺焦点约束/返回的 Release hardening 项随本条实现；修复在共享组件内完成，Web 同时受益，但 Web 不挂载菜单。

验收：弹窗/卡库详情/抽屉/下拉打开时 Esc 只关闭最上层；IME 组合中、按键重复、文本框聚焦时不开菜单；生成中开关菜单请求不受影响；忙碌页面通过菜单跳转被守卫拦截；关闭开关后不再出现菜单；焦点返回正确；Web 构建不挂载菜单。真实 WebView 键盘/IME 验收列入集中实机清单。

## DESK-SET-001 统一信息架构与可用性

两端提供共同设置页面壳、分组名称、搜索当前可用设置的入口（规模确有需要时）、字段标签/说明、保存/撤销/错误投影；Desktop/Web 专属项只由相应宿主声明。首版不建设动态 schema 表单引擎，复用显式组件和受控 props。

`/me` 保留展示与历史；资料编辑可从 me 和 settings 到达同一共享面。Web 新 `/settings` 与 Desktop 原 `/settings` 使用一致章节定位。旧 `/me?tab=settings` 兼容到对应章节；密码恢复 `token` 等敏感流程保留既有 handler，不能经普通 redirect 广泛传播。

携带恢复 token 的 URL **MUST** 只经整文档导航到达（地址栏直达、邮件链接、服务端 `redirect()`），不得经 Web 端 SPA 客户端导航（`<Link>`、`router.push/replace`）进入。原因：GA 等分析脚本一旦在先前页面加载会监听 history 变化并自动上报 `page_location`（含 query），目标路由卸载分析组件不构成防护——不变量落在 URL 生产侧，而非目标页渲染侧。

未登录可以改设备外观/本地偏好；只有账号章节才按需读取会话。无此宿主能力的条目隐藏；暂时离线、权限不足和未验证分别解释。账号安全流程首期可明确外部浏览器完成，不把系统浏览器承载误称本地原生实现。

## DESK-SET-002 资料缓存、编辑与状态

资料缓存以服务范围和 userId 隔离，禁止只按 username 或一个全局头像键保存。缓存资料不得包含 token、Cookie 或 Provider Key。avatarDataUrl/文件只接受既有允许图像形态和大小，不能用任意远程 URL 偷偷发出资源请求。

启动时先读取非秘密快照，显示“上次账号，尚未验证”；不得投影 active，也不能据此上传/修改资料。存在已保存凭据时，宿主在首屏可交互后后台校验会话，成功后刷新资料并更新缓存；失败按离线/过期/服务错误分别投影，不清除本地库。无凭据时不发账号请求。头像/个性签名/徽章更新后更新同一缓存和顶栏，不维护两份长期状态。异步回复不能覆盖另一账号或用户正在编辑的草稿。

资料保存必须以服务端确认结果为成功；请求结束不等于保存成功。表单保留 dirty 值，初次加载正确填入，失败可重试，离开时提示未保存。离线编辑可保留带账号作用域的草稿，但不自动排队上传。登出清除相应账号缓存与订阅，本地库/设备偏好不变。

消息未知与零条未读区分；断线不自动清零。会话 active 后按 Web `useTopBarMessages` 模型刷新摘要（缓存过期才查询、窗口回到前台且过期时再查、本地消息变更时刷新、隐藏时不查），复用同一刷新间隔常量，不另设更激进的轮询；账号退出即停止并清理。不强制后台推送。

## DESK-SET-003 字段权威与迁移

每个迁移字段记录：语义、scope、现 owner/key、目标 owner/key、默认、是否敏感、写入确认、兼容、失败恢复和导出范围。目标是所有权明确，不要求所有存储合并。

| 现有类别 | 本轮规则 |
| --- | --- |
| Web Provider/model/参数和主题等偏好 | 保留既有命名空间及手填 modelId，随真实字段迁移一次切换 writer |
| Desktop AI overlay | 继续由既有 singleton store 持有；未明确迁入配置文件前不得双写 |
| Desktop Provider Profile | 继续 SQLite，保留 ID、secretRef、时间及用户修改 |
| API Key/账号 credential | 继续 OS secret/native；普通配置和诊断不读回 |
| 云端资料 | 服务器权威；本地只是展示缓存/草稿，不自动变成账号设置同步平台 |

迁移须幂等；目标写入确认前保留旧源，迁移成功后只启用一个 writer。不能让旧版/未知字段被静默删掉，也不以失败为由自动选择第一 Provider 或改成服务器。

## DESK-SET-004 人工配置格式与读取

Desktop 的用户配置路径由 native 的应用配置目录解析后固定为 `config.json`，不按当前源码/进程工作目录寻找。设置页可显示路径、打开该固定目录和显式重载。Web 不显示本地文件选项。

文件为 UTF-8 JSON，顶层带 `version: 1`；字段只在已有真实消费者时登记共享 schema，提供同版例子/字段说明。S2 随首个真实消费切片交付（DESK-SET-007 中任一 Desktop 专属字段：Esc 菜单开关、公告策略、外链确认或 K1 缓存策略，以先落地者为准），不单独交付只能存 `{version:1}` 的空配置系统。不同时支持 TOML/JSONC，不引入优先级复杂的多层文件/环境变量覆盖。

缺文件时使用内置默认且不强制落盘。显式保存/生成示例才创建文件。读取前有有界字节限制，校验字段类型、范围和版本；未知字段/未来版本产生可定位错误并保留原文，不能当成有效空配置。

配置错误时，本地阅读仍能启动；可安全降级的展示偏好明确使用默认或上次有效快照，页面显示诊断。执行位置、连接引用等一旦迁入，错误必须阻止受影响的执行配置生效，不得静默替换。日志不打印用户原始配置值，避免用户误填 secret 后泄露。

## DESK-SET-005 写入、重载与冲突

UI 与手工修改必须经同一解析/校验语义。native 只暴露固定配置读写/重载命令，不授予 renderer 任意文件接口。TypeScript schema 负责共同语义，native 独立检查字节/路径/必要执行安全边界；不复制领域实现。

UI 保存携带读取时的文件 revision（基于实际内容的变更标识，不仅 mtime）；native 串行写入并在替换前复核。发现外部改动返回冲突，保留双方内容并提示重载，不静默覆盖。先写同目录临时文件、flush/sync，再用目标平台可靠的原子替换；保留上次有效文件的恢复路径。此本地变更检测不是源码证据 hash 门禁。

首版推荐关闭应用手工编辑，或编辑后显式重载；不承诺与不遵守锁的任意编辑器实现无窗口的协同合并。正在生成的任务使用已冻结快照，新配置只影响下次操作。配置写失败不报“已保存”，也不能把内存值冒充落盘值。

portable library archive 不包含此配置；D2 备份范围不被暗改。需要导出配置时是独立明确动作，排除 secrets；不得把可移植库包宣称“全部设置已备份”。

## DESK-SET-006 不可配置的安全边界

普通配置不能修改项目服务 origin、任意 secret/header、CSP、IPC capability、Web 包信任、Strict/多人资格、签名校验或兼容门禁。开发调试覆盖仍按既有受控编译/开发配置，不进入用户文件。

配置不新增无实现的自动签名开关、模型下载、自动云同步或隐藏能力解锁。合法 Direct 自定义配置仍通过现有 Profile/native 校验，不能用安全限制为由取消已接受的自定义端点能力。

下表只登记已有真实行为的字段；字段名是目标示例，实现时随共享 schema 定稿，但 scope/owner/默认值属于本规格。每项在消费切片落地后才出现在 UI 中，未落地不显示占位开关。

## 验收最小集

| 范围 | 必须观察到的行为 |
| --- | --- |
| 壳/首页 | 默认/null/custom 品牌；正确图标/网格与本地资源；可见入口确实可达；阻断项目域名时首页与本地旅程照常可用、不等待在线请求 |
| Web 回用 | 旧主要 CTA、主题、modifier-click、表单/结果行为保持；小改进有独立用例 |
| 问卷 | 预设/导入/多问卷、条件题、批量、快速随机与取消；golden 达到实际请求边界 |
| 结果 | 导出/本地保存失败不丢正文，uncertain 不自动重发，不伪造签名 |
| 资料/消息 | 有凭据启动后台校验/无凭据不发账号请求；未验证缓存、账号切换、迟到响应、失败保存、头像删除与未知未读正确；隐藏窗口不轮询，退出即停止 |
| 设置 | 离线设备设置无 auth；Web/应用专属项不串；旧深链接与敏感回跳仍有效 |
| config | 缺失/损坏/未来版本/写失败/外改冲突/重载；单一 writer；重启读取；在途任务不变 |
| 首批设置项 | 页面与设置页修改同一偏好值；重置不碰草稿；动效/自动定位双端生效；公告 `on-launch` 每次启动至多一次请求且失败不阻塞、`manual` 只在手动刷新时请求；内容外链确认可关、native 校验不可关；非法值按降级规则处理并诊断 |
| Esc 菜单 | 层级只消费一次；IME/重复/文本框不开菜单；生成不取消；守卫不绕过；开关有效；Web 不挂载 |
| 无障碍/实机 | 键盘、焦点、IME、窄屏、缩放、减少动效；Tauri 原生验证集中记录，不由 jsdom 替代 |
