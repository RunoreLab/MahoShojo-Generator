## DESK-PROD-001 产品入口与覆盖

Desktop **MUST** 以产品首页启动，沿用 Web 的品牌、导航分组和已迁移功能的名称与主要交互。运行时自述与 Provider 测试面板 **MUST NOT** 作为最终首页；配置归入设置，首次生成可在上下文中引导配置。

首页、`/details`、`/character-manager` 与 `/encyclopedia` 是逐步迁移的核心旅程。功能未落地时 **MUST** 隐藏不可执行动作或显示明确原因，**MUST NOT** 保留可点击但失效的内部链接。路径与导航的实现来源 **MUST** 共源，不能维护两套手工同步的完整路由配置。旧文档将 `/battle`、`/arena` 误称为 PVP 的口径不再适用：二者是保留的 Arena，按 D5 规划迁移；已退休的 `/pvp` 不恢复，D3.3 旧任务不重新启用。

验收：在未登录、未配置模型的安装包中进入首页、百科、问卷及已交付的本地管理入口；逐一点击可见导航，不出现依赖 Next server 的白屏、远端主 UI 或静默 404。首发覆盖清单不得把后续功能算作已交付。

## DESK-PROD-002 共享实现与依赖方向

新迁移的页面、组件和功能 hooks **MUST** 按真实复用需要提取到 `@mahoshojo/ui-web` 的显式入口；纯规则、Prompt、schema、归档继续归现有专职包。Web **MUST** 回用同一实现，**MUST NOT** 让“共享包里的 Desktop 副本”与 Web 原实现长期并存。

共享 UI **MUST NOT** 导入 Next、Tauri、服务器秘密或 `apps/*`；所有 app-to-app 深导入和 alias 绕行仍被禁止。平台检测只允许在 app 组合入口或平台适配边界，不扩散为共享业务的双套分支。

验收：依赖边界检查覆盖新增客户端包；Web 和 Desktop 构建消费同一 feature export；一个共享组件的行为修复在两端对应测试都生效。不能以“复制文件后肉眼相似”替代此项。

## DESK-PROD-003 最小能力注入

页面 **MUST** 复用已有 `AiExecutionPort`、`CardRepository`、`WebPackageRepository` 等契约；新边界仅在实际需要时增加。导航、文件、在线认证和可执行内容 hosting 通过窄适配注入；不建立无消费者的通用 registry 或另一套同义 generation transport。

产品能力状态 **MUST** 区分未配置、需登录、无网络/服务失败和尚未实现；**MUST NOT** 把这些状态都显示成“没有数据”。可用性提示 **MUST NOT** 被当作 native ACL、服务器授权或数据可信性证明。

验收：用最小 fake adapter 驱动共享页面的可用/不可用/失败状态；绕过隐藏按钮仍不能越过 native 或服务端权限；Next 专属 `refresh()` 不被模拟成在所有宿主都完成同样业务刷新。

## DESK-PROD-004 本地启动与出站边界

主 UI、样式、字体、内置预设和百科必要资源 **MUST** 来自本地产物。离线首页、问卷编辑、已有本地卡/历史阅读、保存与归档旅程 **MUST NOT** 要求账号、项目可达或远端初始化。

Direct-local、Direct-remote 与 Hosted **MUST** 有明确区分；Direct-remote 可联网访问用户指定供应商，但不得因此被称为全离线。页面 **MUST NOT** 因复用 Web bootstrap 自动挂载登录探测、公告轮询、统计、挑战页或其他项目请求；主动进入在线能力后的请求按该能力独立授权。

验收：本地-only 用户旅程同时观测 renderer 与 native 的网络出口；覆盖 fetch/XHR、WebSocket/EventSource、图片/样式/脚本等资源请求，不只 stub 一个 fetch。纯导入旅程零网络；Direct 旅程允许选定供应商但项目请求为 0；离线启动断开项目服务仍成功。测试守卫自身需有负向验证。

## DESK-PROD-005 生成语义与费用边界

问卷、角色生成、单人休闲战报等已迁移流程 **MUST** 复用输入组装、Prompt/结果契约、解析和错误语义，Desktop 默认使用 Direct 端口。Web 原 Hosted 路径继续可用；这不要求 Desktop 在 D3 就提供 Hosted。

单次生成 **MUST** 固定执行意图与输入，复用既有 request identity、取消、事件排序与唯一终态语义。Provider 不支持的能力 **MUST** 说明而不是用不兼容参数静默发起请求。

**MUST NOT** 在失败后自动跨 Direct/Hosted 重试，或仅因切页/重挂载/网络失败重发 AI 请求。用户主动启用 Strict 或多人时，允许在 dispatch 前将有效位置锁为服务器并解释原因；退出后恢复普通偏好，不自动发起生成。Strict、多人与权威结算继续走既有服务器流程并重验资格，不能把本地结果冒充权威结果。

验收：共享输入夹具走 Web 与 Desktop 适配验证契约；不要求非确定性 AI 产出逐字节一致。覆盖取消真正中止上游、半截输出、解析失败、重复点击和断连；所选模型失败后没有第二个执行者收到同一任务。

## DESK-PROD-006 数据源、存储与副本

Desktop 角色管理与选卡 **MUST** 把本地库作为无需登录的一等数据源；默认本地保存，上传/下载云端副本是显式动作。存储位置与 provenance **MUST** 正交，不能把本地卡一律视为无签名或把云端卡一律视为可信。

**MUST NOT** 新增自动双向同步、隐式上传、云端删除向本地传播，或把用户本地记录与可淘汰云缓存混为一体。退出/切换账号不得删除设备所有数据。用户切换数据源后，迟到响应不能写入另一个来源的列表。

既有 canonical digest、ID、tombstone、import existing-wins、归档安全限制和服务器上传重验继续有效。浏览器存储与 Tauri 存储通过显式导入导出迁移，**MUST NOT** 暗读浏览器配置目录。

验收：未登录创建/编辑/恢复/导出本地卡；登录再退出本地数据仍在；上传失败不回滚本地保存；本地/云端来源可见，重名不静默覆盖，切换来源的竞态不会泄漏列表。

## DESK-PROD-007 草稿、会话与历史

每个迁移 feature **MUST** 明确其草稿、会话、历史、偏好和缓存的 owner、存储 adapter、恢复与导出范围。**MUST NOT** 把 D2 的卡/包库视为已经迁移全部业务存档，或因换宿主而改变用户已保存数据的含义。

初始化或落盘失败 **MUST** 报告；不得悄悄退到另一套存储/易失内存后继续显示“已保存”。恢复操作不得未经确认覆盖用户新编辑。归档/备份界面必须说明实际包含内容，不包含凭据的归档不得暗示可恢复所有秘密。

验收：对应 feature 的草稿重启恢复、取消恢复、库不可用、落盘失败与旧数据导入；检查备份范围文案与实际清单一致。尚未迁移的数据类型明确标识，而不是静默遗漏。

## DESK-PROD-008 导航、关闭与在途工作

共享 feature 声明未保存内容与在途任务，宿主 **MUST** 区分内部导航、同页 query 身份变化、浏览器卸载和 native window close。**MUST NOT** 只依靠 `beforeunload` 或 router mock 宣称窗口关闭保护已完成。

首条生成纵切 **MUST** 定义离开时继续、取消或阻止的实际行为，确保真实任务 owner 与 UI 一致。在没有可恢复 owner 的阶段，应阻止无提示离开，不承诺后台继续或进程退出后恢复上游连接。取消、保存、回到页面不得产生双次提交。

验收：返回/前进、同页 query、拒绝离开后 URL 与页面一致、百科锚点、弹窗焦点返回、关闭窗口确认及其取消。涉及 native 的行为在真实 Tauri 宿主验收；保留路径草稿和部分输出，不用路由引擎默认值替代产品决定。

## DESK-PROD-009 主题与资源

主题、品牌资源和共享控件 **MUST** 单点维护；支持已有亮/暗主题与问卷主题。Desktop 临时面板的独立主题不继续扩成新设计系统。

共享资源通过受控的构建输入进入两个产物；**MUST NOT** 在运行时读取 Web app 目录，也不复制全量 public/临近仓库私有素材。新增资源检查许可证、路径与体积；共享源码的 Tailwind 扫描、CSS 顺序和字体加载必须覆盖真实生产构建。

验收：两端同一参考页面的主题、主操作、可访问标签和响应式行为一致；Windows 缩放与高 DPI 下按钮可达，键盘/输入法正常，减少动态效果偏好生效。视觉差异有原因，不以逐像素相同为门禁。

## DESK-PROD-010 可执行内容与权限

共享层可复用 Web Package/HTML 的结果契约、控制按钮、许可与导出语义，**MUST NOT** 把 Web 的主 UI iframe 承载方式搬进 Desktop。

Desktop 继续遵守 `DESK-010` 至 `DESK-014` 的相关隔离要求；创建第二个 webview 前先启用 `AppManifest::commands`，验证注册 command、ACL 清单与 main-ui 权限一致。零 capability 渲染面、浏览器权限默认拒绝、受控 resolver 与 native 能力不可达均需成立。

验收：不可信 HTML/包无法读取本地库、secret、任意文件或调用自有 command；同源/导航变化不提升权限；退出该渲染窗口不重置主界面编辑状态。无真实宿主验证时保留未验收标记，不用浏览器 iframe 测试代替。

## DESK-PROD-011 在线接入与登录隔离

线上库、账号、Hosted、排行榜、多人与消息通过独立在线适配按需接入；**MUST NOT** 为统一调用而把项目域名加入 Direct Provider，或者暴露任意 URL/header 的 native 网络代理。普通项目 API 不携带 Provider Key；用户明确选择服务器预设 BYOK 时，仅专用生成适配发送所选 Key 并明示接收方，遵守[DESK-ONLINE-005](./2026-10-04_202000_Desktop线上本地整合与AI配置共源规格.md#desk-online-005-系统默认与服务器-byok)，不扩张 Direct 权限或开放 secret 读回。

首个在线写入前 **MUST** 验证真实认证协议、Origin/CSRF、会话过期/注销、需要时的系统浏览器回跳与凭据存储。不能直接复用 Web 的 localStorage auth 凭据和同源 Cookie 假设，也不能通过全局 CORS 放开来绕过问题。服务器仍按原权限、卡槽、审核、幂等、签名与房间权威规则重验。

验收：登录取消/过期、服务器失联、跨账号缓存、上传失败与旧客户端协议不兼容时可诊断；用户仍可回到本地功能。没有 native 在线适配的长尾入口只能明确打开系统浏览器，不静默创建有权限的远端 WebView。

## DESK-PROD-012 数据卡签名延期

首期 **MUST NOT** 增加手动申请签名按钮、申请队列或空壳设置；本地生成不以签名为前置。已有签名字段按契约保存，无法验证时不宣称官方已验签。

未来自动签名受 `ADR-desktop-shared-product` §5 约束：默认关闭；先有服务器可独立验证且绑定精确输出的信任协议，再在流程中自动请求。客户端来源、本地 schema/摘要或“官方安装包”不能单独作为签发依据。失败不丢本地结果，不自动重发 AI 请求。

验收：首期本地生成/保存/导入无签名请求、无手动申请入口；携带旧签名的导入无损，未验证的 UI 不误报可信。Tauri updater 签名门禁保持有效，不因本条延期而关闭。

## DESK-PROD-013 技术选型与版本交付

新增技术仅服务当前切片，优先最新正式且兼容版本；安装前核对官方来源、维护、license、engine/peer 和目标宿主，以锁文件固定。邻仓仅作经验参考，不是本仓库隐性依赖。任何全栈/跨包版本升级 **MUST** 独立论证和验收，不能混入页面提取。

共享代码更新通过两个 app 正常构建/发行同步；**MUST NOT** 运行期热载远端主 UI 代码。在线 API 需处理已安装旧客户端；不兼容时明确拒绝危险写入或提示升级，而不是无条件假定最新 Web 与 Desktop 同时发布。

验收：从 clean checkout 两端可构建；共享依赖变化触发两端相关测试；安装包不含服务器秘密/开发私有文件；旧版在线失败不会毁坏本地库。实际包版本只记录在 manifest/lockfile，调研快照不构成锁版要求。
