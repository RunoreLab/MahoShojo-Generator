# 文档导航

`docs/` 负责存放主题入口、决策记录、规格、阶段计划、架构、报告、参考资料与过程日志。

## 目录说明

- `topics/`
  - 按主题提供稳定导读页，汇总当前口径、核心文档与未决问题。
- `decisions/`
  - 存放单点稳定决策，适合长期引用。
- `migration/`
  - 存放迁移台账、字段映射与兼容损耗记录模板。
- `specs/`
  - 存放概念初稿、结构草案与后续规格文档。
- `plans/`
  - 存放阶段计划与跨多轮推进顺序。
- `architecture/`
  - 信息架构、仓库结构、协议边界与系统分层说明。
- `reports/`
  - 阶段性设计决策、评估与专题报告。
- `references/`
  - 来源笔记、其他仓库复用清单、外部资料摘录。
- `logs/`
  - 过程留痕，不作为稳定结论源。
