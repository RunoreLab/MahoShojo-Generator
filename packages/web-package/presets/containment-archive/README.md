# 存续院收容档案

社区作者：**冉霖**。本包来自魔法少女生成器&竞技场①群内 Web 包征集，作者同意投稿；原投稿版本为 `continuance.cx-archive-package@1.3.2`，本项目接入修订版为 `1.3.3`。来源与素材说明见 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。

AI 只生成 `data/archive.json`，静态入口和包内脚本负责装配档案。生成前的数据是明确的等待占位页；`generation/example.json` 是供 AI 参考和验收的完整档案，不会自动替代本场生成内容。

## 内容与资源

- 保留宣纸 / 玄墨主题、权限黑条、认知检查、收容失效、附录模块及打印演出。
- 认知检查、权限与档案科记录均为本页内的虚构交互，不上传检查结果，也不因阅读订立实际保密协议。交互状态刷新后重置。
- 全部运行资源来自包内 HTML、CSS、JavaScript、JSON 与 SVG；无外链资源、照片、音视频、字体文件或第三方运行时依赖。
- 附录由 `modules/registry.json` 登记，生成数据只选择模块；模块代码与版式仍由包本体提供。
- 复制编号使用浏览器剪贴板能力；不可用时会提示手动选择。权限演出不要求宿主同源授权。

## 本次接入修订

补充项目内容边界、角色设定忠实性与事实记录规则；明确虚构演出措辞及作者署名；修正元数据示例中“失去左翼”与“左翼轻伤”的矛盾。未改变目标 JSON 结构、模块装配协议或生成前占位内容。

## 验收要点

1. 用 `generation/example.json` 形成 Overlay 后，正文与声明的附录可正常装配；未声明模块不加载。
2. 检查进入 / 跳过认知检查、权限黑条、目录抽屉、主题切换、录像、信件、签章与打印。
3. 在受限模式中确认包内资源可用，外部网络不可用时主体验完整。
4. 检查手机宽度、键盘导航和减少动效偏好；生成的字符串按文本处理，不执行其中的 HTML 或脚本。
5. 下载 ZIP 后重新导入，应得到相同包身份与资源；实际模型生成仍需同时通过 JSON schema 和宿主尾注校验。
