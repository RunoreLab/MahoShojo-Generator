# 竞技场新闻资源包

本目录中的文件是资源包的静态源文件。构建流程生成文件索引与摘要；使用和下载均基于这些文件。入口只是等待生成的说明，AI 完整替换 index.html，包本体保持不变。

## 资源选择

- ai/instructions.md 与 ai/assets.json 面向 AI 投影，包含完整路径、用途、标记契约和可独立理解的示例。
- styles/tokens.css 与 styles/news.css 提供可选视觉原语：暖白报刊、夜间与蓝色播报变量；不固定信息架构。
- scripts/news.js 是无依赖经典脚本。推荐放在 body 末尾；支持 DOMContentLoaded 自动挂载。所有状态在内存中，不联网，不读取 cookie/storage。
- components/ 中是单项组件参考片段，不是可加载的网页或模板引擎。AI 自己生成内容并组合到唯一 HTML。
- assets/ 中为可直接 img 引用的 SVG 素材；来源见 THIRD_PARTY_NOTICES.md。

脚本自动挂载 document；window.ArenaNews.mount 仅用于独立 DOM 根的高级场景，同根幂等，不应重叠挂载。搜索为一个全局过滤器。所有路由 view 的键唯一，home 为首页；未知路由回退首页。收藏点赞按键同步，投票每组一次，评论每篇上限 50 条。所有模拟状态刷新即消失。

## 验证清单

在有脚本能力的包预览中，生成含两个详情 section、全局状态区及选用组件的 index.html，再检查：

1. 首页→详情→另一详情→浏览器后退及未知 hash 回退；键盘焦点移到文章标题。
2. 关键词与分类组合过滤、零结果提示、清空恢复；不会隐藏文章正文。
3. 同键收藏按钮同步、点赞再取消、投票不能重复提交。
4. 空白评论不提交，HTML 字符作为文本显示；评论与笔名长度受限。
5. 模拟广告与订阅提供可见/可读屏提示；没有网络请求或真实个人信息要求。
6. 刷新后模拟状态重置；不允许 storage 的 sandbox 中运行正常。
7. 手机宽度、键盘 Tab、焦点可见、图片 alt、浏览器缩放与禁用脚本后的内容可读性。

不需要外部 CDN、图标字体、追踪器或生产依赖。默认完全离线。
