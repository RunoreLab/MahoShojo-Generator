# AI 生成失败：常见原因与自救

> 作者：[Colanns](https://github.com/colasama) / [末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-01-05

当你在生成角色/情景/战报时看到「生成失败」「魔法失效了」之类提示，通常不是“你写错了”，而是以下几类原因之一。

## 你可能会看到的现象

- 输出中断、内容为空、长时间转圈后失败
- 提示「模型不可用 / 额度不足 / API Key 无效 / 未知的模型」
- 提示「服务端响应异常 / 服务器内部错误（HTTP 5xx）」

## 常见原因（按概率从高到低）

1. **高峰期排队/拥堵**：同一时间请求太多，生成容易超时或失败
2. **自定义通道配置问题**：供应商/模型 ID 选错，或 API Key 未填/已失效
3. **上游限流或额度不足**：模型供应商返回 rate limit/insufficient quota
4. **输入过长/任务过重**：提示词太长、要求太复杂，导致生成时间过长或触发上下文限制
5. **内容风控/敏感拦截**：触发站内安全机制会跳转到逮捕页

## 自救建议（优先顺序）

- **先重试 1 次**：高峰期的偶发失败很多
- **缩短输入**：减少背景设定、删掉不必要的长段落，把任务拆分成几次生成
- **切换生成方式**：对战报优先使用支持流式输出的模式（更不容易“全无”）
- **检查自定义通道**：重新选择供应商/模型，确认 API Key 没有多余空格
- **仍然频繁失败**：更可能是网络或 Cloudflare/服务器问题（见下方相关条目）
