# 通用数据卡（Markdown）：通用角色 / 通用情景

> 作者：[末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-01-14

0.7.0 版本起，站内多处会出现两种“最自由”的数据卡：**通用角色**与**通用情景**。它们的共同点是——字段极少，正文用 Markdown 写，特别适合创作者做长线设定与反复复用。

## 1) 这两种卡分别是什么？

### 通用角色卡（templateId=通用角色）

- 只有 `name` + `content` 两个核心字段
- `content` 推荐写成 Markdown 小传/设定集/口吻说明

### 通用情景卡（templateId=通用情景）

- 只有 `title` + `content` 两个核心字段
- `content` 推荐写成 Markdown 舞台设定/规则/长线笔记

你可以把它们理解为：**“一张可以被系统使用的 Markdown 设定卡”**。

## 2) 什么时候该优先用“通用卡”？

- 你想写**长文本**（人物小传、世界观、口吻、规则），不想被结构化字段限制
- 你想做**可维护的常驻设定**（后续只改 Markdown，不用改一堆字段）
- 你在做**跨生态迁移**（例如从 SillyTavern 导入一张角色卡，再整理成通用角色）
- 你想用**流式生成**边看边改（流式输出会被包装成通用卡）

## 3) 怎么创建通用角色/通用情景？

### 方式 A：角色问卷的「流式生成」（生成通用角色）

1) 打开 `/details`（魔法少女）或 `/canshou`（残兽）  
2) 在「生成方式」选择 **流式**  
3) 提交生成后，会实时输出 Markdown，并自动生成一张**通用角色卡**

### 方式 B：箱庭物语 `/scenario`（生成/编辑通用情景）

你可以在页面底部的「通用情景卡（Markdown）」区域：

- 创建空白通用情景卡（自己写 Markdown）
- 将结构化情景一键转换为通用情景卡
- 选择流式生成：实时输出 Markdown，并直接生成通用情景卡

### 方式 C：自由生成 `/free`（生成通用角色/通用情景）

在 `/free` 里选择 Schema：

- 通用角色卡（Markdown）
- 通用情景卡（Markdown）

然后用你自己的提示词生成即可（也支持参考附件）。

## 4) 让系统更好“读懂名字/标题”的小技巧

流式生成时，系统会尝试从 Markdown 里解析名字/标题；解析失败会回退到页面默认值。为了更稳，建议在正文靠前写清楚：

- 通用角色：`代号：...` / `名字：...`（或用 `# 标题` 开头）
- 通用情景：`标题：...`（或用 `# 标题` 开头）

## 5) 怎么把通用卡拿去“上场”？

- **通用角色**：可在 `/arena` 作为参战者使用（跨模板混战时也更稳）。
- **通用情景**：在 `/arena` 的「情景模式」里可作为主情景/辅助情景上传或粘贴使用。
- 你也可以在 `/character-manager`（档案馆）保存到云端、编辑、公开分享。

## 6) 常见限制（别踩坑）

- 通用卡字段少：某些依赖结构化字段的功能（例如特定字段展示/自动提取）可能效果更弱或不可用。
- 通用卡（尤其是**流式/自由生成/手动创建**）通常不包含 `signature`，因此会被视为**非原生卡**。  
  原生性会影响部分口径（例如严格排位/部分审核展示等），详见：`/encyclopedia/native`。
