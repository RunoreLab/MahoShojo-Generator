# 成长升华

> 作者：末伏之夜  
> 更新时间：2026-01-03

“成长升华”是一个把角色设定“沿经历升级/蜕变”的工具：它会在保留你指定要素的前提下，让 AI 生成一个新的形态设定（新 JSON）。

你可以把它当作：

- 角色的“二转/觉醒/进化”
- 或把原设定迁移到另一个模板体系的“重铸”

## 基本流程（推荐）

1) 选择输入：上传 JSON / 粘贴 JSON / 从数据库选择  
2) 选择目标模板（默认沿用识别到的模板）  
3) （可选）填写成长引导：你希望她“怎么成长、付出什么代价、留下什么后遗症”  
4) 开始升华 → 下载结果 JSON → 回到档案馆查看/编辑/保存

## 高级选项：读写历战/状态栏

升华支持决定是否读取/写入：

- 历战记录（`arena_history`）
- 状态栏（`current_state`）

经验建议：

- 想做长线剧情与连续成长：可以开启读取  
- 想要“纯设定重构/不带前尘往事”：关闭读取更干净  

## 高级选项：保留字段

你可以指定“哪些字段不改”（例如外观、核心概念、问卷答案等）。  
这会让升华更像“成长”，而不是“换人”。

另外：当你跨模板升华时，系统可能会自动取消保留字段，让 AI 完全重塑，以避免结构不兼容。

## 常见问题

### 为什么升华失败或被拦截？

- 输入 JSON 不可解析 / 结构不符合预期
- 文本触发了敏感词过滤（会被拦截并可能跳转到逮捕页）

可以先看：

- `/encyclopedia/sensitive-words`
