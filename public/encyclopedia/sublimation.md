# 成长升华

> 作者：[末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-01-05

“成长升华”是一个把角色设定“沿经历升级/蜕变”的工具：它会在保留你指定要素的前提下，让 AI 生成一个新的形态设定（新 JSON）。

你可以把它当作：

- 角色的“二转/觉醒/进化”
- 或把原设定迁移到另一个模板体系的“重铸”

## 1) 它适合用来做什么？

- **续写式成长**：读入历战/状态栏，让角色“带着前尘往事”成长。
- **跨模板迁移**：把魔法少女/残兽/通用角色互相转换，再由 AI 补全结构与设定。
- **保留核心不换人**：勾选保留字段，让成长更像“同一个人变强了”，而不是“换了个人设”。

## 2) 基本流程（推荐）

1) 选择输入：上传 JSON / 粘贴 JSON / 从数据库选择  
2) 选择目标模板（默认沿用系统识别到的模板）  
3) （可选）填写成长引导：你希望她“怎么成长、付出什么代价、留下什么后遗症”  
4) 选择是否读写历战/状态栏、是否保留字段  
5) 开始升华 → 下载结果 JSON / 保存到云端 → 回到档案馆进一步整理

> 小提醒：升华是“用 AI 改写结构化数据”，比纯展示更像一次“改稿/重铸”，建议先备份原文件再操作。

## 3) 目标模板：你要升华成哪一种？

升华支持三个目标模板：

- 魔法少女
- 残兽
- 通用角色

如果你不确定选什么：先选“通用角色”通常最稳（它的结构更自由，容错更高）。

## 4) 高级选项：读写历战/状态栏

升华支持分别控制“读取”和“写入”：

- 历战记录（`arena_history`）
- 状态栏（`current_state`）

经验建议：

- 想做长线剧情与连续成长：可以开启读取  
- 想要“纯设定重构/不带前尘往事”：关闭读取更干净  

写入开启时，系统会尝试维护一条连续世界线（例如更新 `world_line_id`、累加 `sublimation_count`、写入 `last_sublimation_at`），方便你长期追踪成长轨迹。

## 5) 高级选项：保留字段（让成长更像“同一个人”）

你可以指定“哪些字段不改”（例如外观、核心概念、问卷答案等）。  
这会让升华更像“成长”，而不是“换人”。

页面里也提供了快捷预设（例如偏“保留性格/基调”的一键选择）。  
当你切换目标模板时，可保留字段列表会自动变化，这是正常的。

另外：当你跨模板升华时，部分字段可能因为结构不兼容而被自动忽略或改写；这是为了避免生成出“能下载但不能用”的坏数据。

## 6) 原生性（签名）会发生什么？

如果你的输入卡是“原生卡”（带有效签名），升华可能出现两种结果：

- **无成长引导**：更有机会保留签名（视服务端策略而定）。
- **有成长引导**：通常会被视为强干预，输出会移除签名，变成“衍生数据”。

这不是惩罚，而是为了让“原生性”的含义更清晰：原生卡强调“流程生成且未被强改”。

## 7) 冷却与模型选择（为什么有时更快/更稳）

- 使用系统默认配置：无需填写 Key，但通常有更长冷却时间。
- 使用自定义供应商 + 自备 API Key：你可以更明确地固定模型，且部分页面会有更短冷却时间。  
  API Key 仅存储在你的浏览器本地 `localStorage`，不会上传到服务器。

## 常见问题

### 为什么升华失败或被拦截？

- 输入 JSON 不可解析 / 结构不符合预期
- 文本触发了敏感词过滤（会被拦截并可能跳转到逮捕页）

可以先看：

- `/encyclopedia/sensitive-words`
