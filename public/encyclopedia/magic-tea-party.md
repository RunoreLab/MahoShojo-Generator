# 魔法茶会（功能与快速开始）

> 作者：[末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-01-18

“魔法茶会”是一个基于**角色卡 / 情景卡**的长期剧情对话页：你可以把角色们请进同一个舞台，像跑团/视觉小说一样推进剧情。

与竞技场不同：竞技场更像“一次生成一篇战报”；茶会更像“多轮对话 + 可选选项 + 可选摘要/更新”，更适合长线故事、日常互动、慢慢写人设。

## 1) 你能用它做什么

- **多角色同台**：一次会话可放入多张角色卡，自由搭配主情景/追加情景。
- **你可以扮演**：作为 `{{user}}` 参与，或选择某个角色作为“玩家角色”。
- **两种输出模式**：
  - **JSONL 模式（推荐）**：旁白/对白/选项会被解析成结构化片段，阅读更清晰。
  - **Markdown 模式**：更自由的正文输出，但不保证稳定解析选项/分段。
- **视觉小说选项**：可一键生成下一步行动选项（2~16）。
- **自动摘要**：对话变长时可自动摘要，减轻上下文压力。
- **角色更新**：可把本次茶会的影响写入角色卡的 `arena_history` / `current_state`（写入后会移除 `signature`，变为非原生）。
- **导入/导出**：会话保存在本地浏览器，可导出 JSON 备份，或导出为 SillyTavern JSONL。

## 2) 重要提醒（避免先翻车）

1) **茶会仅支持自备 API Key**  
左侧需要选择模型并填写 Key；`system` 供应商在茶会中被禁用。

2) **聊天记录默认只保存在本地浏览器**  
换设备/清缓存会丢失，请定期导出会话或归档 ZIP。

3) **如果提示“正在核验内测权限…”**  
说明你还未获得茶会权限，可打开 `/beta-access?feature=magic-tea-party` 查看要求（例如徽章或公开卡使用量门槛）。

## 3) 快速上手（5 分钟开一局）

1) 打开 `/magic-tea-party`  
2) 在左侧「自备 API Key（必填）」里选择供应商/模型并填写 Key  
3) 点击左侧「新建」创建会话（也可先选一个预设场景）  
4) 在「会话设置」中添加角色卡（上传 / 粘贴 / 拖拽 / 在线库）  
5) 可选：添加情景卡（主情景 + 追加情景）  
6) 选择「扮演方式」（作为 `{{user}}` 或扮演某个角色）  
7) 点击「生成开场」，然后开始聊天  
8) 想要选项：点击「生成选项」或在侧边栏开启“合并输出计划”  
9) 想让角色“记住这次经历”：在「资料读写」开启写入，并在「会话摘要 → 角色更新」生成草案/写入

## 4) 推荐默认配置（省钱又稳定）

- 输出模式：**JSONL**
- 合并输出计划（仅对 JSONL 生效）：
  - 选项：`auto`（或 `off` + 手动点“生成选项”）
  - 摘要：`auto`（长线会更稳）
  - 更新草案：`off`（确定要写入时再手动生成）
- 读取历战：开，读取条数 **3**
- 读取当前状态：开
- 写入：先关（确定要写入再开），写入策略建议先用“确认写入”
