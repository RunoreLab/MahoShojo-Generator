# 429 Too Many Requests（请求过于频繁）

> 作者：[Colanns](https://github.com/colasama) / [末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-01-05

当你看到 `HTTP 429` 或「请求过于频繁」「冷却中」之类提示，表示你触发了**限流/冷却**：系统为了稳定与公平，会限制短时间内的重复生成。

## 为什么会这样？

- 同一入口在短时间内被连续点击/刷新多次
- 高峰期服务压力大，系统会更敏感地保护资源
- 某些入口会基于通道（官方/自备 Key）设置不同冷却

## 你能做什么？

- **等待冷却结束再试**
- **避免连点/多标签页同时生成**
- **使用自备模型时**：确认已填写 API Key，并选择正确供应商/模型（通常冷却更短）
