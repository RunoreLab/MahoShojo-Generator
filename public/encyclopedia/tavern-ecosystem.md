# 酒馆生态联动（SillyTavern 角色卡导入/导出）

> 作者：[末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-01-14

0.7.0 起，站内提供 `/tavern`：用于 **SillyTavern（酒馆）角色卡 PNG（内嵌 JSON）** 的导入与导出。

你可以把它理解为两件事：

- **导入**：把酒馆 PNG 解析成本站可用的数据卡（推荐先导成通用角色）
- **导出**：把本站数据卡写回酒馆 PNG（可选附带 A.R.E.N.A. 世界书与情景拼接）

## 1) 导入教程：酒馆 PNG → 本站数据卡

1) 打开 `/tavern`，切到「导入」  
2) 上传酒馆角色卡 PNG  
3) 若解析出多个候选块（不同格式/版本），按预览选择你要的那一份  
4) 选择「导入为」：
   - **通用角色（推荐）**：最稳、容错最高
   - **魔法少女 / 残兽（保守填充）**：会尽量不做过度推理，难以结构化的信息会塞到备注/分析里
5) 可选：开启“保真选项”保存 `_tavern.raw`  
   - 体积很大，**仅建议本地下载**；保存到档案馆前建议关闭
6) 选择转换模式：
   - **规则映射（不调用 AI）**：稳定、可解释、不会发起网络请求
   - **AI 深度转换（可选）**：结构化质量更高，但会发送裁剪后的输入包到生成接口，输出会通过 schema 校验  
     - AI 模式也支持切换「流式/非流式」：流式会输出 Markdown 并生成通用角色；非流式会输出结构化字段（更适合后续玩法/再次导出）
7) 点击「生成角色卡」，在下方预览后下载/复制/保存到云端

## 2) 导出教程：本站数据卡 → 酒馆 PNG

1) 打开 `/tavern`，切到「导出」  
2) 选择本站数据卡 JSON（上传文件 / 浏览在线角色库 / 随机匹配）  
3) 可选：使用「AI 补全文本字段」补全 `scenario/first_mes/mes_example` 等（会发送字段到生成接口）  
4) 选择底图 PNG（可不选，自动使用占位图；也可用站内“生成立绘”一键设为底图）  
5) 推荐勾选：
   - **覆盖已有酒馆块**：避免 PNG 内重复块导致导入结果不确定
   - **写入 ccv3**：主流格式
   - **写入 chara（旧版兼容）**：兼容部分旧导入器
6) 可选：A.R.E.N.A. 世界书 / 情景拼接
   - scenario 为空时自动填入默认舞台（A.R.E.N.A.）
   - 附带 A.R.E.N.A. 世界书（写入 SillyTavern character_book）
   - 追加“附加情景”（支持上传/选择：通用情景卡、结构化情景卡）
7) 点击「生成并下载酒馆卡 PNG」，把 PNG 导入回 SillyTavern 即可

## 3) 隐私与常见坑

- 默认情况下，PNG 的解析/写入在浏览器本地完成；**只有在你选择 AI 功能时才会发起网络请求**。
- 不要把隐私信息写进 `creator_notes/system_prompt` 等字段（导出后会随 PNG 一起流通）。
- 若你在导入时开启 `_tavern.raw`，文件体积会明显变大；保存到云端前请谨慎。
