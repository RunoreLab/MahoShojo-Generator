# 排位与排行榜

排位分是一个「近似强度/稳定性」的统计指标：它来自 LLM 叙事裁判，不追求电竞级公平。

## 两套梯子

- `strict`（严格）：限制更多、可信度更高，但必须登录才计分。
- `free`（自由）：限制更少，允许匿名参与（但需要可用的 `ip_anonymized` 才会计分）。

当某局满足 `strict` 条件时，会同时更新 `strict + free`（便于理解：`strict ⊆ free`）。

## 1v1 MVP

v0.6.0 默认只对 `combatant_count = 2` 的对局计分，避免多人/队伍带来的胜者歧义。

## 段位（显示层）

段位由排位分映射得到（可调参）：

- 无牌：低于阈值或定级期
- 白牌：900–1099
- 字牌：1100–1299
- 花牌：1300–1599
- 权杖：>= 1600

## 排行榜展示口径

公共榜默认只展示：

- 数据卡：`is_public = 1` 且 `review_status = 'approved'`
- 预设角色：默认恒公开参与榜单

你可以在 `/ranking` 页面切换梯子、排序与筛选条件。
