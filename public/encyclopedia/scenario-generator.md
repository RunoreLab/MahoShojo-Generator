# 箱庭物语（情景生成器）

> 作者：末伏之夜  
> 更新时间：2026-01-04

“箱庭物语”会根据你的问卷回答，生成一份结构化的**情景文件（JSON）**，用于竞技场的「情景模式」：它相当于“舞台与剧本钩子”，让角色在同一个明确的场景里展开故事。

## 1) 它会生成什么？

生成结果通常包含：

- `title`：情景标题
- `scenario_type`：情景类型（例如日常/采访/调查/竞技比赛等）
- `description`：简短介绍
- `elements`：场景要素（时间/地点/环境特征/预设 NPC/核心事件/氛围/发展方向）

你可以把它理解为：**可被 AI 复用的“结构化情景设定”**，而不是一段纯文字剧情。

## 2) 怎么填更容易出好结果？

- **场景**：多写“可感知细节”（光线、气味、声音、空间结构），比空泛形容词更稳定。
- **NPC**：如果你不希望生成固定 NPC，建议直接填“未指定”（页面占位提示也强烈建议这么做）。
- **核心事件**：把目标与冲突写清楚（要做什么、阻力是什么、达成/失败会怎样）。
- **氛围**：用几个关键词锁定风格（轻松/热血/悬疑/悲伤…）。
- **发展方向**：写 2～5 条“可能发生的转折”，能显著提升可玩性。

## 3) 高级选项：强制留空字段

在「高级选项：强制留空字段」里，你可以勾选让 AI **必须留空**的部分（例如场景时间、地点、预设 NPC 等），方便你后续自行补全或复用同一份模板。

常见用法：

- 你只想要“结构骨架”，打算自己写 NPC/地点/时间
- 你想做“通用舞台模板”，每次只替换某几个字段

## 4) 选择模型与冷却（普通用户能看懂版）

- 使用系统默认配置：无需填写 Key，但通常有更长冷却时间。
- 使用自定义供应商 + 自备 API Key：你可以更明确地固定模型，且部分页面会有更短冷却时间。  
  API Key 仅存储在你的浏览器本地 `localStorage`，不会上传到服务器。

## 5) 生成后怎么用到竞技场？

生成成功后你可以：

- 下载情景文件（JSON）
- 复制到剪贴板（便于粘贴导入）
- 登录后保存到云端（也支持“替换已有”）

在竞技场使用时：

1) 打开 `/arena`，把模式切到「情景模式」  
2) 选择一个**主情景**（可从在线库选择，或自己上传/粘贴）  
3) 可选：添加“辅助情景”（会和主情景一起进入提示词，用于补充规则或细节）  
4) 选择参战者并生成战报
