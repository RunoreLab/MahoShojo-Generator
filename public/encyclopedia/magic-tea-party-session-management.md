# 魔法茶会：会话管理（置顶/分支/合并/备份与导出）

> 作者：[末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-01-18

魔法茶会的会话与消息**默认只保存在本地浏览器（IndexedDB）**。  
因此，“会话管理”几乎等价于：**如何不丢档、如何改写中途分叉、如何把更好的分支合回主线**。

如果你还没开过茶会，请先读：`/encyclopedia/magic-tea-party`。

## 1) 会话是什么？（以及它保存了什么）

一条茶会“会话”通常包含：

- 你选择的角色卡（可多张）与情景卡（主情景 + 追加情景）
- 本会话的设置：输出模式（JSONL/Markdown）、选项/摘要/写入开关、合并输出计划等
- 对话消息、摘要、更新草案、选项缓存、分支信息等

重要提醒：

- **API Key 不会随会话导出/导入**（换设备需要重新配置 Key）。
- 本地保存意味着：**换设备/清缓存会丢会话**，请养成备份习惯。

## 2) 置顶会话（把常用会话钉起来）

在左侧会话列表中：

- 点「置顶」可把会话移到置顶区。
- 置顶会话 ≥2 个且未开启搜索筛选时，可**拖拽调整置顶顺序**（按提示拖动）。

## 3) 分支会话：从某一轮开始“另写一条线”

什么时候用分支？

- 你想把某条输入改掉，但又不想破坏原会话（保留“原时间线”）
- 你想在关键节点尝试不同选择（多结局/多路线）
- 你想修正“跑偏的一句”并从那里重写后续

怎么创建分支？

1) 在对话区找到你要改写的那条**用户输入**  
2) 点它下面的「编辑并分支」  
3) 修改文本后点「创建分支」  

系统会：

- 创建一个新会话，并复制“分支点之前”的对话作为前置历史
- 把你修改后的那条输入作为分支的起点
- 给分支会话标注“从第 N 轮分支”

## 4) 合并分支：把分支结果写回原会话

当你确认“分支这条线更好”，可以把它合回原会话：

- 在左侧会话列表中，进入该分支会话
- 点击「合并到原会话」

合并做了什么？

- 原会话从“分支锚点”开始的旧内容会被标记为**已被更新替换**（灰色提示），不会立刻删除
- 分支从锚点开始的内容会被复制进原会话，成为新的后续

注意：

- **合并主要针对“对话内容”**；如果你在分支里改了角色/情景/设置，合并后原会话不一定自动同步这些变更，建议你手动对齐卡组与设置。

## 5) 分支链：快速跳转父子会话

当一个会话有父分支或子分支时，左侧会出现「分支链」入口：

- 可查看主线链路（从根会话一路到当前会话）
- 可查看当前会话的子分支
- 点击即可快速跳转到目标会话

## 6) 导入 / 导出（强烈建议定期备份）

茶会提供多种导入导出形式（入口在左侧面板的「导入 / 导出」）：

- **导出当前会话（JSON）**：最推荐的“站内备份”格式
- **导出当前会话（SillyTavern JSONL）**：给酒馆生态使用（偏互通，不保证保留所有茶会元信息）
- **导出全部会话（JSON）**：把所有会话打包成一个 JSON
- **导出全部会话（ZIP，含图片）**：会包含本地缓存的立绘/插画资源，适合迁移浏览器/设备前做完整归档

支持：

- 魔法茶会导出的 JSON
- SillyTavern JSONL
- 茶会归档 ZIP

建议备份策略：

- 长线会话：每隔一段剧情节点导出一次 JSON（或定期 ZIP 归档）
- 准备清浏览器缓存/换设备前：务必先导出 ZIP（含图片）

## 7) 把对话保存成图片（便于分享/发群）

对话区下方有「保存图片」面板，可将对话渲染成 PNG：

- 支持导出最近 N 条 / 全部 / 手动勾选
- 可选移动端/桌面布局
- 可选是否包含 system 消息、是否显示时间戳

提示：生成过程中建议先点「停止生成」再保存图片，避免导出不完整。
