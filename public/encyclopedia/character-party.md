# 角色组队（/character-party）

> 作者：[末伏之夜](https://github.com/notuhao)  
> 更新时间：2026-01-14

“角色组队”用于把多张角色卡**拼接**成一张“队伍角色卡”：把一个小队/团体/多名 NPC 打包成一个可上场的角色文件。

它特别适合创作者做这类事情：

- 让“一个队伍”在竞技场里作为一个整体上场
- 把常用 NPC 组合打包，方便反复复用
- 把多人设定拼成一张卡，再导出到酒馆生态

## 1) 合并规则（你需要知道的最关键点）

- 字符串字段与数组元素会自动加上前缀 `【队员标识】...`，避免信息混在一起
- 缺失字段会被忽略；同字段会按队员顺序拼接
- 队员顺序会影响合并结果（尤其是数组：会按队员顺序依次展开）
- 模板不一致时，默认会自动降级为**通用角色卡**（更稳）

## 2) 使用教程（从 0 到导出）

1) 打开 `/character-party`  
2) 添加队员（任选其一）：
   - 从云端添加：登录后可直接选自己的数据卡
   - 从本地添加：上传多个 `.json` 文件
   - 粘贴添加：支持 JSON 对象或对象数组
3) 在「队员列表」里：
   - 修改“队员标识”（这就是前缀里显示的名字）
   - 上移/下移调整顺序
4) 在「合并设置」里选择输出模板：
   - 自动（推荐）：同模板直接拼接，不同模板降级通用角色
   - 强制：通用角色 / 魔法少女 / 残兽（不一致时会提示并自动降级）
5) 在预览区确认效果后：
   - 下载 JSON / 复制到剪贴板 / 保存到云端
   - 可选：保存角色卡图片、生成立绘

## 3) 原生性与签名（常见疑问）

页面会对队员进行原生性校验：

- 若队伍中存在非原生角色：输出将不包含 `signature`（队伍卡为非原生）
- 若队伍全部为原生角色：下载/保存时会尝试请求服务器为合并结果重新签名  
  （若部署环境未启用签名密钥，会自动降级为不含签名输出）
